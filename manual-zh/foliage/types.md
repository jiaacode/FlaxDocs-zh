# 植被类型

每个植被 Actor 都包含一个它使用的类型列表。这有助于同时编辑多个实例，并为其共享数据以提高整体性能。使用 **植被** 选项卡来添加/移除/修改所选植被 Actor 中包含的植被类型。

## 属性

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **模型**               | 此类型的所有植被实例所绘制的模型。它在植被 Actor 内必须是唯一的，且不能为空。 |
| **材质**               | 模型材质覆盖集合。可用于将网格的特定材质更改为自定义材质，而无需编辑资源。 |
|                        |                                                              |
| **剔除距离**           | 每个实例的剔除距离。                                         |
| **剔除距离随机范围**   | 每个实例的剔除距离随机化范围（每个实例随机化，并添加到主 CullDistance 值中）。 |
| **阴影模式**           | 阴影投射模式。                                               |
| **接收贴花**           | 确定此网格是否可以接收贴花。                                 |
| **光照贴图缩放**       | 光照贴图中的缩放（用于此植被类型的实例）。可用于调整植被实例的静态光照质量。 |
| **使用密度缩放**       | 用于确定是否对此植被类型的实例使用全局植被密度缩放的标志。   |
| **密度缩放比例**       | 应用于此类型植被实例全局缩放的密度缩放比例。可用于增强或降低此植被类型上的密度缩放效果。 |
|                        |                                                              |
| **密度**               | 植被实例密度，定义为每 1000x1000 单位面积内的实例数量。      |
| **半径**               | 植被实例之间的最小半径。                                     |
| **绘制地面坡度角范围** | 可在其上绘制植被的最小和最大地面坡度角（以度为单位）。       |
| **缩放**               | 缩放模式。                                                   |
| **最小缩放**           | 每个轴的最小缩放值。                                         |
| **最大缩放**           | 每个轴的最大缩放值。                                         |
|                        |                                                              |
| **偏移 Y**             | Y 轴上每个实例的随机偏移范围（最小值-最大值）。              |
| **随机俯仰角**         | 随机俯仰角范围（围绕法线向量在两个方向上均匀分布）。         |
| **随机翻滚角**         | 随机翻滚角范围（围绕法线向量在两个方向上均匀分布）。         |
| **对齐法线**           | 如果勾选，实例将对齐到放置表面的法线。                       |
| **随机偏航**           | 如果勾选，实例在放置时将使用随机偏航。随机偏航将使用 Y 轴上的旋转范围。 |
