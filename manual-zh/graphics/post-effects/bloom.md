# 泛光

![泛光](/manual/media/bloom.png)

**泛光** 效果会搜索输入图像的明亮区域，并将其扩展到周围区域。这模拟了强光使相机过曝，从而使明亮物体开始发光。

## 属性

![属性](/manual/media/bloom-properties.jpg)

| 属性         | 描述                                                    |
| ------------ | ------------------------------------------------------- |
| **已启用**   | 如果勾选，将渲染泛光效果。                              |
| **强度**     | 泛光效果强度。设置为 0 可禁用它，而较高的值会增加效果。 |
| **阈值**     | 泛光开始的亮度阈值。                                    |
| **阈值过渡** | 控制阈值衰减曲线。较高的值会产生更柔和的过渡。          |
| **限制**     | 泛光高光的最大亮度限制。                                |
| **基础混合** | 基础 Mip 贡献，用于更宽、更柔和的泛光。                 |
| **高混合**   | 高 Mip 贡献，用于更紧致、核心的泛光。                   |
