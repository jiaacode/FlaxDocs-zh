# 颜色分级

![颜色分级](media/color-grading.png)

**颜色分级**（或称**颜色校正**）是一种用于增强整体场景颜色的效果。Flax 引擎提供了强大的颜色分级工具，使美术师能够在编辑器内以实时预览的方式对过场动画和游戏玩法进行颜色校正。这为创建外观出色的游戏作品迈出了一大步。

要使用自定义颜色分级 LUT，请参阅以下部分以了解如何导入和应用查找表纹理。

## 色轮

![色轮](media/color-grading-wheel.png)

在 *颜色分级* 选项部分，你可以找到**色轮**（也称为**轨迹球**）。它们用于执行更具“艺术性”控制的*三向*颜色分级。

调整色轮上点的位置将产生在给定色调范围内将图像色调向该颜色偏移的效果。不同的色轮用于影响图像内的不同范围。调整色轮右侧的滑块允许你手动指定所需的颜色，或仅修改单个通道（`Red`、`Green` 或 `Blue`）。此外，`Alpha` 滑块用于偏移颜色的亮度。你可以将其视为“缩放”值。

## 属性

![属性](media/color-grading-properties.jpg)

颜色分级轨迹球分为 4 组：

- 主控
- 阴影
- 中间调
- 高光

每组控制范围的一个选定部分（*主控* 除外，它影响整个图像）。

| 属性           | 描述                                                         |
| -------------- | ------------------------------------------------------------ |
| **饱和度**     | 调整所表示颜色的强度（纯度）。较高的饱和度强度将导致颜色看起来更接近其最纯的形式（红、绿、蓝），而当饱和度降低时，颜色将显得更灰或褪色。 |
| **对比度**     | 调整场景中明暗颜色值的色调范围。降低强度将移除高光并使图像变亮，导致褪色的外观，而较高的强度将收紧高光并使整体图像变暗。 |
| **伽马**       | 调整图像中间调的亮度强度，以准确再现颜色。降低或提高此值将导致图像褪色或太暗。 |
| **增益**       | 调整图像白色（高光）的亮度强度，以准确再现颜色。提高或降低此值将导致图像高光褪色或太暗。 |
| **偏移**       | 调整图像黑色（阴影）的亮度强度，以准确再现颜色。提高或降低此值将导致图像阴影褪色或太暗。 |
|                |                                                              |
| **阴影**       | 饱和度/对比度/伽马/增益与主控值的工作方式相同，但仅应用于场景阴影。 |
|                |                                                              |
| **中间调**     | 饱和度/对比度/伽马/增益与主控值的工作方式相同，但仅应用于场景中间调。 |
|                |                                                              |
| **高光**       | 饱和度/对比度/伽马/增益与主控值的工作方式相同，但仅应用于场景高光。 |
|                |                                                              |
| **阴影最大值** | 控制图像黑色（阴影）的亮度强度，以准确再现颜色。提高或降低此值将导致图像阴影褪色或太暗。 |
| **高光最小值** | 控制影响高光部分中已调整的颜色校正属性的乘数。               |

## 自定义 LUT 纹理

**查找表（LUT）** 用于对最终渲染图像执行颜色校正。混合在 LDR 中执行，并在色调映射、程序化颜色校正和曝光控制之后应用。

Flax 中使用的 **LUT** 纹理必须是展开的 **256x16** 纹理，以无压缩、无 mipmap 且仅使用 RGB 通道的方式导入。

LUT 纹理示例：
![LUT 纹理](media/LUT_LateSunsetTable.png)

要应用 LUT，只需添加一个 PostFx Volume Actor，并在 *颜色分级* 类别中分配纹理和权重。
![LUT 纹理示例](media/lut-example.png)

要制作自己的 LUT 纹理，你可以截取游戏视口的屏幕截图，然后执行自定义颜色校正以达到所需的外观。接下来，将相同的颜色分级应用于中性 LUT，并在引擎中将其用于颜色分级。
