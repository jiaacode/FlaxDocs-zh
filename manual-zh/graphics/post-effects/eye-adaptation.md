# 眼睛适应

![眼睛适应](media/eye-adaptation.png)

**眼睛适应**（或称**自动曝光**）是一种用于模拟人眼对光线曝光的适应效果。现实摄像机中的光线传感器以类似的方式工作。它会修改曝光以适应图像亮度。例如，如果一个人从明亮的环境移动到黑暗的环境，眼睛会调整以适应进入的光线量。

## 属性

![属性](media/eye-adaptation-properties.jpg)

| 属性                       | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **Mode**                   | 用于曝光处理效果的渲染模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**None**</td><td>禁用眼睛适应效果。</td></tr><tr><td>**Manual**</td><td>手动模式使用固定的曝光值。</td></tr><tr><td>**Automatic Histogram**</td><td>自动模式使用直方图，基于场景颜色亮度混合应用眼睛适应曝光。需要计算着色器支持。</td></tr><tr><td>**Automatic Average Luminance**</td><td>自动平均亮度模式使用平均亮度，基于场景颜色亮度混合应用眼睛适应曝光。</td></tr></tbody></table> |
| **Speed Up**               | 当场景亮度从暗区域移动到亮区域（亮度增加）时，曝光变化的速度。 |
| **Speed Down**             | 当场景亮度从亮区域移动到暗区域（亮度降低）时，曝光变化的速度。 |
| **Pre Exposure**           | 在执行后期处理（如泛光、镜头光晕等）之前应用于场景颜色的预曝光值。 |
| **Post Exposure**          | 在执行后期处理（如泛光、镜头光晕等）之后，但在颜色分级和色调映射之前应用于场景颜色的后曝光值。 |
| **Minimum Brightness**     | 自动曝光的最小亮度，限制了眼睛可以适应的最低亮度。           |
| **Maximum Brightness**     | 自动曝光的最大亮度，限制了眼睛可以适应的最高亮度。           |
| **Histogram Low Percent**  | 场景颜色亮度直方图的下限。此值以百分比表示，并限制低于此亮度的像素。使用范围为 60-80 的值。仅在自动直方图模式下使用。 |
| **Histogram High Percent** | 场景颜色亮度直方图的上限。此值以百分比表示，并限制高于此亮度的像素。使用范围为 80-95 的值。仅在自动直方图模式下使用。 |
