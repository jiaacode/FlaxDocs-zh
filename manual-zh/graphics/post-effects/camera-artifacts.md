# 摄像机伪影

![摄像机伪影](media/camera-artifacts.png)

**摄像机伪影** 是一组有助于模拟现实摄像机伪影的效果。这包括暗角、噪点和色差。所有这些效果都与摄像机胶片和镜头相关。

## 属性

![属性](media/camera-artifacts-properties.jpg)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **暗角强度**         | 暗角效果的强度。值为 `0` 时隐藏它。默认值为 `0.8`。          |
| **暗角颜色**         | 暗角的颜色。                                                 |
| **暗角形状因子**     | 控制暗角的形状。接近 `0` 的值产生矩形形状。较高的值产生更圆的形状。默认值为 `0.125`。 |
| **颗粒数量**         | 颗粒滤镜的强度。值为 `0` 时隐藏它。默认值为 `0.005`。        |
| **颗粒大小**         | 颗粒的大小。默认值为 `1.6`。                                 |
| **颗粒速度**         | 颗粒动画的速度。                                             |
| **色差**             | 控制色差效果的强度。值为 `0` 时隐藏它。                      |
| **屏幕淡入淡出颜色** | 屏幕色调颜色（Alpha 通道定义混合因子）。                     |
