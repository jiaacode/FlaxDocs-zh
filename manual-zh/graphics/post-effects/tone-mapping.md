# 色调映射

![色调映射](/manual/media/tone-mapping.png)

**色调映射** 获取高动态范围（`HDR`）输入颜色，并将其重新映射为显示器可以显示的低动态范围（`LDR`）。这是后期处理帧的最后阶段。

> [!TIP]
> 强烈建议为整个项目设置色调映射器选项，而不是按每个摄像机镜头设置。对于更动态的图像调整，请使用[颜色分级](color-grading.md)。

## 电影色调映射器

Flax 引擎实现了由[学院颜色编码系统（ACES）](http://www.oscars.org/science-technology/sci-tech-projects/aces)为电视和电影设定的行业标准。这导致跨多种格式和显示器保持一致的颜色，同时也使源材料具有未来兼容性，因为无需针对后续出现的每种媒介进行调整。目标是使用标准化的高质量格式。

## 属性

使用色调映射器的选项可以调整最终的胶片 S 曲线形状和平衡色温。

![属性](/manual/media/tone-mapping-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **白色温度** | 根据场景中光源的色温调整白平衡。当光源色温与该值匹配时，光线将呈现白色。当使用的值高于场景中的光源时，会产生“暖色”或黄色，反之，如果值较低，则会产生“冷色”或蓝色。默认值为 `6500`。 |
| **白色色调** | 通过调整青色和品红色范围来调整场景的白平衡色温色调。理想情况下，此设置应在调整白平衡色温后使用，以获得准确的颜色。在某些光源色温下，颜色可能看起来更黄或更蓝。这可用于平衡结果颜色，使其看起来更自然。默认值为 `0`。 |
| **模式**     | 用于颜色分级过程的色调映射模式。                             |
