# 屏幕空间反射

![屏幕空间反射](/manual/media/screen-space-reflections.png)

**屏幕空间反射** 效果（缩写为 **SSR**）为对象添加局部反射，增加场景的真实感。此效果在 *屏幕空间* 中渲染，这意味着只有已经在屏幕上的对象才能被反射（它不适用于屏幕外或被遮挡的对象）。

这意味着 SSR 在走廊和房间等封闭区域效果良好，但在开放空间中效果较差，因为开放空间中你期望反射出更多的世界。它们在有纹理的表面上也效果最好，这可以掩盖反射中的瑕疵，而在非常光滑、镜面般的表面上效果较差。例如，在镜子中，缺失的反射很明显。
作为回退，值会使用放置的环境探针中的反射颜色。

## 算法

Flax 引擎通过几个通道渲染 SSR：

1. **光线投射** 通道在深度缓冲区上执行屏幕空间光线追踪，以查找几何体交点。
2. **解析** 通道解析光线并计算反射颜色。
3. **时间** 通道使用历史缓冲区在当前帧和上一帧之间持续混合。这减少了反射中的噪点，但会产生有时可见的动画“抖动”效果。你可以调整或禁用此步骤以创建所需的效果。
4. **合成** 通道将效果的结果与渲染图像混合。

## 属性

![属性](/manual/media/screen-space-reflections-properties.jpg)

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **强度**               | 反射强度缩放（范围为 0 到 1）。                              |
| **深度分辨率**         | 下采样深度缓冲区以优化光线投射性能。*Full* 提供更好的质量，但 *Half* 提高性能。默认值为 Half。 |
| **光线追踪分辨率**     | 光线投射分辨率。有两个选项：*Full* 和 *Half*。Full 提供更好的质量，但 Half 提高性能。默认值为 Half。 |
| **BRDF 偏差**          | 反射扩散参数。此值控制源粗糙度对反射模糊的影响。较小的值产生更宽的反射扩散，但也引入更多噪点。较高的值提供更镜面般的反射。默认值为 `0.82`。 |
| **粗糙度阈值**         | 材质可以具有的最大粗糙度量以反射场景。例如，如果此值设置为 `0.4`，则只有粗糙度值为 `0.4` 或以下的材质才会反射场景。默认值为 `0.45`。 |
| **世界抗自遮挡偏差**   | 光线投射原点的偏移。较低的值产生更正确的反射位置，但会产生轻微伪影。我们建议值为 `0.3` 或更低。默认值为 `0.1`。 |
| **解析分辨率**         | 使用光线投射结果计算反射颜色。有两个选项：*Full* 和 *Half*。Full 提供最佳结果，但 Half 提高性能。默认值为 Full。 |
| **解析样本数**         | 用于解析反射颜色的光线数量。较高的值产生较少的噪点，但性能较差。默认值为 `4`。使用 1 以获得最高速度。 |
| **边缘淡出因子**       | 反射远边缘开始淡出的点。这对性能没有影响。默认值为 `0.1`。   |
| **使用颜色缓冲区 Mip** | 如果勾选，在解析反射颜色时下采样输入颜色缓冲区并使用模糊的 mipmap 链。这会通过模糊粗糙（高粗糙度）材质中反射的远距离部分来产生更真实的结果。它还能在大多数平台上提高性能。但是，它会使用更多内存，因此你可能希望在移动平台（例如）上禁用它。 |
| **启用时间效果**       | 如果勾选，启用时间通道。这会减少噪点，但会产生有时可见的动画“抖动”效果。时间效果默认启用。 |
| **时间缩放**           | 控制时间效果的强度。较低的值产生更快的反射，但噪点更多。默认值为 `8`。 |
| **时间响应**           | 定义当前帧中的反射与历史缓冲区之间的混合速度。较低的值产生更快的反射，但抖动更多。如果你的游戏中的摄像机移动不多，我们建议使用接近 `1` 的值。默认值为 `0.8`。 |

>[!Note]
>如果时间效果被禁用，其他时间属性无效。
