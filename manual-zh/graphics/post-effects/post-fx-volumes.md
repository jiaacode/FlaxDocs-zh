# 后期处理效果体积

![后期处理效果体积](media/post-fx-volumes.png)

**后期处理效果体积** 是一种特殊的 Actor，用于覆盖空间中已定义体积内的默认后期处理设置。
通过使用它，你可以修改体积内的景深、泛光或其他效果。
当玩家摄像机移入体积时，设置会发生混合。

使用后期处理效果体积可以在 3D 空间中或按摄像机（只需将后期处理效果体积作为摄像机的子级附加）修改后期处理。Flax 引擎支持混合无限数量的体积。但是，同时混合过多体积可能会对 CPU 性能产生负面影响。

## 属性

![属性](media/post-fx-volumes-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **中心**     | 边界中心的位置（在 Actor 的局部空间中）。                    |
| **大小**     | 包围盒的大小。                                               |
| **优先级**   | 混合优先级。具有较高优先级的体积首先被混合。                 |
| **混合半径** | 边界混合衰减半径。用于在摄像机进入边界时平滑设置过渡。仅在体积 *有界* 时使用。 |
| **混合权重** | 归一化（范围为 0-1）的体积混合权重。可以在运行时进行动画或修改，以在启用体积时执行平滑过渡（而不是使用二进制选项 *是否激活*）。 |
| **有界**     | 如果勾选，设置混合将使用对象的边界，否则它将具有全局效果。   |

## 编辑后期处理设置

后期处理效果体积支持 *“逐选项”* 值覆盖，这意味着只有选定的选项可以被体积修改。这在游戏制作过程中处理每个关卡区域的自定义效果时非常方便。

要覆盖设置，只需勾选其专用的复选框，然后调整值，如下图所示。
