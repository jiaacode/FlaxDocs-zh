# 环境光遮蔽

![环境光遮蔽](media/ambient-occlusion.png)

**环境光遮蔽** 效果用于向对象应用接触阴影。它模拟现实生活中的阴影，有助于在 3D 空间中创建关于对象位置的视觉感。

## 属性

![属性](media/ambient-occlusion-properties.jpg)

| 属性         | 描述                                       |
| ------------ | ------------------------------------------ |
| **已启用**   | 如果勾选，将渲染效果。                     |
| **强度**     | 遮蔽区域变暗效果的强度。                   |
| **幂**       | 环境光遮蔽幂参数。控制遮蔽渐变。           |
| **半径**     | 遮蔽采样的半径。                           |
| **淡出距离** | 超出此距离（以世界单位为单位）效果将淡出。 |
