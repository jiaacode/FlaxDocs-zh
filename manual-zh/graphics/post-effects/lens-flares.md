# 镜头光晕

![镜头光晕](media/lens-flares.png)

**镜头光晕** 效果模拟了现实相机镜头内部光传输产生的伪影。这包括光线的反射和散射。

这些伪影通常沿着由原始亮点和屏幕中心定义的线条排列。最明显的伪影通常相对于屏幕中心与真实点光源完全对称。

## 属性

![属性](media/lens-flares-properties.jpg)

| 属性             | 描述                                         |
| ---------------- | -------------------------------------------- |
| **强度**         | 效果的强度。值为 0 可禁用它。                |
| **重影**         | *重影* 样本的数量。                          |
| **光晕宽度**     | 镜头光晕的光晕宽度。                         |
| **光晕强度**     | 镜头光晕的光晕强度。                         |
| **重影分散**     | *重影* 样本的分散参数。                      |
| **畸变**         | 镜头光晕的颜色畸变参数。                     |
| **阈值偏差**     | 输入图像亮度阈值。添加到输入像素。           |
| **阈值缩放**     | 输入图像亮度阈值缩放。用于乘以输入像素。     |
| **镜头污渍**     | 全屏镜头污渍纹理。                           |
| **镜头污渍强度** | 全屏镜头污渍强度参数。允许调整污渍可见性。   |
| **镜头颜色**     | 用于镜头颜色光谱的自定义镜头颜色纹理（1D）。 |
| **镜头星形**     | 由镜头光晕采样的自定义镜头星形纹理。         |
