# 静态模型

![模型](media/box.png)

**模型 Actor** 渲染模型并允许覆盖其某些属性，例如阴影投射或材质槽集合。使用模型 Actor 是在场景中放置模型的最常见方式。

## 模型属性

![模型属性](media/model-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **光照贴图缩放** | 模型网格在光照贴图中的缩放。用于缩放所有网格的主参数。       |
| **边界缩放**     | 模型边界缩放参数。在使用位置偏移来动画对象顶点超出其边界时非常有用。增加对象的边界会降低性能和阴影质量。 |
| **隐藏阴影**     | 如果勾选，对象将投射阴影但不可见。                           |
| **模型**         | 用于渲染的模型资源。                                         |
| **条目**         | 要覆盖的模型槽的集合。请参阅 *网格属性* 部分以了解更多信息。 |

## 网格属性

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **材质**         | 用于渲染的材质或材质实例资源。                               |
| **光照贴图缩放** | 网格在光照贴图中的缩放。                                     |
| **可见**         | 如果勾选，网格可见。允许使用此条目隐藏网格。                 |
| **变换**         | 应用于使用此槽的网格的局部变换（平移、旋转和缩放）。可用于旋转机翼或移动一组网格。 |
| **接收贴花**     | 确定此网格是否可以接收贴花。                                 |
| **阴影模式**     | 使用此条目的网格的阴影投射模式。可能的选项：<br><table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**无**</td><td>从不渲染阴影。</td></tr><tr><td>**仅静态**</td><td>仅在静态视图中渲染阴影（环境探针、光照贴图等）。</td></tr><tr><td>**仅动态**</td><td>仅在动态视图中渲染阴影（游戏、编辑器等）。</td></tr><tr><td>**全部**</td><td>始终渲染阴影。</td></tr></tbody></table> |
