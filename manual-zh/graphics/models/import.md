# 导入模型

导入模型文件的方式与导入其他资源类型相同。只需将模型文件从文件 *资源管理器* 窗口（MacOS 上为 *Finder*）拖放到 *内容* 窗口，或使用 *导入* 按钮。

![导入模型](/manual/media/import-model.jpg)

选择文件后，将显示 **导入文件设置** 对话框。它用于指定每个模型的导入选项。在大多数情况下，默认值是可接受的，你只需按下 **导入** 按钮即可。

> [!Note]
> 使用 **导入文件设置** 对话框，你可以一次选择多个模型（或使用 **Ctrl+A** 全选）并同时指定导入选项。

每个模型都可以重新导入（源文件的相对路径会被缓存），并且可以使用[模型窗口](model-window.md)修改导入设置。

## 支持的文件类型

Flax 引擎支持导入以下列表中的文件类型作为模型：
- `.fbx` - 当前推荐的格式
- `.gltf`
- `.glb`
- `.obj`
- `.x`
- `.dae`
- `.blend`
- `.lwo`
- `.lws`
- `.lxo`
- `.ply`
- `.q3o`
- `.q3s`
- `.stl`

## 导入模型 LOD

Flax 支持最多 6 个模型细节级别。要导入它们，请在模型文件中的对象节点名称中使用 `LODx`（其中 `x` 是 LOD 索引，从 0 开始）后缀。此外，在导入模型时，请确保勾选 **导入 LOD** 选项。

## 导入到预制体

模型导入系统支持将源文件内容（网格、节点、动画、材质、纹理等）全部导入到引擎内的预制体场景中。这允许轻松自定义导入的对象，并且对于更复杂的场景尤其有用。导入文件时，将类型选择为 **预制体**，然后你可以自定义其他导入选项（每个网格在导入后都可以覆盖设置）。

![模型预制体导入](/manual/media/model-prefab.png)

导入的预制体可以被打开和自定义。将其添加到场景后，预制体中的任何更改都将同步到整个项目的所有实例中。创建的预制体的根对象包含 `ModelPrefab` 脚本，该脚本存储了保存的导入选项和源文件路径（相对于项目文件夹或绝对路径）。你可以使用它来重新导入源资源（例如，与源文件同步或使用不同的导入选项）。

## 导入碰撞网格

Flax 支持从源模型自动导入碰撞网格。要导入碰撞网格，请在模型文件中为碰撞网格使用自定义名称前缀（例如 `COLL_` 或 `UCX_` 前缀），并在导入选项 **碰撞网格前缀** 中指定该前缀。引擎将提取这些碰撞网格并创建一个单独的碰撞数据资源。

使用示例：

![模型碰撞导入引擎](/manual/media/collision-mesh.png)

为方便使用，将模型添加到场景后，你可以使用 *右键单击* 并选择选项 **添加网格碰撞体**。编辑器将自动选取导入的碰撞网格（或生成一个新的），并将其添加到场景中的模型上，使其具有用于物理的碰撞。你可以在凸包和三角形网格之间更改 `碰撞类型` - 凸包更优化但精度较低。

## 导入多个模型时重用材质

当导入大量模型时，导入器会为每个模型创建材质，这可能效率不高。为了优化它，你可以：
* 选择所有模型（例如使用 `Ctrl+A`）以批量编辑它们，
* 勾选 **将材质导入为实例** 以创建材质实例而不是材质，
* 分配用作基础的 `实例要导入为` 材质（它可以包含公共参数，如 `Color`，以便在实例中被导入器覆盖），
* 将 `子资源文件夹` 设置为所有模型的导入材质和纹理将放置到的文件夹名称（例如 `mat`）
* 导入。

![导入多个模型时重用材质](/manual/media/import-models-with-shared-mat-instances.png)

## 模型导入设置

![模型](/manual/media/imort-model-settigns.jpg)

Flax 对 **模型**、**蒙皮模型** 和 **动画** 使用相同的导入设置数据方案，因为它们都可以从相同的源文件（例如 `.fbx` 或 `.dae`）导入。

|                          |                                                              |
| **几何体**               |                                                              |
| **计算法线**             | 如果勾选，模型法线向量将被重新计算。                         |
| **平滑法线角度**         | 指定在同一顶点位置的两个面法线在平滑之前可能出现的最大角度（以度为单位）。仅在勾选 *计算法线* 时使用。默认值为 175。 |
| **计算切线**             | 如果勾选，模型切线向量将被重新计算。                         |
| **平滑切线角度**         | 指定在两个顶点的切线和副切线平滑之前可能出现的最大角度（以度为单位）。仅在勾选 *计算切线* 时使用。默认值为 45。 |

| **实例要导入为**         | 用作基础材质的材质，该材质将被实例化为导入模型的材质。       |

| **重新导入时保留材质槽** | 如果勾选，导入器将尝试保留模型当前的材质槽，而不是从源文件导入材质。 |
|                          |                                                              |
| **拆分对象**             | 如果勾选，导入的网格/动画将被拆分为单独的资源。如果 *对象索引* 设置为 -1，则使用。 |

| **子资源文件夹**         | 如果指定，指定的文件夹将用作自动导入的子资源（如纹理和材质）的子目录名称。设置为空格（单个空格）以导入到同一目录。 |

## 提示

如果模型看起来缺少某些内容或比你预期的多，请确保你导入的模型确实是你认为的那样。例如，Blender 默认导出所有内容，除非你勾选了“仅选择”框。检查这一点的一个简单方法是将文件重新导入到你的建模器中。

如果你想从源文件导入所有动画片段或将所有模型网格作为单独资源导入，请使用 **拆分对象** 选项。它将从模型文件中拆分源对象，并将它们作为单独的资源导入。它将支持轻松重新导入，因为每个拆分对象都会自动分配自己的 **对象索引**。
