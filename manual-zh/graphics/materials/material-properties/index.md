# 材质属性

本页面详细介绍了所有可用的材质属性。这些选项可以通过[材质编辑器](../material-editor/index.md)窗口为每个材质进行访问。

![属性](../media/material-properties.jpg)

## 常规

![常规](../media/properties-general.png)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **领域**     | 指定材质的使用方式。某些用于后期处理或 2D 渲染的材质需要渲染管线生成额外的指令。因此，指定涵盖这些情况的材质领域很重要。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Surface**</td><td>表面材质。可用于渲染场景几何体，包括模型和蒙皮模型。</td></tr><tr><td>**Post Process**</td><td>[后期处理材质](../../post-effects/post-fx-materials.md)。可用于对渲染帧执行自定义后期处理。</td></tr><tr><td>**Decal**</td><td>[贴花材质](../../decals/index.md)。可用于对世界中的对象表面应用自定义叠加或表面修改。</td></tr><tr><td>**GUI**</td><td>GUI 着色器。可用于绘制自定义控件界面元素或为 GUI 添加自定义效果。</td></tr><tr><td>**Terrain**</td><td>地形着色器。只能与使用优化顶点数据并支持多层混合的地形块几何体一起使用。</td></tr><tr><td>**Particle**</td><td>粒子着色器。只能与粒子几何体（精灵、轨迹和带状）一起使用。支持在 GPU 上读取粒子数据。</td></tr><tr><td>**Deformable**</td><td>可变形着色器。只能与可变形对象（例如样条模型）一起使用。</td></tr></tbody></table> |
| **着色模型** | 指定如何组合材质输入和属性以产生最终表面颜色。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Unlit**</td><td>无光照材质。自发光通道用作输出颜色。可以执行自定义光照操作或仅发光。不会受光照管线影响。</td></tr><tr><td>**Lit**</td><td>默认的有光照材质。材质表面最常见的选择。</td></tr><tr><td>**Subsurface**</td><td>次表面材质。适用于蜡或皮肤等需要光散射来模拟光线穿过对象的材质。</td></tr></tbody></table>要了解有关着色模型的更多信息，请参阅相关文档[此处](../shading-models/index.md)。 |
| **混合模式** | 指定如何将材质与环境混合。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Opaque**</td><td>不透明材质。在 *GBuffer* 通道渲染期间使用。这是默认值。</td></tr><tr><td>**Transparent**</td><td>透明材质。在 *正向* 通道渲染期间使用。</td></tr><tr><td>**Additive**</td><td>叠加混合。材质颜色用于添加到表面后方对象的颜色中。在正向通道渲染期间使用。</td></tr><tr><td>**Multiply**</td><td>相乘混合。材质颜色用于乘以表面后方对象的颜色。在正向通道渲染期间使用。</td></tr></tbody></table>要了解有关混合模式的更多信息，请参阅相关文档[此处](../blend-modes/index.md)。 |

## 渲染

![渲染](../media/properties-rendering.png)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **剔除模式** | 定义几何体渲染期间使用的图元剔除模式。                       |
| **线框**     | 如果勾选，使用此材质的几何体将以线框模式渲染，而不进行实体三角形填充。 |
| **深度测试** | 如果勾选，在材质渲染期间启用深度测试。                       |
| **深度写入** | 如果勾选，在材质渲染期间启用写入深度缓冲区。                 |

## 透明度

![透明度](../media/properties-transparency.png)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **透明光照模式**     | 透明材质光照模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Surface**</td><td>在材质表面逐像素评估的默认方向光照。用于半透明表面——漫反射和高光光照分量均处于活动状态。</td></tr><tr><td>**Surface Non-Directional**</td><td>在材质表面逐像素评估的非方向光照。用于烟雾、雨或灰尘等体积对象——仅漫反射光照项处于活动状态（无高光）。</td></tr></tbody></table> |
| **启用反射**         | 如果勾选，在渲染材质时启用反射。                             |
| **启用屏幕空间反射** | 如果勾选，在渲染材质时启用屏幕空间反射。                     |
| **启用雾效**         | 如果勾选，在渲染材质时启用雾效。                             |
| **启用失真**         | 如果勾选，在渲染材质时启用失真效果。                         |
| **启用全局光照**     | 如果勾选，在材质中启用全局光照采样（例如光照探针或体积光照贴图）。 |
| **像素法线偏移折射** | 基于逐像素法线与逐顶点法线之间的差异启用折射偏移。对于大型水面类表面非常有用。 |
| **不透明度阈值**     | 控制不透明度值的裁剪点。                                     |

## 细分

![细分](../media/properties-tessellation.png)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **细分模式**     | 网格表面细分方法。仅适用于 *Domain* 设置为 *Surface* 的材质。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**None**</td><td>无细分。</td></tr><tr><td>**Flat**</td><td>平面细分。也称为棋盘细分。</td></tr><tr><td>**PointNormal**</td><td>点法线细分。</td></tr><tr><td>**Phong**</td><td>Phong 法线插值的几何版本，不应用于法线，而是应用于顶点位置。</td></tr></tbody></table> |
| **最大细分因子** | 最大三角形细分因子。默认值为 `15`。增加它以解锁更高的细分。较高的值会降低渲染性能。 |

## 杂项

![杂项](../media/properties-misc.png)

| 属性                     | 描述                                                         |
| ------------------------ | ------------------------------------------------------------ |
| **使用输入世界空间法线** | 如果勾选，材质输入法线将被假定为世界空间而非切线空间。       |
| **使用抖动 LOD 过渡**    | 如果勾选，材质使用抖动的模型 LOD 过渡以实现更平滑的 LOD 切换。 |
| **遮罩阈值**             | 控制遮罩值的裁剪点。                                         |
| **贴花混合模式**         | 指定贴花材质的混合模式。仅适用于 *Domain* 设置为 *Decal* 的材质。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Translucent**</td><td>贴花将与材质表面完全混合。</td></tr><tr><td>**Stain**</td><td>贴花颜色将与材质表面颜色混合（使用乘法）。</td></tr><tr><td>**Normal**</td><td>贴花将仅混合法线向量。</td></tr><tr><td>**Emissive**</td><td>贴花将仅应用自发光。</td></tr></tbody></table> |
| **后期处理位置**         | 指定何时渲染后期处理材质。仅适用于 *Domain* 设置为 *Post Process* 的材质。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**After Post Processing Pass**</td><td>使用 *LDR* 输入帧在后期处理通道之后渲染材质。</td></tr><tr><td>**Before Post Processing Pass**</td><td>使用 *HDR* 输入帧在后期处理通道之前渲染材质。</td></tr><tr><td>**Before Forward Pass**</td><td>在正向通道之前但在 *GBuffer* 之后使用 *HDR* 输入帧渲染材质。</td></tr><tr><td>**After Custom Post Effects**</td><td>在自定义后期效果（脚本化）之后渲染材质。</td></tr><tr><td>**Before Reflections Pass**</td><td>在反射通道之前渲染材质。在光照通道之后。可用于实现将光照累积到光照缓冲区的自定义光源类型。</td></tr><tr><td>**After Anti-Aliasing Pass**</td><td>在抗锯齿滤镜通道之后渲染材质。渲染到输出后缓冲区。</td></tr></tbody></table> |

## 参数

![参数](../media/properties-params.png)

每个材质都包含一组自定义参数。这些参数可以从游戏逻辑代码中访问，或使用[材质实例](../instanced-materials/index.md)进行覆盖。

此部分允许添加、编辑和删除自定义材质参数。每个参数都有指定的类型和默认值。材质参数由名称标识，这意味着它必须是唯一的，以防止混淆。

要添加新参数，请从下拉菜单中选择一个类型，然后按下 **添加参数** 按钮。然后你可以 **右键单击参数名称** 以重命名或删除它。

要在图中直接访问材质参数值，请使用 **获取参数**。它允许通过下拉菜单选择参数并使用其值，如下图所示。

![获取材质参数](../media/get-param.png)

### 特性

每个参数都可以具有一组可自定义的**特性**，这些特性可以自定义其在 UI 中的显示逻辑，或用作其他系统（例如序列化）的元数据。

要为参数添加特性，只需 **右键单击 -> 编辑特性**，然后使用 **+** 按钮添加新特性，将 **类型** 设置为下拉列表中的一项，调整特性的属性，然后单击 **确定** 确认。

例如，工具提示特性可用于向其他用户显示有关参数的文档说明。范围和滑块特性可以帮助自定义标量值的编辑，而编辑器组和编辑器顺序可以组织参数列表。要了解特性类型，请参阅[此页面](../../../scripting/attributes.md)。
