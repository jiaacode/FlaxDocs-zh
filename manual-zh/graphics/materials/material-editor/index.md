# 材质编辑器

![材质编辑器窗口](../media/sample-material.jpg)

**材质编辑器窗口** 是用于创建和修改材质资源的工具。它使开发者能够生成并连接材质节点以创建材质图。

本页面描述了材质创建过程背后的一些基本概念，并展示了如何使用材质编辑器。

# 打开材质编辑器

要打开材质编辑器，只需双击材质资源（在 *内容* 窗口中或在任何资源选择器控件中）。

![材质](../media/my-material.png)

# 界面

材质编辑器窗口的 UI 由工具栏、视口、属性面板和曲面图组成。

![材质编辑器](../media/material-editor-ui.jpg)

1. 工具栏
2. 视口
3. 属性面板
4. 曲面面板

## 工具栏

下表列出了工具栏中的选项及其作用。

| 图标                                                 | 描述                             |
| ---------------------------------------------------- | -------------------------------- |
| ![图标](../media/material-editor-ui-toolstrip-1.png) | 在 *内容* 窗口中显示并选择该资源 |
| ![图标](../media/material-editor-ui-toolstrip-2.png) | 将资源保存到文件                 |

| ![图标](/manual/media/material-editor-ui-toolstrip-5.png)    | 显示在线材质文档页面             |

## 视口

![视口](../media/viewport.png)

视口面板显示当前材质的预览。在材质编辑（删除节点、连接框等）过程中，材质会实时更新，所有更改都可以在视口中看到。

你可以通过使用 **鼠标右键** 在视口中导航，或按住鼠标右键并使用 **鼠标滚轮** 进行缩放。

与编辑器中的所有视口一样，此视口也带有一个 *视图* 小部件菜单。按下该按钮，你可以调试材质通道、预览不同的视图模式，甚至更改摄像机的视野角度。要了解有关使用编辑器视口和相关工具的更多信息，请阅读[调试工具](../../debugging-tools/index.md)页面。

## 属性面板

![属性](../media/material-properties.jpg)

此面板包含所有材质资源属性并允许编辑它们。

此外，面板底部有一个下拉菜单和 *添加参数* 按钮。它用于添加新的材质参数。只需从菜单中选择新参数类型，然后按下按钮即可生成新参数。

要了解有关材质属性的更多信息，请参阅专门的[材质属性](../material-properties/index.md)页面。

## 曲面

![属性](../media/material-surface.png)

材质编辑器窗口最重要的部分是 **曲面**。此面板包含属于此材质的所有材质节点的图。默认情况下，每个材质都包含一个 `Material` 节点。该节点有一系列输入，每个输入与材质的不同方面相关联（如下图所示）。

![主节点](../media/main_node.png)

要了解有关材质输入的更多信息，请参阅专门的[材质输入](../material-inputs.md)页面。

# 导航控制

材质编辑器中的控件通常与 Flax 编辑器中其他工具的控件相匹配。例如，材质节点图可以像其他链接对象编辑器一样导航，材质预览网格可以像其他网格工具一样定向，等等。

## 鼠标控制

| 控制                         | 操作                 |
| ---------------------------- | -------------------- |
| **鼠标右键** 在背景上拖动    | 平移节点图           |
| **鼠标右键** 点击背景        | 显示节点创建菜单     |
| **鼠标右键** 点击节点        | 显示节点编辑菜单     |
| **鼠标左键** 在背景上拖动    | 使用矩形工具选择节点 |
| **鼠标左键** 点击节点        | 选择节点             |
| **Ctrl + 鼠标左键** 点击节点 | 切换节点选择状态     |
| **鼠标左键** 点击节点标题    | 移动选中的节点       |
| **鼠标滚轮**                 | 缩放                 |

## 键盘控制

| 控制         | 操作                     |
| ------------ | ------------------------ |
| **Ctrl + S** | 保存资源                 |
| **Ctrl + A** | 选择所有节点             |
| **Ctrl + C** | 将选中的节点复制到剪贴板 |
| **Ctrl + V** | 从剪贴板粘贴节点         |
| **Ctrl + X** | 将选中的节点剪切到剪贴板 |
| **Ctrl + D** | 复制选中的节点           |
| **Delete**   | 删除选中的节点           |
| **Escape**   | 取消选择节点             |
| **方向键**   | 移动选中的节点           |
| **//**       | 围绕选中的节点创建注释   |

# 添加新节点

要添加新的材质节点，请右键单击曲面背景，然后从弹出菜单中选择节点类型，或输入其名称以查找它。

![添加新节点](../media/material-context-menu-1.png)
![添加新节点](../media/material-context-menu-2.png)

# 材质着色器源代码

材质编辑器窗口允许预览材质着色器的生成源代码。要查看它，请使用工具栏按钮。
