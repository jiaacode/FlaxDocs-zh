# 分层材质

![分层材质](../media/layered.png)

**分层材质** 可以描述为“材质中的材质”。此功能提供了一种将多个材质混合到单个材质中的方法。这种技术允许创建由许多 *层* 组成的材质，这在创建复杂表面或为大型项目使用共享资源数据库时提供了许多机会。

## 层

创建分层材质的最简单方法是使用 *Sample Layer* 节点来获取其他材质的属性（白色箭头连接类型）。然后使用例如 *Linear Layer Blend* 节点进行混合，该节点使用给定的 Alpha 参数在底层和顶层之间插值所有材质属性。使用专用的表面遮罩纹理有助于在层之间进行混合。

![分层材质](../media/layered-graph.jpg)

## 优势

- 降低更高级材质的复杂性
- 更简单的工作流程
- 可用于为游戏创建材质数据库（原型）
- 可以减少绘制调用（例如，为每个角色使用带有混合的单个材质）

## 注意事项

- 每个材质可能生成更多指令
- 层必须具有相同的 *领域*
- 需要使用层遮罩纹理
