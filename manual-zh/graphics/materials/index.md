# 材质

![材质](/manual/media/sample-material-instance.jpg)

**材质** 是一种资源，可以在渲染期间应用于网格，以定义对象的视觉外观。理解材质的最简单方式是将其视为覆盖对象表面的 *油漆*。但这还不是全部，因为每种单独的材质都定义了各种表面属性，例如颜色、粗糙度、金属感等。所有这些属性使美术师能够定义所需的场景外观。

从更技术的角度来说，当场景中的光线照射到表面时，材质用于计算光线如何与该表面交互。这些计算使用所有材质表面属性来完成。本节涵盖了使用材质时的所有基础知识以及更高级的主题。
