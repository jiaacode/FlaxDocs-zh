# 着色模型

Flax 支持多种**着色模型**，可用于不同的游戏对象以达到所需的外观。
最常见的选择是 **Lit** 材质类型（默认设置）。使用此页面了解有关使用其他着色模型的更多信息以及如何在游戏中使用它们。

材质着色模型可以在[材质属性](../material-properties/index.md)中更改。

![设置着色模型](media/set-shading-model.png)

## Unlit

无光照材质不使用着色算法，所有光照或反射都会被此材质忽略。无光照材质使用 **自发光** 通道作为输出颜色。它可用于执行自定义光照操作或仅发光。它不会受光照管线影响。

![无光照材质](media/unlit.png)

## Lit

默认的有光照材质是材质表面最常见的选择。它可用于定义塑料、木材、金属或玻璃表面。通过使用 **粗糙度**、**环境光遮蔽** 和 **高光** 输入，你可以定义由 BRDF 着色函数使用的微表面属性。

![有光照材质](media/lit.png)

## Subsurface

**次表面** 着色模型适用于皮肤、玉石、蜡或植被等材质。它的工作方式与 *Lit* 类似，不同之处在于它支持光线穿过材质的散射。这可以通过 **次表面颜色** 输入（定义材质内部体积的颜色）和 **不透明度** 输入（描述材质的局部厚度，值 1 表示完全不透明，值 0 表示光线可以轻松穿过）来控制。默认不透明度值为 *1*，这不会产生非常令人信服的效果。使用更接近 0 的值可以为光散射提供更多透明度（例如 `0.1`）。

![次表面材质](media/subsurface.png)

## Foliage

**Foliage** 着色模型与次表面类似，不同之处在于它是专门为植被表面（例如通常较薄的树叶和刷子）制作的。

## Custom Lit

**Custom Lit** 着色模型在着色器内提供完整的光照信息，并允许实现自定义着色。它在 GBuffer 和正向通道渲染期间都可以访问场景光照数据，因此它可用于实现[赛璐珞风格渲染](../../shaders/cel-shading.md)。

![使用 Custom Lit 的赛璐珞风格渲染](../../shaders/media/cel-shading-material.png)
