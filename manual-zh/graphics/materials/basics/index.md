# 材质基础

![图形](../media/sample-material-instance.jpg)

**材质** 定义了模型表面的外观及其对光线的反应方式。每种材质不仅描述其颜色，还描述其如何反射和发射光线。所有这些属性都由 Flax 渲染管线用于生成逼真的光照（*基于物理的渲染*）。

# 创建新材质

1. 在 *内容* 窗口中导航到 *Content* 文件夹

2. 在空白区域右键单击

3. 选择选项 *新建* -> *材质*

    ![创建新材质](../media/new-material.jpg)

4. 指定新材质名称并按 *Enter*

5. 双击材质

    ![创建新材质](../media/my-material.png)

6. 将显示[材质编辑器](../material-editor/index.md)窗口

# 材质节点

关于材质编辑，首先也是最重要的一点是它们由节点组成。每个节点生成一段 HLSL 代码。通过这种方式，连接的节点网络产生了完整材质源代码的输出。这意味着用户使用可视化脚本而不是编写代码来创建材质。

![示例材质](../media/sample-material.jpg)

上图展示了一个红木地板表面属性的示例。然而，重要的是要说明材质节点网络并不需要如此简单。在许多情况下，美术师会创建复杂的材质以达到所需的外观。

要了解有关材质编辑器的更多信息，你可以在[材质编辑器](../material-editor/index.md)部分找到更多文档。

# 使用纹理

为材质表面提供细节的最常见方式是使用**纹理**。对于材质而言，纹理只是提供某种基于像素数据的图像。这些数据可能是对象的颜色、其光泽度、透明度以及各种其他方面。有一种老派的观念认为 *纹理* 是向游戏模型应用颜色的方式。虽然创建纹理的过程仍然至关重要，但重要的是将纹理视为材质的组成部分，而不是最终结果本身。

单个材质可能出于不同目的使用几种不同的纹理。例如，一个简单的材质可能有一个漫反射颜色纹理、一个粗糙度贴图和一个法线贴图。

要在材质中使用纹理，只需将其从 *内容* 窗口拖放到材质曲面中。它将自动创建一个合适的纹理采样节点。或者，你可以创建一个新的 *纹理* 或 *法线贴图* 节点。

![示例材质](../media/texture-node.png)

要了解有关纹理管线的更多信息，你可以在[纹理](../../textures/index.md)部分找到更多文档。

# 将材质应用到模型

有几种方法可以将材质应用到模型：

- 将材质资源 *拖放* 到模型上

![应用材质](../media/apply-material-1.jpg)

- 将材质资源 *拖放* 到属性窗口中

![应用材质](../media/apply-material-2.jpg)

- 将材质分配到模型的材质槽中

![应用材质](../media/apply-material-3.jpg)

- 使用 C# 脚本设置材质

```cs
public class SetMaterial : Script
{
    [Tooltip("Material to assign to the model")]
    public Material Material;

    public override void OnStart()
    {
        Actor.As<StaticModel>().SetMaterial(0, Material);
    }
}
```
