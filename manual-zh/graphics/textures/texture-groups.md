# 纹理组

![纹理组选项](/manual/media/texture-groups.png)

**纹理组** 是引擎的一项功能，允许将一组纹理资源聚集在一起，并为它们使用共享配置。例如，用于地形的纹理（漫反射贴图、法线贴图等）可以组合在一起，以使用自定义配置进行流式传输、采样和质量缩减。这有助于在大型项目中组织游戏内容。

纹理组可用于控制纹理质量、流式传输速度以及不可见纹理的质量缩减。你还可以定义每个平台的纹理分辨率剥离，以减少游戏构建大小并提高移动或低端平台的性能。最后，纹理组可用于控制 PC 游戏的动态纹理质量，使游戏性能与 GPU 性能和可用内存相匹配（纹理质量和采样选项）。

请参阅本文档部分，了解如何使用纹理组。

## 纹理组设置

第一步是创建新的 *流式传输设置* 资源（或使用现有的）。要了解如何操作，请参阅此[教程](../../editor/game-settings/index.md)。
确保在 *游戏设置* 中设置了流式传输设置资源。

然后，将第一个纹理组添加到列表中。每个纹理组都包含多个可以在运行时（例如从游戏脚本）修改的属性。确保 **保留组的顺序**，因为资源通过索引（而不是 *名称*）来引用组。

要将纹理分配到特定的纹理组，请使用[纹理窗口](texture-window.md)编辑器（*属性* 组）或在[导入新纹理](import-settings.md)时进行分配。使用纹理组选择器来显示项目中纹理组的列表。对于非常特定的场景，你也可以在运行时通过脚本更改纹理组。

## 属性

| 属性                        | 描述                                                         |
| --------------------------- | ------------------------------------------------------------ |
| **名称**                    | 组的名称（供开发者识别组）。                                 |
| **采样器过滤**              | 使用此纹理组的采样器的默认过滤方法。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Point**</td><td>使用最近像素进行过滤。纹理看起来有像素感。</td></tr><tr><td>**Bilinear**</td><td>使用附近像素的线性平均值进行过滤。纹理看起来模糊。</td></tr><tr><td>**Trilinear**</td><td>使用附近像素和附近 Mipmap 的线性平均值进行过滤。纹理看起来模糊。</td></tr><tr><td>**Anisotropic**</td><td>使用各向异性过滤，在陡峭角度查看纹理时提高质量。在极端视角下纹理看起来清晰。</td></tr></tbody></table> |
| **最大各向异性**            | 可用于提高各向异性样本足迹质量的最大样本数。较高的值会改善纹理但降低性能。受 GPU 能力限制，仅在采样器过滤器为各向异性时使用。 |
| **质量**                    | 应用于此组纹理的质量缩放因子。可用于增加或减少纹理分辨率。范围为 0-1，其中 0 表示最低质量，1 表示完全质量。 |
| **不可见时质量**            | 当纹理在一段时间（由 TimeToInvisible 定义）内不可见时应用的质量缩放因子。用于在纹理未被渲染时降低纹理质量。 |
| **不可见时间**              | 纹理被视为不可见的时间（以秒为单位）（如果在一段时间内未被渲染）。 |
| **最小 Mip 级别**           | 此组纹理的已加载最小 Mip 级别数。定义应始终加载的 Mip 数量。较高的值会减少流式传输使用并保持更多 Mip 加载。 |
| **最大 Mip 级别**           | 此组纹理的已加载最大 Mip 级别数。定义可以加载的最大 Mip 数量。按每个平台覆盖。较低的值会降低纹理质量并提高性能。 |
| **Mip 级别偏差**            | 此组纹理的已加载 Mip 级别偏差。可用于增加或减少此组纹理的流式传输质量（例如在电影序列期间提高质量）。 |
| **每个平台的最大 Mip 级别** | 此组纹理的每个平台最大 Mip 级别数。可用于在为目标平台烘焙游戏时剥离纹理质量（仅编辑器）。 |

## 纹理流式传输质量

默认情况下，Flax 将所有已加载纹理流式传输到最高可用质量。然而，较大的场景需要更高级的配置和流式传输预算。通过使用纹理组设置并将某些纹理分配到特定组，你可以控制全局纹理质量，并定义纹理未被渲染（不可见）时的质量。

你可以通过 **图形质量窗口** 在编辑器中实时预览纹理组设置。下面的示例 GIF 显示了动态纹理质量的变化。

## 纹理采样

![带有纹理组采样器的纹理采样节点](/manual/media/sample-texture-group.png)

默认情况下，材质在对对象进行纹理处理时使用 **Trilinear Wrap** 采样器。对于自定义采样器，请在材质中使用 **Sample Texture** 节点，该节点包含选择其他采样器的选项，或使用 **来自纹理组的采样器**（选择 Texture Group 作为采样器并选择一个纹理组）。然后 *采样器过滤* 和 *各向异性* 属性将用于将采样器传递到 GPU 着色器。这些属性也可以在运行时更改（例如在过场动画期间提高纹理质量，或从游戏主菜单手动更改）。

## 每个平台的纹理质量

在创建跨平台游戏时，你可能希望为某些平台（例如 Android 或 Switch）降低纹理质量。为此，请使用 *每个平台的最大 Mip 级别* 属性，该属性允许为目标平台定义最大 Mip 级别数（按纹理组）。例如，为 *Android* 添加一个值为 *10* 的条目，将给定组的纹理质量限制为 10 个 Mip，这将纹理分辨率限制为 1024 像素（宽度或高度）。这将在烘焙游戏时应用，因此最终构建将更小且运行更快。
