# 纹理导入设置

![纹理](media/import-texture-options.jpg)

| 属性                      | 描述                                                         |
| ------------------------- | ------------------------------------------------------------ |
| **类型**                  | 指定纹理数据类型。在某些情况下，纹理可能没有 Alpha 通道或包含非常特定的数据，因此在导入和压缩期间，纹理可能会以特定方式进行处理。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**ColorRGB**</td><td>颜色纹理。使用 `RGB` 通道。推荐用于漫反射贴图。</td></tr><tr><td>**ColorRGBA**</td><td>带 Alpha 通道的颜色纹理。使用 `RGBA` 通道。推荐用于透明材质反照率或线材/链条材质。额外的 Alpha 通道可以包含打包的表面粗糙度值，以减少纹理数量。</td></tr><tr><td>**NormalMap**</td><td>法线贴图纹理。推荐用于所有切线空间法线贴图。</td></tr><tr><td>**GrayScale**</td><td>灰度纹理。使用 `R` 通道。推荐用于粗糙度/高光/高度/遮蔽贴图。</td></tr><tr><td>**HdrRGBA**</td><td>带 Alpha 通道的 HDR 颜色纹理。使用 `RGBA` 通道。推荐用于自发光贴图或其他自定义用途。</td></tr><tr><td>**HdrRGB**</td><td>HDR 颜色纹理。使用 `RGB` 通道。推荐用于天空纹理或自发光贴图。</td></tr></tbody></table> |
| **是图集**                | 如果勾选，纹理将作为纹理图集（带有精灵）导入。               |
| **从不流式传输**          | 如果勾选，将为此纹理禁用动态资源流式传输。                   |
| **压缩**                  | 如果勾选，纹理数据将被压缩以使用更少的内存。                 |
| **独立通道**              | 如果勾选，纹理通道具有独立数据（用于压缩方法）。应用于遮罩或打包纹理。 |
| **sRGB**                  | 如果勾选，纹理包含 sRGB 格式数据的颜色。                     |
| **生成 Mip 映射**         | 如果勾选，将为纹理生成完整的 Mip 映射链。                    |
| **翻转 Y**                | 如果勾选，纹理 Y 坐标将被翻转。                              |
| **缩放**                  | 自定义缩放参数。允许增加或减少导入纹理的分辨率。默认值为 1。 |
| **最大尺寸**              | 导入纹理的最大尺寸。用于裁剪过大的纹理。                     |
| **调整大小**              | 如果勾选，导入器将调整纹理大小。使用 Size 属性定义纹理的宽度和高度。纹理缩放属性将被忽略。 |
| **大小**                  | 导入纹理的尺寸。如果勾选了 *调整大小* 属性，则纹理将在导入期间调整为此值，否则将被忽略。 |
| **保留 Alpha 覆盖**       | 勾选以在生成的 Mip 中保留 Alpha 覆盖，以供 Alpha 测试参考。缩放 Mipmap Alpha 值，以基于 Alpha 测试参考值保留 Alpha 覆盖。 |
| **保留 Alpha 覆盖参考值** | Alpha 覆盖保留的参考值。仅在勾选 *保留 Alpha 覆盖* 时使用。  |
| **纹理组**                | 用于流式传输的纹理组（可选）。请参阅[纹理组](texture-groups.md)。 |
