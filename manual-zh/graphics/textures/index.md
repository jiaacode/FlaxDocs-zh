# 纹理

![纹理](media/parallax-texture.png)

**纹理** 是包含由像素数据组成的图像资源。它们主要用于材质中覆盖表面。

例如，纹理可以包含颜色信息或材质粗糙度变化，因此将其用于材质着色器可以增加更多真实感。

纹理也可以在材质之外使用。例如在 UI 中或通过直接的 CPU 计算。有关 C# 脚本的更多信息，请参阅 C# API 文档中的 [Texture](http://docs.flaxengine.com/api/FlaxEngine.Texture.html) 类页面。

## 支持的文件类型

Flax 引擎支持导入以下列表中的文件类型作为纹理：
- `.png`
- `.jpg`
- `.jpeg`
- `.bmp`
- `.gif`
- `.tga`
- `.tif`
- `.tiff`
- `.dds`
- `.hdr`
- `.raw`
- `.exr`

> [!Note]
> Flax 仅导入动画图像文件（例如动画 gif 或 PNG）的第一帧。它们在 Flax 中不会动画；它们显示为静态图像。

> [!Note]
> 有关立方体贴图纹理的文档，请查看[此页面](cube-textures.md)。

> [!Note]
> 类型为 `.RAW` 的文件假定包含 16 位灰度原始无符号归一化值，采用小端字节序（它必须是正方形，宽度等于高度）。你可以使用它们为地形导入高度图，以最大限度地减少从外部工具导出的资源生成地形时的质量损失（选择建议的 `HdrRGBA` 格式，并带 `no compression`）。

## 导入纹理

导入一个或多个纹理的最简单方法是将它们从文件 *资源管理器* 窗口（MacOS 上为 *Finder*）拖放到 *内容* 窗口。

![导入纹理](media/import-texture.jpg)

或者，你可以使用 *内容* 窗口工具栏中的 **导入** 按钮，然后选择要导入的文件。

选择文件后，将显示 **导入文件设置** 对话框。它用于为每个纹理指定导入选项。在大多数情况下，默认值即可，你只需按下 **导入** 按钮。

![导入纹理](media/import-settings-textures.jpg)

> [!Note]
> * Flax 会根据纹理名称自动检测导入的纹理类型。例如：*Chair_Normal.png* 将被检测为法线贴图，*Chair_AO.png* 将被检测为灰度纹理（因为它包含单通道环境光遮蔽数据）。
> * 使用 **导入文件设置** 对话框，你可以一次选择多个纹理（或使用 **Ctrl+A** 全选）并同时指定导入选项。

每个纹理都可以重新导入（源文件的相对路径会被缓存），并且可以使用[纹理窗口](texture-window.md)修改导入设置。

有关纹理导入设置的更多信息，请阅读专门的文档页面[纹理导入设置](import-settings.md)。

## 使用纹理

要在材质中使用纹理资源，只需将其拖放到材质曲面图中，并使用 *纹理* 节点进行采样。

![使用纹理](../materials/media/texture-node.png)

要了解有关材质和使用纹理进行渲染的更多信息，请转到[材质基础](../materials/basics/index.md)页面。

## 程序化纹理

![程序化纹理](media/cubeResult.png)

Flax API 公开了几种方法，使你能够从代码中创建和使用程序化纹理。要了解如何使用这些功能，请参阅相关教程：[如何生成程序化纹理](generate-texture.md)。

## 纹理组

Flax 支持在流式传输设置中对纹理进行分组，以便更轻松地进行纹理流式传输配置和质量选项。请参阅专门的文档页面以了解有关[纹理组](texture-groups.md)的更多信息。
