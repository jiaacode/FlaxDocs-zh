# 纹理窗口

![纹理](/manual/media/texture-window.jpg)

**纹理窗口** 是预览和重新导入纹理资源的主要工具。要访问它，只需在 *内容* 窗口中双击纹理即可。

## 界面

纹理窗口的 UI 由工具栏、视口和属性面板组成。

![纹理窗口](/manual/media/texture-editor-ui.jpg)

1. 工具栏
2. 视口
3. 属性面板

### 工具栏

下表列出了工具栏中的选项及其作用。

| 图标                                                 | 描述                             |
| ---------------------------------------------------- | -------------------------------- |
| ![图标](../../../media/editor-icons/search.png)      | 在 *内容* 窗口中显示并选择该资源 |
| ![图标](../../../media/editor-icons/import.png)      | 重新导入纹理                     |
| ![图标](../../../media/editor-icons/center-view.png) | 在曲面上显示整个材质图           |

### 视口

视口面板显示纹理的预览。你可以使用 **鼠标按钮** 在视口中导航，或使用 **鼠标滚轮** 进行缩放。

在左上角，视口包含小部件按钮。通过按下 `R/G/B/A` 按钮，你可以切换单个纹理通道的可见性。这对于调试遮罩纹理内容非常有用。你还可以使用按钮在预览中切换纹理过滤模式，在 *Point* 和 *Linear* 之间切换。此外，**Mip** 按钮可用于预览任何纹理 Mip 映射的内容。

### 属性面板

![属性](/manual/media/texture-properties.png)

此面板显示纹理信息和设置。

- **通用** 组包含有关纹理数据格式、大小和内存使用情况的信息。
- **属性** 组包含可调整的纹理选项（编辑后请确保保存资源）。
- **导入设置** 组包含纹理导入选项（从上次导入恢复）。你可以修改它们，然后按 **重新导入** 按钮从源图像文件更新资源。

要了解有关纹理导入选项的更多信息，请参阅专门的[纹理导入设置](import-settings.md)页面。
