# 操作指南：从样条线创建动态链条

在以下教程中，你将学习如何使用样条线组件创建带有物理效果的动态链条/绳索/缆绳。

## 教程

### 1. 创建样条线

按照[此](index.md)教程创建一个简单的样条线，沿一条线均匀放置大约 6-15 个点。

![样条线链](media/spline-chain-line.png)

### 2. 向样条线添加模型

在 *场景* 窗口中 *右键单击* 样条线 Actor，然后选择选项 **添加样条线模型**。这将创建一个样条线模型渲染 Actor，作为样条线的子级。它会在样条线段之间绘制模型。在此示例中，它将用于绘制链条段。

![添加样条线模型](media/add-spline-model.png)

现在，设置你想要在样条线上绘制的模型。如果你没有自己的链条/绳索/缆绳模型，可以使用内置的基本几何体之一，例如盒体或圆柱体。此外，请记住使用 **预变换** 属性来调整模型的旋转、缩放和平移，使样条线看起来符合预期。

![设置样条线模型](media/set-spline-model.png)

如果你想为样条线模型使用自定义材质，请确保**材质领域**设置为 **可变形**。这样，将使用特殊着色器来使网格沿样条曲线变形。此外，它还支持细分，以改善高度弯曲网格的模型几何体。

### 3. 向样条线添加绳索物理体

再次在 *场景* 窗口中 *右键单击* 样条线 Actor，然后选择选项 **添加样条线绳索体**。当此 Actor 作为子级添加到样条线时，它会在样条线的点上运行物理模拟。结果是一个高效的绳索模拟，可用于场景中的链条和缆绳，为其增加更多动态运动。

![添加样条线绳索体](media/add-spline-rope-body.png)

你可以自由调整绳索体的属性，例如重力、缩放或其他模拟设置。你还可以将样条线端点附加到其他 Actor，这将使两端受到约束。

### 4. 测试！

现在，点击 *播放* 按钮，看看样条线像链条一样运动，即使你在场景中移动它也是如此。
