# 贴花

![贴花](media/title.png)

**贴花** 是投影到场景对象（包括模型和动画模型）上的特殊材质。
例如，使用血迹纹理并通过贴花，你可以在玩家身体被子弹击中时将其绘制在身体上。另一个示例是在玩家行走时在沙地上渲染脚印。

## 如何创建贴花？

要了解如何创建和使用贴花，请参阅相关教程[此处](create-decal.md)。

## 性能

贴花在 *GBuffer Pass* 之后渲染，以注入自定义表面属性，例如法线向量或颜色污渍。
Flax 会收集所有贴花并进行批处理绘制，以提高引擎性能。在大多数情况下，你应该使用默认的 **排序顺序**，因为它可以提高整体性能。

贴花在屏幕空间中渲染，因此可以同时渲染大量贴花而不会大幅降低性能。性能会随着屏幕空间尺寸的增大和着色器指令数量的增加而降低。
