# 贴花

![贴花](media/decals.png)

**贴花** 是一种 Actor 类型，用于在其他对象之上投影并渲染材质。贴花使用定向包围盒来定义其体积。

## 使用方法

要了解如何设置和使用贴花，请参阅专门的教程：[如何创建贴花](create-decal.md)。

## 属性

![贴花属性](media/decal-properties.png)

| 选项                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **材质**             | 贴花材质。必须将领域模式设置为 *Decal* 类型。                |
| **排序顺序**         | 贴花渲染顺序。较高的值会在之后渲染（位于上方）。             |
| **渲染层遮罩**       | 用于渲染合成的层遮罩。可用于在绘制时包括或排除特定的 Actor 层（在其上方绘制）。 |
| **大小**             | 贴花边界大小（在局部空间中）。                               |
| **最小屏幕绘制尺寸** | 贴花绘制的最小屏幕尺寸。如果贴花在屏幕上的尺寸小于此值，则贴花将被剔除。将其设置为较高的值可使剔除更积极。 |
