# 指数高度雾

![指数高度雾](/manual/media/exponential-height-fog.png)

**指数高度雾** Actor 用于创建云层等雾效，但其密度与雾的高度相关。它渲染的雾，其密度根据高度和衰减参数呈指数增长。它支持调整雾的散射颜色、密度、起始距离和其他艺术参数。

此外，指数高度雾被[体积雾](volumetric-fog.md)使用。

## 属性

![贴花属性](/manual/media/exponential-height-fog-properties.png)

| 选项               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **雾密度**         | 雾密度因子。                                                 |
| **雾高度衰减**     | 雾高度密度因子，控制密度随高度降低而增加的方式。较小的值会产生更明显的过渡层。 |
| **雾散射颜色**     | 雾的颜色。                                                   |
| **雾最大不透明度** | 雾的最大不透明度。                                           |
| **起始距离**       | 雾从摄像机开始的距离，以世界单位为单位。                     |
| **雾截止距离**     | 超过此距离的场景元素将不会应用雾。将此值设置为 0 可禁用它。  |
| *方向内散射*       |                                                              |
| **光源**           | 用于方向内散射的方向光 Actor。                               |
| **指数**           | 控制用于近似内散射的方向内散射锥的大小。                     |
| **起始距离**       | 控制方向内散射从观察者开始的起始距离，用于近似内散射。       |
| **颜色**           | 控制方向内散射的颜色，用于近似来自方向光的内散射。           |
| *体积雾*           |                                                              |
| **启用**           | 是否启用体积雾。图形质量设置控制雾模拟的分辨率。             |
| **散射分布**       | 控制散射相位函数——入射光在不同方向上的散射程度。             |
| **反照率**         | 体积雾使用的高度雾粒子反射率。空气中的水粒子具有接近白色的反照率，而灰尘的值稍暗。 |
| **自发光**         | 高度雾发出的光。这是一个密度值，因此你透过雾看得越远，发出的光就越多。 |
| **消光缩放**       | 缩放体积雾使用的高度雾粒子消光量。大于 1 的值会导致雾粒子在所有地方吸收更多光线。 |
| **距离**           | 应计算体积雾的距离。较大的值会将效果延伸到远处，但会暴露细节中的采样不足伪影。 |
