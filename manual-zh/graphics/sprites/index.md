# 精灵

**精灵** 是包含由像素数据组成的图像的资源。它们主要用于 GUI 实现，并且可以制作动画。精灵可以是单个图像，也可以是由多个帧组成的图像。当精灵包含多个图像或帧时，它被称为精灵图集。

Flax 引擎支持导入以下列表中的文件类型作为精灵：
- `.png`
- `.jpg`
- `.jpeg`
- `.bmp`
- `.gif`
- `.tga`
- `.tif`
- `.tiff`
- `.dds`
- `.hdr`
- `.raw`
