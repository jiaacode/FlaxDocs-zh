# 天空盒

![天空盒](media/skybox.png)

使用**天空盒**可以为场景创建一个背景。典型的天空盒包含天空、云朵、山脉和其他远景。天空盒使用预渲染的立方体贴图纹理或全景纹理。

> [!Note]
> 要了解有关导入和使用立方体贴图纹理的更多信息，请参阅相关文档[此处](../../textures/cube-textures.md)。

## 属性

![天空盒属性](media/skybox-properties.jpg)

| 属性               | 描述                                         |
| ------------------ | -------------------------------------------- |
| **立方体贴图纹理** | 要绘制的立方体贴图纹理。                     |
| **全景纹理**       | 要绘制的全景纹理。其分辨率比例应接近 2:1。   |
| **自定义材质**     | 用于覆盖默认材质的自定义材质资源。           |
| **颜色**           | 天空盒纹理颜色倍增器                         |
| **曝光**           | 天空盒纹理曝光值。可用于使天空盒更亮或更暗。 |

## 全景纹理

![全景天空盒](media/skybox-panoramic-usage.png)

如果分配了全景纹理，它将被映射到球体的 360 度范围内。其分辨率比例应接近 2:1 - 经度/纬度（全景）天空盒：2:1 宽高比（例如 8192/4096、4096/2048、2048/1024）。

## 自定义天空盒材质

默认情况下，天空盒使用提供的立方体贴图纹理并对其进行采样，从而营造出 3D 环境的错觉。然而，此行为可以通过指定**自定义材质**来覆盖。自定义材质将使用球体模型进行渲染。

要创建此类材质，请确保：
* 将**剔除模式**更改为 **双面**
* 取消勾选**深度写入**选项

在 *材质窗口* 中编辑天空盒着色器时，你可以**取消勾选 显示 -> 默认场景** 以获得更好的实时预览。
