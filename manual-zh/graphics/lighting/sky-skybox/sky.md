# 天空

![天空](/manual/media/title.png)

**天空** Actor 提供了对光线穿过行星大气层的散射的近似模拟。这可以让你的户外关卡看起来更加逼真。

## 属性

![天空属性](/manual/media/sky-properties.jpg)

| 属性               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **Sun Light**      | 对将用于太阳近似的[方向光](../light-types/directional-light.md) Actor 的引用。 |
| **Sun Disc Scale** | 在天空上渲染的太阳圆盘的大小。                               |
| **Sun Power**      | 用于调整亮度的太阳强度参数。                                 |
