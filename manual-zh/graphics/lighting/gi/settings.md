# 静态光照配置

光照贴图可以使用各种参数进行配置：
* 每个光源的 **间接光照强度** - 可用于增强或减弱光源对静态光照的影响
* 每个模型/网格的 **光照贴图缩放** - 可用于增强或减弱给定对象的光照贴图质量（较高的缩放值会导致给定对象的光照贴图纹理分辨率更高）
* 每个场景的 **光照贴图烘焙设置**

# 光照图设置

![光照图设置](media/lightmap-settings.png)

选择[场景](../../../get-started/scenes/index.md) Actor 以编辑每个场景的光照贴图设置。

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **间接光照强度**     | 控制所有光源对间接光照的贡献程度。                           |
| **全局对象缩放**     | 光照贴图中对象的全局缩放，以提高质量                         |
| **图表边距**         | 光照贴图图集中图表之间的像素空间量                           |
| **图集大小**         | 单个光照贴图图集的大小（宽度和高度）                         |
| **反弹次数**         | 间接光 GI 反弹通道的数量                                     |
| **压缩光照贴图**     | 启用/禁用压缩光照贴图纹理（每个光照贴图 3 个纹理，HDR 中包含 RGBA 数据） |
| **使用无材质几何体** | 启用/禁用为缺失或材质槽为空的几何体渲染静态光照              |
| **质量**             | GI 质量（范围 [0;100]）                                      |
