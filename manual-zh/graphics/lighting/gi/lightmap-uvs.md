# 光照图 UV

为了在静态对象上使用光照贴图纹理，其几何体必须具有有效的光照贴图纹理坐标通道。许多 DDC 工具都有在模型导出期间生成此数据的选项。此外，Flax 支持在模型导入时自动生成光照贴图 UV。你可以通过将 **光照图 UV 源** 设置为 *禁用*、*生成*、*通道 0*、*通道 1*、*通道 2* 或 *通道 3* 来调整光照图纹理坐标导入方法。

## UV 预览

模型光照图 UV 可以在资源编辑器的 **UV** 选项卡下查看。为获得最佳光照贴图效果，建议在图表中添加边距并分离对象接缝（如下图所示）。

## UV 质量预览

烘焙光照的最终质量取决于光照贴图 UV 的质量、对象尺寸和[烘焙设置](settings.md)。为了识别对象上光照贴图覆盖的问题，建议使用 **光照图 UV 密度** 视图。在 *编辑器* 中，视口选项 **视图 -> 调试视图 -> 光照图 UV 密度** 可以预览光照贴图图表的密度。

颜色映射：
* *红色* - 光照贴图密度过低或无效（修复光照贴图 UV 或增加对象在光照贴图中的缩放比例）
* *绿色* - 密度良好
* *蓝色* - 光照贴图密度过高（减少对象在光照贴图中的缩放比例）
