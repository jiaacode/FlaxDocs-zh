# 环境探针

![环境探针](/manual/media/env-probe.png)

[环境探针](http://docs.flaxengine.com/api/FlaxEngine.EnvironmentProbe.html) Actor 使用立方体贴图纹理，并将其作为反射源应用到对象上。这种技术称为反射映射，在再现金属、大理石或光泽塑料等反射表面时非常有用。

## 创建新的反射探针

创建反射探针的方式与创建其他 Actor 类型类似。只需在 *场景* 窗口中右键单击 Actor 节点，然后选择选项 **新建 -> 可视化 -> 环境探针**。

![新建环境探针](/manual/media/env-probe-create.jpg)

在运行时通过脚本创建探针也是可行的，但不推荐。更好的做法是切换现有探针的可见性或修改其 **亮度** 属性以淡入或淡出。

或者，你可以使用 *工具箱* 窗口，从 **可视化** 组中将环境探针 Actor 拖放到场景中。

## 属性

![属性](/manual/media/env-probe-properties.jpg)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **盒体投影**         | 如果勾选，探针将使用盒体投影将反射映射到对象表面上。此方法更适合室内区域。 |
| **亮度**             | 控制探针反射颜色的强度。可用于淡入或淡出反射。               |
| **混合距离**         | 探针形状内部边距，在此范围内进行混合以平滑边界。             |
| **半径**             | 反射探针影响范围。                                           |
| **排序顺序**         | 探针渲染顺序。值较高的会较晚渲染（位于上方）。               |
| **捕获近平面**       | 定义用于渲染探针的近裁剪平面。使用较高的值可裁剪探针附近的几何体。 |
| **自定义探针**       | 如果指定，环境探针将使用自定义的 [CubeTexture](http://docs.flaxengine.com/api/FlaxEngine.CubeTexture.html) 作为反射源。 |
| **捕获偏移**         | 在捕获之前应用的探针位置偏移，可用于调整反射。               |
| **更新模式**         | 探针更新模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Manual**</td><td>探针可以手动更新（例如在编辑器中或从脚本更新）。</td></tr><tr><td>**When Moved**</td><td>探针移动时将自动更新。</td></tr><tr><td>**Realtime**</td><td>探针将实时自动更新（仅在视图中且频率取决于到摄像机的距离）。</td></tr></tbody></table> |
| **立方体贴图分辨率** | 反射纹理分辨率。可以使用图形设置或自定义分辨率。             |

要捕获反射探针周围的场景，请按下 **烘焙** 按钮。它将场景在 6 个方向上的渲染结果渲染到立方体贴图中并进行过滤。在反射探针渲染期间，只有启用了 [StaticFlags.ReflectionProbe](http://docs.flaxengine.com/api/FlaxEngine.StaticFlags.html) 的 Actor 才可见。

**视图** 按钮可用于检查立方体贴图资源。

更新的环境探针立方体贴图纹理存储在 *SceneData* 文件夹中。要了解有关场景数据的更多信息，请参阅下面的 `场景数据存储` 部分。

## 混合

![反射混合](/manual/media/env-probe-blending.png)

Flax 引擎使用屏幕空间着色器通过专用通道将反射探针渲染到专用缓冲区中。然后它将最终的反射颜色混合到光照缓冲区中。这提供了执行高质量 **逐像素反射颜色混合** 的机会。渲染从绘制半径最大的探针开始，然后移动到较小的探针（**探针按半径排序**）。这可以通过 `排序顺序` 属性覆盖，以使艺术家对照明有更多控制权。反射颜色也会在探针边界边缘淡出。这会导致平滑过渡并减少任何闪烁——尤其是对于在场景中快速移动的动态对象。

## 场景数据存储

默认情况下，Flax 使用专用的内容目录来存储 **场景数据资源**。它被光照贴图、CSG 网格以及环境探针使用。反射探针的立方体贴图纹理位于：**Content/SceneData/'场景名称'/EnvProbes**。如果你想重用烘焙的反射探针或修改它，你可以在该位置访问纹理。此外，环境探针 Actor 包含一个专用的公共属性 [EnvironmentProbe.Probe](http://docs.flaxengine.com/api/FlaxEngine.EnvironmentProbe.html#FlaxEngine_EnvironmentProbe_Probe)，可用于访问正在使用的立方体贴图纹理。

要了解有关场景资源的更多信息，请参阅[场景数据存储](../../../get-started/scenes/scene-data.md)页面。

## 实时探针

探针可以在运行时通过脚本使用，或每帧自动使用。这可以用于以性能为代价实现动态环境反射。请确保限制频繁更新的探针数量，并调整分辨率以保持稳定的性能。
