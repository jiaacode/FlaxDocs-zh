# 光源类型

![光源类型](media/lights.png)

Flax 支持 4 种不同类型的光源：

- **方向光**
- **点光源**
- **聚光灯**
- **天光**

每种光源类型都有略微不同的用途和各自的一组属性。本节涵盖了它们的详细信息，并描述了如何在场景中使用光源。

## 本节内容

* [方向光](directional-light.md)
* [点光源](point-light.md)
* [聚光灯](spot-light.md)
* [天光](sky-light.md)

## 可视化

![光源调试](media/lights-debug.png)

Flax 编辑器提供了内置选项，可以直接在编辑器视口中调试 *光照缓冲区* 的内容。为此，请单击 **视图** 小部件，然后选择 **调试视图 -> 光照缓冲区** 选项。这将更改视图模式。要还原，请选择 *默认* 选项。

![光源调试](media/lights-debug-option.jpg)

> [!Note]
> 要了解有关 *调试视图* 和其他调试工具的更多信息，请参阅相关页面[此处](../../debugging-tools/debug-view.md)。
