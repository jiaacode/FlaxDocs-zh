# 天光

![天光](media/sky-light.png)

**天光** 绘制由[天空盒](../sky-skybox/skybox.md)、[天空](../sky-skybox/sky.md)或场景其他远处部分发出的环境光。它有助于[基于图像的光照（Wikipedia）](https://en.wikipedia.org/wiki/Image-based_lighting)。

对于室外场景（可以看到大量天空）来说，天光是一个非常好的选择。在底层，天光使用[立方体贴图纹理](../../textures/cube-textures.md)并对其进行采样（低 mip 级别），以模拟逼真的方向辐照度。天光可以使用自定义纹理或烘焙纹理。要更新捕获，请按下对象属性下的 **烘焙** 按钮。

## 光照属性

![天光属性](media/sky-light-properties-1.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **颜色**     | 光的发射颜色。                                               |
| **附加颜色** | 要添加的附加光颜色。源纹理颜色会与其相加。可用于应用自定义环境颜色。 |
| **半径**     | 光照范围（以世界单位为单位）。使用非常高的值可将光全局应用。 |
| **亮度**     | 光亮度参数。控制此 Actor 发出的光强度。                      |
| **视距**     | 控制光的可见范围。光完全淡出的距离。使用值 0 可始终绘制光。  |

## 探针属性

![天光属性](media/sky-light-properties-2.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **模式**         | 定义天光光源模式。可能的选项：                               |
| **天空距离阈值** | 距离光一定距离时，任何几何体都应被视为天空的一部分（以世界单位为单位）。 <br>可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**捕获场景**</td><td>捕获的场景将用作光源。</td></tr><tr><td>**自定义纹理**</td><td>自定义立方体贴图纹理将用作光源。</td></tr></tbody></table> |
| **自定义纹理**   | 自定义光照纹理。仅在 *模式* 设置为 *自定义纹理* 时使用。     |

如果 **模式** 设置为 **捕获场景**，则使用 **烘焙** 按钮更新捕获的图像。

> [!Note]
> 要了解有关 Flax 中立方体贴图纹理的更多信息，请参阅[此页面](../../textures/cube-textures.md)。

## 体积雾属性

![天光属性](media/volumetric-fog-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **散射强度** | 控制此光对[体积雾](../../fog-effects/volumetric-fog.md)的贡献程度。设置为 0 时，没有贡献。 |
| **投射阴影** | 如果勾选，光将为[体积雾](../../fog-effects/volumetric-fog.md)投射体积阴影。此外，应为此光启用阴影投射，以使其投射体积雾阴影。 |

> [!Note]
> 要了解有关体积雾效果的更多信息，请参阅[此页面](../../fog-effects/volumetric-fog.md)。
