# 点光源

![点光源](/manual/media/point-light.png)

**点光源** 从单个点向所有方向发射光线。点光源适用于模拟局部光源，例如灯具和灯泡。

## 光照属性

![点光源属性](/manual/media/point-light-properties.jpg)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **半径**             | 光照范围（以世界单位为单位）。                               |
| **源半径**           | 光源构造源半径（以世界单位为单位）。                         |
| **源长度**           | 光源构造源长度（以世界单位为单位）。                         |
| **衰减指数**         | 控制光照的径向衰减。仅当选项 *使用平方反比衰减* 被禁用时生效。 |
| **使用平方反比衰减** | 如果勾选，将使用基于物理的平方反比距离衰减。                 |
| **颜色**             | 光的发射颜色。                                               |
| **亮度**             | 光亮度参数。控制此 Actor 发出的光强度。                      |
| **视距**             | 控制光的可见范围。光完全淡出的距离。使用值 0 可始终绘制光。  |
| **最小粗糙度**       | 控制着色期间用于限制材质表面粗糙度的最小粗糙度值。有助于柔化高光。 |

## 区域光

通过使用 **源半径** 和 **源长度** 属性，你可以更改点光源的构造尺寸。这允许模拟区域光并为场景带来更多真实感。

![区域光](/manual/media/area-lights.png)

## 光照衰减

![光照衰减](/manual/media/light-fall-off.png)

Flax 为光照衰减提供了两种模式。可以使用自定义的 **指数** 参数，或使用 **平方反比衰减** 模式。平方反比模式提供更基于物理的距离衰减，其中 **半径** 仅用于限制光照的贡献。然而，使用手动光照衰减指数提供了更多的自定义选项。

## 阴影属性

![点光源属性](/manual/media/shadow-light-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **模式**         | 描述视觉元素投射阴影的方式。可能的选项：<br><table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**None**</td><td>从不渲染阴影。</td></tr><tr><td>**Static Only**</td><td>仅在静态视图中渲染阴影（环境探针、光照贴图等）。</td></tr><tr><td>**Dynamic Only**</td><td>仅在动态视图中渲染阴影（游戏、编辑器等）。</td></tr><tr><td>**All**</td><td>始终渲染阴影。</td></tr></tbody></table> |
| **锐度**         | 控制阴影锐度。可用于调整半影宽度。                           |
| **强度**         | 控制动态阴影混合强度。默认值为 1，表示完全不透明阴影；值为 0 则禁用阴影。 |
| **距离**         | 阴影渲染距离（以世界单位为单位）。                           |
| **淡出距离**     | 阴影淡出距离（以世界单位为单位）。                           |
| **深度偏差**     | 控制动态阴影深度偏差值。深度偏差用于阴影贴图比较。           |
| **法线偏移缩放** | 控制动态阴影法线向量偏移缩放。一个因子，指定相对于表面法线添加到计算的阴影贴图深度的偏移量。 |
| **接触阴影长度** | 通过屏幕空间追踪计算的接触阴影的光线长度。将此值设置为大于 0 可为此光源启用屏幕空间阴影渲染。这改善了阴影细节。实际光线距离基于像素到摄像机的距离。 |
| **更新率**       | 阴影更新的频率。1 - 每帧更新，0.5 - 每两帧更新，0 - 启动或更改时更新。它是阴影贴图更新之间应发生的帧数的倒数（例如，0.5 的倒数是 2，因此阴影将每两帧更新一次）。 |
| **距离更新率**   | 在阴影仍被渲染的视图最大距离处的阴影更新频率。此值乘以 *阴影更新率*，允许在阴影范围内缩放更新率。例如，如果光靠近视图，它将获得正常的阴影更新，但在远离视图时会降低此速率。 |
| **分辨率**       | 定义用于从光源视角绘制对象投影的阴影贴图纹理的分辨率。较高的值会提高阴影质量，但会牺牲性能。 |

> [!Note]
> 要了解有关 Flax 中阴影的更多信息，请参阅[此页面](../shadows.md)。

## 体积雾属性

![点光源属性](/manual/media/volumetric-fog-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **散射强度** | 控制此光对[体积雾](../../fog-effects/volumetric-fog.md)的贡献程度。设置为 0 时，没有贡献。 |
| **投射阴影** | 如果勾选，光将为[体积雾](../../fog-effects/volumetric-fog.md)投射体积阴影。此外，应为此光启用阴影投射，以使其投射体积雾阴影。 |

> [!Note]
> 要了解有关体积雾效果的更多信息，请参阅[此页面](../../fog-effects/volumetric-fog.md)。

## IES 光分布文件属性

![点光源属性](../media/ies-properties.jpg)

| 属性              | 描述                                                         |
| ----------------- | ------------------------------------------------------------ |
| **IES 纹理**      | 分配的 IES 纹理（来自现实世界测量数据的光分布文件）。在此了解更多信息[此处](../ies-profiles.md)。 |
| **使用 IES 亮度** | 如果勾选，光的亮度将基于导入的 IES 光分布文件亮度。然后使用 *亮度缩放* 参数进行缩放。 |
| **亮度缩放**      | 如果勾选 *使用 IES 亮度* 选项，则用于光亮的自定义缩放参数。  |

> [!Note]
> 要了解有关 IES 光分布文件的更多信息，请参阅[此页面](../ies-profiles.md)。
