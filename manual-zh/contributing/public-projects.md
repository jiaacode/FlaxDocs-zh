* # 公开项目

  Flax 引擎具有很强的可扩展性，允许开发人员在引擎的任何领域创建自定义解决方案。你可以在社区项目部分看到许多此类项目。此外，下面列出了官方维护的插件和项目，以便更快地启动开发。

  > [!Tip]
  > 如果你正在使用 Flax 创建插件或开源项目，请通过提交 PR 来告知我们，我们将添加到此页面！

  ## 官方项目

  * [Arizona Framework](https://github.com/FlaxEngine/ArizonaFramework) - 用于在 Flax 中创建游戏的开源框架
  * [Arizona Framework Sample](https://github.com/FlaxEngine/ArizonaFrameworkSample) - 使用 Arizona Framework 的开源示例多人游戏
  * [NVIDIA DLSS](https://github.com/FlaxEngine/DLSS) - 适用于 Flax 引擎的 NVIDIA DLSS
  * [FidelityFX FSR](https://github.com/FlaxEngine/FidelityFX-FSR) - 适用于 Flax 引擎的 AMD FidelityFX 超分辨率
  * [Online Platform Steam](https://github.com/FlaxEngine/OnlinePlatformSteam) - 适用于 Flax 引擎的 Steam
  * [Online Platform Xbox Live](https://github.com/FlaxEngine/OnlinePlatformXboxLive) - 适用于 Flax 引擎的 Xbox Live
  * [Network Sample](https://github.com/FlaxEngine/NetworkSample) - 包含玩家同步和聊天的多人游戏大厅示例
  * [Flax Samples](https://github.com/FlaxEngine/FlaxSamples) - Flax 引擎的示例项目集合
  * [Example Plugin](https://github.com/FlaxEngine/ExamplePlugin) - Flax 的示例插件
  * [Dear ImGui](https://github.com/FlaxEngine/ImGui) - 适用于 Flax 引擎的 Dear ImGui
  * [Flax Web Racing](https://github.com/FlaxEngine/FlaxWebRacing) - Flax 引擎中的街机赛车游戏

  ## 社区项目

  * [Character Controller Pro](https://github.com/PrecisionRender/CharacterControllerPro) - 适用于 Flax 的全功能模块化角色控制器
  * [Flax Voxels](https://github.com/Erdroy/FlaxVoxels) - Flax 引擎的体素地形
  * [Auto Import Resources Plugin](https://github.com/FlaxCommunityProjects/flax-auto-import-resources-plugin) - 自动将 `Assets` 文件夹中的所有内容导入到 `Content/Imported`
  * [Flax Unit Testing](https://github.com/FlaxCommunityProjects/FlaxUnitTesting) - 适用于 Flax 引擎的简单单元测试插件
  * [Flax Collaborate](https://github.com/FlaxCommunityProjects/FlaxCollaborate) - 允许多人同时编辑同一场景的插件
  * [Flax Custom Visject Plugin](https://github.com/FlaxCommunityProjects/flax-custom-visject-plugin) - 带插件的自定义 Visject 曲面
  * [Volumetric Clouds](https://github.com/lb2110/VolumetricClouds) - 适用于 Flax 引擎的基础体积云着色器和 Worley 噪声生成器
  * [FTween](https://github.com/honzapatCZ/FTween/) - 易于使用的 Flax 补间动画库
  * [UE4 Content Importer](https://github.com/chicken-with-lips/flax-plugin-ue4-utilities) - Flax 引擎的 UE4 转换器
  * [Journal](https://github.com/Crawcik/Journal) - 带命令处理的 Flax 引擎控制台
  * [Flax Plugin Manager](https://github.com/Crawcik/FlaxPluginManager) - Flax 插件管理器和工具
  * [Flax Csgjs](https://github.com/FlaxCommunityProjects/FlaxCsgjs/) - 适用于 Flax 引擎的 `csg.js` 和 `earcut` 移植
  * [Flax VR](https://github.com/FlaxCommunityProjects/FlaxVR) - 适用于 Flax 引擎的基础 VR 模块
  * [Flax CLI](https://github.com/W2Wizard/FlaxCLI) - 提供命令行界面工具
  * [Flax Voxel Terrain](https://github.com/FlaxCommunityProjects/FlaxVoxelTerrain) - 基础体素地形项目
  * [Flax Space Fighter Demo](https://github.com/FlaxCommunityProjects/FlaxSpaceFighterDemo) - Flax 引擎的太空战机演示
  * [Flax Object Pool](https://github.com/DevHrytsan/FlaxObjectPool) - 回收和重用对象以提高性能
  * [FlaxCustomAttributes](https://github.com/FlaxCommunityProjects/FlaxCustomAttributes) - 用于编辑器的自定义 C# 特性使用工具
  * [HeroCrab Plugin](https://github.com/herocrab/HeroCrabPlugin) - 用于多人游戏的权威网络消息框架
  * [RmlUi](https://github.com/GoaLitiuM/RmlUi) - HTML/CSS 用户界面库 `RmlUi` 的封装（[示例](https://github.com/GoaLitiuM/FlaxRmlUiSamples)）
  * [Flax FMOD](https://github.com/Tryibion/FlaxFmod) - FMOD 音频库集成
  * [Flax Simple Save System](https://github.com/Tryibion/FlaxSimpleSaveSystem) - 包含存档槽、加密、哈希和数据缓存的存档系统
  * [Audio Reactor](https://github.com/holdulv-2nd/AudioReactor) - 使用 NAudio 实现实时音频可视化，将游戏世界（灯光、摄像机、UI、对象）与节拍同步。
