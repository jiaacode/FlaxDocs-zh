### Flax 引擎

主仓库 [Flax Engine](https://github.com/FlaxEngine/FlaxEngine) 包含了 Flax 引擎和 Flax 编辑器的完整源代码，以及所有工具和平台支持。你可以 fork 它并按需编辑。修改后的引擎和/或编辑器可以用于 Flax 游戏开发，因此拥有对引擎的更多控制权会非常方便。同时，也欢迎任何 pull request。

GitHub 上提供的仓库是我们内部 Git 仓库的镜像，托管在 [https://gitlab.flaxengine.com/flax/flaxengine](https://gitlab.flaxengine.com/flax/flaxengine)（镜像每 5 分钟更新一次）。我们使用内部的 LFS 服务器来托管大型二进制文件。该仓库包含一个 `.lfsconfig` 文件以确保 LFS 正常工作，但如果你在推送更改到 fork 时遇到问题，请尝试使用 `git push --no-verify` 或迁移到你自己的 LFS 服务器。

如果你想在 Visual Studio 中打开 Flax 引擎，可能需要安装 [Flax Engine Tools for Visual Studio](https://marketplace.visualstudio.com/items?itemName=Flax.FlaxVS) 扩展（1.6 及以上版本不需要）。
