# 编辑器样式

Flax 编辑器支持通过编辑器选项编辑默认 UI 样式、颜色和字体。要自定义外观，请打开主菜单 **工具 -> 选项**。

## 字体

![自定义编辑器字体](/manual/media/editor-custom-font.png)

打开 **界面** 选项卡，在 **字体** 部分，你可以调整编辑器 UI 使用的字体资源和字体大小。你也可以调整编辑器特定部分（例如调试日志、输出日志）的视觉效果。
要查看更改，请重新启动编辑器。

## 主题

打开 **主题** 选项卡，在 *样式* 子组中添加新项目。然后双击标签，将其从 *Key* 重命名为你的名称。然后保存资源，单击主题预览以编辑它。

![主题编辑器](/manual/media/editor-theme-preview.png)

要预览更改，请点击 **确定**，将 **选定样式** 设置为你的新条目，**保存** 资源并 **重新启动编辑器**。

![自定义编辑器主题](/manual/media/custom-editor-theme.png)

你可以通过将 *选定样式* 上的 *Default* 选项设置回来，来恢复默认主题。
