# 编辑器界面

![Flax 编辑器界面](../get-started/media/flax-layout.png)

Flax 编辑器的界面由**可停靠窗口**组成，这些窗口可以重新排列、分组、分离和停靠。
你可以通过选择并拖动窗口标题栏来拖拽和排列窗口。这在根据你的需求调整工作区时非常有用。Flax 编辑器会在关闭时（以及每隔几秒）保存窗口布局（每个项目），以便在重新启动时恢复。

用于更快导航的实用快捷键：
* **Ctrl + Tab** - 下一个选项卡
* **Ctrl + Shift + Tab** - 上一个选项卡
* **Ctrl + W** - 关闭选项卡
* **Ctrl + O** - 查找器工具，可导航到任何内容

## 主要窗口

默认布局包含一组最重要的元素：
* [视口](windows/viewport.md) - 显示游戏视图。用于导航和编辑场景。
* [内容窗口](windows/content-window.md) - 显示项目资源。用于创建和管理你的资源。
* [场景窗口](windows/scene-window.md) - 显示场景 Actor 层级。用于查看和修改场景结构。
* [属性窗口](windows/properties-window.md) - 显示选定对象的属性。用于查看和编辑场景对象（脚本、Actor）。
* [工具箱](windows/toolbox.md) - 提供用于编辑场景的有用工具。用于生成对象、绘制模型和创建地形。
* [工具栏](windows/toolbar.md) - 提供对基本编辑器功能的访问。用于快速测试你的游戏或一键保存更改。

## 默认布局

![Flax 编辑器布局](media/restore-layout.jpg)

始终可以通过使用主菜单选项 **窗口 -> 恢复默认布局** 来恢复默认窗口布局。
