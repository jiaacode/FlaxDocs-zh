# 时间设置

时间设置资源描述了时间管理器的初始值。
通过调整这些值，你可以为游戏调整合适的 FPS 或物理模拟质量。
你可以使用 [Time](https://docs.flaxengine.com/api/FlaxEngine.Time.html) 服务访问和编辑此设置。

## 属性

![Flax 时间设置](/manual/media/time-settings.png)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **更新 FPS**         | 每秒游戏逻辑更新的目标次数（脚本更新频率）。                 |
| **物理 FPS**         | 每秒物理模拟更新的目标次数（也是固定更新频率）。             |
| **绘制 FPS**         | 每秒渲染帧的目标次数（实际游戏 FPS）。                       |
| **时间缩放**         | 游戏时间缩放因子。默认值为 1。                               |
| **最大更新增量时间** | 游戏逻辑更新步骤允许的最大增量时间（以秒为单位）。           |
| **失焦最大 FPS**     | 当应用程序窗口失去焦点时限制最大游戏帧率。使用 0 可禁用此功能。 |
| **失焦暂停**         | 当应用程序窗口失去焦点时启用暂停游戏。                       |
