# 构建设置

构建设置资源指定了 Game Cooker 的选项，并包含一组游戏构建预设。
有关编辑和使用预设的信息，请参阅 [Game Cooker 窗口](../game-cooker/index.md)，因为它具有更好的界面来完成此操作。

## 属性

![Flax 构建设置](media/build-settings.jpg)

| 属性                               | 描述                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| **输出名称**                       | 由构建系统创建的输出应用程序的名称。用于重命名主可执行文件（例如 `MyGame.exe`）或最终包名称（例如 `MyGame.apk`）。自定义令牌：`${PROJECT_NAME}`、`${COMPANY_NAME}`。 |
| **每个包的最大资源数**             | 要包含到单个资源包中的最大资源数量。如果需要，资源将被拆分到多个包中。 |
| **最大包大小（以 MB 为单位）**     | 单个资源包的最大大小（以兆字节为单位）。如果需要，资源将被拆分到多个包中。 |
| **内容密钥**                       | 游戏内容烘焙密钥。为游戏和 DLC 包使用相同的值，以支持由构建后的游戏加载它们。使用 0 可在构建期间随机生成。 |
| **用于分发**                       | 如果勾选，Game Cooker 生成的构建将被视为用于最终游戏分发（例如用于游戏商店上传）。以这种方式进行的构建无法在主机开发套件（例如 Xbox One、Xbox Scarlett）上进行测试。 |
| **跳过打包**                       | 如果勾选，输出构建文件将不会为目标平台打包。在从本地 PC 调试构建时非常有用。 |
|                                    |                                                              |
| **附加资源**                       | 要包含到构建中的附加资源（放入根资源集中）。                 |
| **附加场景**                       | 要包含到构建中的附加场景（放入根资源集中）。                 |
| **附加资源文件夹**                 | 要包含到构建中的包含资源的附加文件夹（放入根资源集中）。相对于项目目录或绝对路径的路径列表。 |
|                                    |                                                              |
| **着色器不优化**                   | 在已烘焙游戏中禁用着色器编译器优化。可用于在目标平台上调试着色器或加快着色器编译时间。 |
| **着色器生成调试数据**             | 在已烘焙游戏中为着色器启用着色器调试数据生成（取决于目标平台渲染后端）。 |
| **跳过默认字体**                   | 如果勾选，跳过捆绑 UI 的默认引擎字体。如果你不使用默认引擎字体而仅使用自定义字体，则使用此选项以减小构建大小。 |
| **最大网格位置误差**               | 数据量化的最大可接受网格顶点位置误差（以世界单位为单位）。使用 `0` 可禁用此功能。在导入（或重新导入）期间影响网格。 |
|                                    |                                                              |
| **跳过 .NET 运行时打包**           | 如果勾选，.NET 运行时将不会与游戏打包在一起，并且在运行游戏构建时，用户需要在系统上安装它。仅在 Windows、Linux 和 macOS 等支持的平台上可用。 |
| **跳过未使用的 .NET 运行时库打包** | 如果勾选，.NET 运行时打包将跳过打包未使用的库，从而减小游戏构建的大小。 |
|                                    |                                                              |
| **预设**                           | 构建[预设](https://docs.flaxengine.com/api/FlaxEditor.Content.Settings.BuildPreset.html)。 |
