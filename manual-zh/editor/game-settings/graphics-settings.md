# 图形设置

图形设置资源指定了初始渲染质量和其他与图形相关的选项。
你可以在运行时使用 [GraphicsQuality](https://docs.flaxengine.com/api/FlaxEngine.GraphicsQuality.html) 服务更改其中的大多数值，或使用编辑器中用于编辑图形质量的专用窗口（从 *主菜单* 选择 **窗口 -> 图形质量** 选项）。

## 属性

![Flax 图形设置](/manual/media/graphics-settings.png)

| 属性                       | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **使用垂直同步**           | 启用与显示设备刷新率的渲染同步，以避免“撕裂”伪影。           |
|                            |                                                              |
| **抗锯齿质量**             | 抗锯齿质量设置。                                             |
| **屏幕空间反射质量**       | 屏幕空间反射质量。                                           |
| **屏幕空间环境光遮蔽质量** | 屏幕空间环境光遮蔽质量设置。                                 |
| **体积雾质量**             | 体积雾质量设置。                                             |
| **阴影质量**               | 阴影质量。                                                   |
| **阴影贴图质量**           | 阴影贴图质量（纹理分辨率）。                                 |
| **允许 CSM 混合**          | 为方向光阴影启用级联分割混合。                               |
| **默认探针分辨率**         | 默认探针立方体贴图分辨率（用于环境探针，可以按每个 Actor 覆盖）。推荐默认值为 `128x128`。对于移动平台，尝试使用较低分辨率以获得更高性能。 |
| **使用 HDR 探针**          | 如果勾选，环境探针将使用 HDR 纹理格式。在非常明亮的场景中以较高的内存使用为代价提高质量。 |
|                            |                                                              |
| **启用全局 SDF**           | 如果勾选，启用全局 SDF 渲染。这可以在材质、着色器和粒子中使用。 |
| **全局 SDF 距离**          | 全局 SDF 的绘制距离。使用 DDGI 时实际值可能较大。            |
| **全局 SDF 质量**          | 全局 SDF 质量。控制体积纹理分辨率和要使用的级联数量。        |
| **导入模型时生成 SDF**     | 如果勾选，默认情况下模型导入选项中的 `Generate SDF` 选项将被勾选。如果你的项目使用全局 SDF（例如用于全局光照或粒子），请使用此选项。 |
|                            |                                                              |
| **全局光照质量**           | 全局光照质量。控制 GI 效果的质量。                           |
| **全局光照探针间距**       | 全局光照探针间距距离（以世界单位为单位）。定义 GI 分辨率的质量。调整为 200-500 以改善性能并降低低频 GI 数据。 |
| **全局光照级联混合**       | 为全局光照启用级联分割混合。                                 |
| **全局表面图集分辨率**     | 全局表面图集分辨率。如果图集因溢出而“闪烁”，请调整它（例如调整为 4096）。 |
|                            |                                                              |
| **伽马色彩空间**           | 如果勾选，色彩空间工作流将使用 Gamma 而不是 Linear。Gamma 色彩空间使用应用的伽马曲线（sRGB）定义颜色，因此它们在感知上是线性的。当渲染的输出表示将呈现给非 HDR 屏幕的最终颜色值时，这是有意义的。 |
| **渲染颜色格式**           | 渲染管线使用的像素格式（用于光照缓冲区和后期处理）。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**R11G11B10**</td><td>HDR 32 位缓冲区，不支持 Alpha 通道。提供良好的性能，但由于数据精度较低，可能导致颜色条纹或向偏黄颜色偏移。</td></tr><tr><td>**R8G8B8A8**</td><td>LDR 32 位缓冲区，支持 Alpha 通道。提供良好的性能，但不支持高动态范围渲染。</td></tr><tr><td>**R16G16B16A16**</td><td>HDR 64 位缓冲区，支持 Alpha 通道。为广泛的颜色范围提供非常好的质量，但需要更多内存。</td></tr></tbody></table> |
|                            |                                                              |
| **回退字体**               | 用于文本渲染的回退字体列表。如果为空则忽略。                 |
|                            |                                                              |
| **后期处理设置**           | 默认后期处理设置。可以由关卡中的 PostFxVolume 在本地、按摄像机或整个地图覆盖。 |
