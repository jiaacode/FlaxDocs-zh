# 流式传输设置

流式传输设置资源包含用于流式传输系统的资源配置，例如纹理组，即用于纹理流式传输的列表。

## 属性

![Flax 纹理流式传输设置](media/streaming-settings.jpg)

| 属性       | 描述                                                         |
| ---------- | ------------------------------------------------------------ |
| **纹理组** | 纹理流式传输配置（按组）。请参阅[纹理组](../../graphics/textures/texture-groups.md)文档以了解更多信息。 |
