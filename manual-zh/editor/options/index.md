# 编辑器选项

编辑器选项窗口允许查看和修改编辑器使用的设置。编辑器选项保存在本地用户缓存文件夹中，并在所有已安装的 Flax 编辑器实例之间全局共享。通过调整设置，你可以根据需求自定义 Flax 编辑器。

## 打开选项窗口

![打开编辑器选项](media/open-options.png)

要打开编辑器选项窗口，请使用主菜单按钮 **工具 -> 选项**。

## 使用方法

你可以修改属性，然后按下工具栏上的 **保存** 图标以应用更改。如果要恢复给定类别的设置，请按 **重置** 按钮。

## 常规选项

![常规选项](media/options-general.png)

| 属性                                 | 描述                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| **启动场景模式**                     | 编辑器启动时加载的场景。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**无**</td><td>启动时不打开场景。</td></tr><tr><td>**项目默认**</td><td>项目默认场景。</td></tr><tr><td>**上次打开的**</td><td>编辑器中上次打开的场景。</td></tr></tbody></table> |
| **撤销操作容量**                     | 编辑器撤销操作的次数限制。较高的值可能增加内存使用，但也会增加更改回滚历史长度。 |
| **主窗口获得焦点时自动重载脚本**     | 确定在主窗口获得焦点时是否在更改后重载脚本。                 |
| **启动时强制编译脚本**               | 确定是否在启动编辑器之前自动编译游戏脚本。                   |
| **启动运行模式时自动保存可视化脚本** | 确定在编辑器中启动运行模式时是否自动保存可视化脚本资源编辑器。 |
| **自动重建 CSG**                     | 确定在画笔更改时是否执行自动 CSG 重建。                      |
| **自动重建 CSG 超时**                | 自动 CSG 重建超时（以毫秒为单位）。使用较低的值可获得更频繁和响应更快的更新，但复杂度更高。 |
| **自动重建导航网格**                 | 确定在场景更改时是否执行自动导航网格重建。                   |
| **自动重建导航网格超时**             | 自动导航网格重建超时（以毫秒为单位）。使用较低的值可获得更频繁和响应更快的更新，但复杂度更高。 |
| **启用自动保存**                     | 启用或禁用对已编辑场景和内容的自动保存更改。                 |
| **自动保存频率**                     | 自动保存之间的间隔（以分钟为单位）。                         |
| **自动保存场景**                     | 启用或禁用对已打开场景的自动保存。                           |
| **自动保存内容**                     | 启用或禁用对内容的自动保存。                                 |
| **启用编辑器分析**                   | 启用或禁用匿名的编辑器分析服务，该服务用于改善编辑器体验和质量。 |

## 界面选项

![界面选项](media/options-interface.png)

| 属性                           | 描述                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| *界面*                         |                                                              |
| **界面缩放**                   | 编辑器用户界面缩放。应用于所有 UI 元素、窗口和文本。可用于在更大的显示器上放大界面。需要重启编辑器。 |
| **使用原生窗口系统**           | 确定是否使用原生窗口标题栏。需要重启编辑器。                 |
| **显示选中的摄像机预览**       | 确定是否在编辑窗口中显示选中的摄像机预览。                   |
| **游戏窗口获得焦点时居中鼠标** | 确定在运行模式下窗口获得焦点时是否居中鼠标位置。在处理锁定鼠标光标的游戏时很有帮助。 |
| **调试日志时间戳格式**         | 调试日志消息的时间戳前缀模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**无**</td><td>无前缀。</td></tr><tr><td>**UTC**</td><td>UTC 时间格式。</td></tr><tr><td>**本地时间**</td><td>本地时间格式。</td></tr><tr><td>**启动后经过时间**</td><td>自启动以来的时间（以秒为单位）。</td></tr></tbody></table> |
| *输出日志*                     |                                                              |
| **时间戳格式**                 | 输出日志消息的时间戳前缀模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**无**</td><td>无前缀。</td></tr><tr><td>**UTC**</td><td>UTC 时间格式。</td></tr><tr><td>**本地时间**</td><td>本地时间格式。</td></tr><tr><td>**启动后经过时间**</td><td>自启动以来的时间（以秒为单位）。</td></tr></tbody></table> |
| **显示日志类型**               | 确定是否在输出日志消息中显示日志类型前缀。                   |
| **文本字体**                   | 输出日志文本字体。                                           |
| **文本颜色**                   | 输出日志文本颜色。                                           |
| **文本阴影颜色**               | 输出日志文本阴影颜色。                                       |
| **文本阴影偏移**               | 输出日志文本阴影偏移。设置为 0 可禁用此功能。                |
| *编辑器内运行*                 |                                                              |
| **运行时聚焦游戏窗口**         | 确定在运行模式启动时是否自动聚焦游戏窗口。                   |
| *字体*                         |                                                              |
| **标题字体**                   | 编辑器 UI 的标题字体。                                       |
| **大字**                       | 编辑器 UI 的大字体。                                         |
| **中字**                       | 编辑器 UI 的中等字体。                                       |
| **小字**                       | 编辑器 UI 的小字体。                                         |
| **回退字体**                   | 当主文本字体缺少某些字符时使用的回退字体列表。留空以使用 GraphicsSettings 中的字体。 |

## 输入选项

![输入选项](media/options-input.png)

使用此部分可修改编辑器使用的输入快捷键绑定。按下 `X` 按钮可移除绑定。

## 视口选项

![视口选项](media/options-viewport.png)

| 属性             | 描述                                                       |
| ---------------- | ---------------------------------------------------------- |
| **鼠标灵敏度**   | 使用视口摄像机时应用的鼠标移动灵敏度缩放。                 |
| **默认移动速度** | 视口摄像机的默认移动速度（必须与视口中的下拉菜单值匹配）。 |
| **默认近平面**   | 视口摄像机的默认近裁剪平面距离。                           |
| **默认远平面**   | 视口摄像机的默认远裁剪平面距离。                           |
| **默认视野**     | 视口摄像机的默认视野角度（以度为单位）。                   |

## 视觉选项

![视觉选项](media/options-visual.png)

| 属性                       | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **显示选择轮廓**           | 如果勾选，选择轮廓将可见。                                   |
| **选择轮廓颜色 0**         | 选择轮廓渐变的第一种颜色。                                   |
| **选择轮廓颜色 1**         | 选择轮廓渐变的第二种颜色。                                   |
| **Gizmo 大小**             | 变换 Gizmo 的大小。                                          |
| **高亮颜色**               | 用于高亮显示选中的网格和 CSG 表面的颜色。                    |
| **为 DebugDraw 启用 MSAA** | 确定是否为 DebugDraw 图元渲染启用 MSAA。有助于减少像素锯齿，但会降低性能。 |

## 源代码选项

![源代码选项](media/options-source-code.png)

| 属性                     | 描述                                                         |
| ------------------------ | ------------------------------------------------------------ |
| **源代码编辑器**         | 用于访问项目和源文件的源代码编辑 IDE。                       |
| **自动生成脚本项目文件** | 确定在编辑器中添加/移除/移动脚本时是否自动生成脚本项目文件。 |

## 自定义选项

编辑器支持通过添加自定义设置来扩展选项。这可以由编辑器插件使用。要了解如何操作，请参阅相关[教程](../../scripting/tutorials/custom-editor-settings.md)。
