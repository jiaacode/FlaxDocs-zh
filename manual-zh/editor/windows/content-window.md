# 内容窗口

![内容窗口](/manual/media/content-window.jpg)

**内容窗口** 显示你的项目资源和脚本。你可以使用新建资源按钮创建新资源，或将源文件拖放到资源视图中。你也可以将资源从资源视图拖放到不同的编辑器或[属性窗口](properties-window.md)中，以添加对它的引用。

窗口左侧显示项目文件夹树状结构（Flax 使用的 *Editor* 和 *Engine* 文件夹仅在开发构建中可见）。主资源视图面板显示当前位置的内容，包括所有有效资源、脚本和子目录。你可以通过中间的拆分控件调整这些区域的大小。

## 上下文菜单

![上下文菜单](/manual/media/content-window-context-menu.jpg)

如果你在项目（资源或文件夹）或资源视图背景上 **右键单击**，将显示上下文菜单。
它包含用于工作区管理和资源操作的一组选项。
你可以使用上下文菜单创建新资源和脚本。

## 快捷键

| 控制                | 操作                                 |
| ------------------- | ------------------------------------ |
| **方向键**          | 导航                                 |
| **Ctrl + 鼠标左键** | 从选择中添加/移除                    |
| **Ctrl + A**        | 选择视图中的所有项目                 |
| **双击资源图标**    | 打开资源编辑器                       |
| **双击资源名称**    | 重命名资源                           |
| **Enter**           | 打开资源编辑器（仅当选中单个项目时） |
| **Backspace**       | 向后导航                             |
| **Delete**          | 删除选中的项目                       |
| **Ctrl + D**        | 复制选中的项目                       |
| **Ctrl + 滚轮**     | 缩放                                 |
