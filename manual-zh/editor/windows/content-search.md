**内容搜索** 是一个用于在项目内容中搜索的实用工具窗口。它可用于查找给定资源名称或可视化脚本方法在各种资源中的使用情况，例如：
* 可视化脚本
* 材质
* 动画图
* 粒子发射器

要打开此窗口，请在图表编辑器（例如在可视化脚本中）中使用 `Ctrl+F`，或使用主菜单中的 *窗口 -> 内容搜索* 选项。此外，你可以 *右键单击* 图表中的参数或方法节点，然后选择 **查找引用...** 选项，这将调出搜索窗口并开始搜索内容。

### 搜索选项

* **搜索字段** - 值匹配是基于文本的，搜索所有值中出现的输入文本（不区分大小写）。如果输入文本值用括号括起来，则将进行精确匹配搜索。
* **搜索位置** - 搜索范围的选项，可以是：*当前资源* 用于搜索当前打开的资源，*所有已打开的资源* 用于搜索所有打开的资源，或 *所有资源* 用于搜索所有内容。
* **搜索资源** - 用于指定要搜索的资源类型的选项。默认情况下，它设置为调用窗口的资源类型，但可以配置为在整个项目中进行搜索。
