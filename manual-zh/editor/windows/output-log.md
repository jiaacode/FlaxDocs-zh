# 输出日志

![输出日志](media/output-log.jpg)

**输出日志** 是一个实用工具窗口，显示当前引擎日志。可用于检测游戏问题或分析引擎工作负载。

你可以轻松地选择并复制日志的部分内容，使用 *搜索* 框过滤条目，或使用 **视图** 下拉菜单下的日志类型过滤器。此外，还支持加载日志文件，可用于读取和分析游戏构建版本（例如来自 Xbox 开发构建）的日志。

### 调试命令

![输出日志中的调试命令](../../scripting/advanced/media/debug-commands-output-log.gif)

在该窗口的底部，有一个输入命令字段，可用于运行[调试命令](../../scripting/advanced/debug-commands.md)。你可以输入命令，并会自动弹出搜索框，根据输入的值显示类似的命令。使用方向键在弹出列表中导航。Tab 键可用于根据最佳匹配自动补全命令。最后，当输入为空时，你可以使用向上方向键在命令历史记录中导航并重新尝试其中的一个。
