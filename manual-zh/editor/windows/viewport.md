# 视口

![视口](media/viewport.jpg)

**视口** 一词指的是**编辑器窗口**和**游戏窗口**。
两者都用于预览关卡。
* **游戏**窗口 - 显示当前的游戏摄像机视图，包含 GUI 和游戏输入控制逻辑
* **编辑器**窗口 - 关卡的交互式视图

## 编辑器窗口

此视图允许在场景中导航摄像机，以及选择、变换和编辑场景对象。

#### 小部件

编辑器视口包含一组小部件按钮。在左上角有一个 *视图* 按钮，允许你更改当前视口属性、调试渲染或生成新的摄像机 Actor。

![编辑器视图小部件](media/viewport-view.jpg)

在右上角有一组小部件按钮，用于控制变换 Gizmo 和视口摄像机速度。
要了解有关使用变换 Gizmo 的更多信息，请参阅[此页面](../../get-started/scenes/transforming-actors.md)。

### 控件

| 操作                       | 描述                                         |
| -------------------------- | -------------------------------------------- |
| **鼠标左键**               | 选择对象                                     |
| **Ctrl + 鼠标左键**        | 从选择中添加/移除对象                        |
| **鼠标右键**               | 旋转摄像机                                   |
| **鼠标右键 + 方向键/WSAD** | 移动摄像机                                   |
| **鼠标右键 + 鼠标中键**    | 移动摄像机                                   |
| **鼠标中键**               | 平移摄像机                                   |
| **鼠标滚轮**               | 缩放                                         |
| **鼠标右键 + Shift**       | 将摄像机速度提高 2 倍                        |
| **鼠标右键 + 鼠标滚轮**    | 提高/降低摄像机速度                          |
| **Alt + 鼠标左键**         | 轨道摄像机（围绕上次查看的对象中心，已平移） |
| **F**                      | 显示选中的 Actor（聚焦于它）                 |
| **R**                      | 旋转选中的 Actor（按 45 度）                 |
| **Delete**                 | 删除选中的对象                               |
| **End**                    | 将选中的对象吸附到地面                       |
| **1**                      | 将 Gizmo 模式设置为 *平移*                   |
| **2**                      | 将 Gizmo 模式设置为 *旋转*                   |
| **3**                      | 将 Gizmo 模式设置为 *缩放*                   |

所有与关卡编辑窗口（视口、场景窗口、属性等）相关的快捷键都可用。例如，使用 **Ctrl + S** 保存所有更改。
注意：某些输入配置可以通过编辑器选项更改。

### 顶点捕捉

![顶点捕捉](media/vertex-snapping.gif)

**顶点捕捉** 允许通过利用基于网格顶点位置的自动精确变换原点放置来快速构建场景。这允许使用顶点作为变换原点（例如围绕它旋转对象），或将对象捕捉到另一个网格的顶点。

这包括两个操作：
* 按住 `V` 键选择鼠标光标附近的顶点用作原点。
* 在按住 `V` 键的同时使用平移 Gizmo，将 Gizmo 原点捕捉到附近对象的顶点。

## 游戏窗口

游戏窗口从游戏中的摄像机渲染。
它代表了你在编辑器内模拟期间的最终构建游戏。
你需要使用一个或多个摄像机来控制玩家在玩游戏时实际看到的内容。

#### 屏幕截图

你可以在游戏窗口选项卡上使用 *右键单击* 来截取游戏视口屏幕截图（保存在项目中的 *Screenshots* 文件夹中）。要制作更高分辨率的屏幕截图（例如用于你的游戏或项目的营销），请使用 **视口分辨率** 并将窗口后缓冲区放大（例如放大 2-4 倍）。

#### 工具

你可以在游戏窗口选项卡上使用 *右键单击* 来显示或隐藏游戏 UI 或 DebugDraw 形状。

![游戏视口工具](media/game-viewport-debug-show.gif)

#### 游戏视口大小调整

在游戏窗口选项卡上 *右键单击*，使用 **视口大小** 子菜单来覆盖视口宽高比或分辨率。例如，它可以用于在 16:9 宽高比下测试过场动画，或在 iPhone 或 Android 设备上测试移动游戏视口。你可以使用预定义的视口大小或添加自定义大小。
