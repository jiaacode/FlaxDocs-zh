# Flax 示例

Flax 引擎附带了一系列可直接使用的示例项目。
它们用于展示一些关键功能，或作为你游戏的项目基础。
所有示例都可以从商店（通过启动器）或从 [GitHub](https://github.com/FlaxEngine/FlaxSamples) 仓库下载。
