# macOS

## 技术信息

Flax 支持 **macOS 10.15 或更高版本**。图形渲染方面，通过 MoltenVK 使用 Vulkan 在 Metal 上运行。

## 构建选项

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **输出**     | 构建的游戏输出文件夹（相对于项目）。                         |
| **显示输出** | 如果勾选，构建后将在资源管理器中显示输出文件夹。             |
| **配置模式** | 游戏构建模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**Release**</td><td>准备发布的发布构建。</td></tr><tr><td>**Debug**</td><td>用于测试和性能分析的调试构建。为获得最佳调试体验，大多数代码优化已被禁用。</td></tr><tr><td>**Development**</td><td>用于测试和性能分析的开发构建，但比 Debug 构建更针对运行时优化。</td></tr></tbody></table> |
| **CPU**      | 目标处理器架构（Intel 或 Apple Silicon）。                   |

## 平台设置

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **应用标识符**         | 应用程序标识符（反向 DNS，例如 com.company.product）。自定义令牌：`${PROJECT_NAME}`、`${COMPANY_NAME}`。 |
| **代码签名身份**       | 应用程序代码签名身份名称（来自本地 Mac 钥匙串）。使用 `security find-identity -v -p codesigning` 列出可能的选项。 |
| **打包钥匙串配置文件** | 用于应用程序公证操作的 Apple 钥匙串配置文件名称（本地安装）。 |
| **窗口模式**           | 默认游戏窗口模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**窗口化**</td><td>窗口带有边框，不占据全屏。</td></tr><tr><td>**全屏**</td><td>窗口独占全屏。</td></tr><tr><td>**无边框**</td><td>窗口行为类似于窗口化模式，但没有边框。</td></tr><tr><td>**全屏无边框**</td><td>与无边框相同，但尺寸为屏幕大小。</td></tr></tbody></table> |
| **屏幕宽度**           | 默认游戏窗口宽度（以像素为单位）。                           |
| **屏幕高度**           | 默认游戏窗口高度（以像素为单位）。                           |
| **可调整窗口大小**     | 允许用户调整游戏窗口大小。                                   |
| **覆盖图标**           | 用于应用程序的自定义图标纹理（覆盖默认图标）。               |
