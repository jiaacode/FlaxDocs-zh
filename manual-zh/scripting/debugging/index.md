# 脚本调试

![调试器](media/Post_FlaxFacts010.jpg)

如果你的脚本在运行时产生意外结果，你可以调试它。有几种方法可以做到。最简单的方法是使用 [Debug.Log](https://docs.flaxengine.com/api/FlaxEngine.Debug.html#FlaxEngine_Debug_Log_System_Object_)。
然后你可以在 *Debug* 窗口中预览输出。

![调试窗口](media/debug-log-win.jpg)

## 代码编辑器

Flax 支持各种代码编辑器集成，并允许通过插件集成自定义编辑器。
你可以使用编辑器选项来更改当前编辑器（在 **源代码** 选项卡中）。

![源代码编辑器](media/source-code-editor.png)
