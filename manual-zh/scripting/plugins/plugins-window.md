# 插件窗口

![插件窗口](media/plugins-window.png)

插件窗口是一个编辑器工具，用于预览已加载的插件。你可以通过使用菜单选项 **工具 -> 插件** 来打开它。

窗口中列出的插件按类别划分。通过双击插件作者名称标签，你可以导航到插件网站以获取更多信息或寻求帮助。

## 插件描述

在创建插件时，请提供适当的描述，包括插件 UI 名称、信息、版本和作者。你还可以通过将图标导入到 `Content/<plugin_assembly_name>.Icon.flax`（在插件项目目录内）来自定义插件图标。图标应为方形纹理（例如分辨率为 128 或 256 像素）。
