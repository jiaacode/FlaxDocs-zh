# 可视化脚本中的数组

**可视化脚本** 支持数组作为脚本属性，并在脚本中使用它们来处理大量数据。请参阅本文档页面，了解如何在项目中使用它们。

## 如何添加数组属性？

![可视化脚本中的数组属性更改](media/array-type-property.png)

数组属性的工作方式与任何其他脚本属性相同。要创建一个，只需添加一个给定类型的变量，例如 `Float`，然后使用 *右键单击* 选择 **类型 -> 数组**。这将把属性从单个值转换为数组。你可以使用此上下文菜单将其更改回来，或修改属性类型。

## 如何迭代数组？

![可视化脚本中的 Array For Each 迭代](media/array-for-each.png)

要迭代数组，你可以使用内置的 **Array For Each** 节点，该节点允许遍历所有数组项，如上所示。它的工作方式类似于 **For Loop**，不同之处在于它适应数组长度，并在迭代器 *Index* 处公开当前的 *Item*。要迭代数组的自定义范围，请使用 For Loop 或 While Loop。

## 如何访问数组？

![可视化脚本中的数组 API 访问节点](media/array-api-nodes.png)

**Array** 组包含许多节点，例如：Length、Get、Set、Remove、Sort 等。这些节点对所有数组类型都是通用的，但会适应输入的数组类型。它们不会编辑引用的输入数组，而是返回修改后的数组值（请参见未命名的输出框）。

## 如何创建数组值？

![可视化脚本中的数组常量](media/new-array-node.png)

使用 **Constants** 组中的 **Array**，分配项类型，指定长度（使用 `+` 和 `-` 按钮），并填充值。
