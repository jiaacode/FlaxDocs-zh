# 行为树装饰器

行为树具有很强的可扩展性，这意味着你可以在游戏项目中创建自己的装饰器类型，或使用引擎和插件中的装饰器。每个装饰器都可以定义自定义逻辑、包含属性并存储运行时状态（每个实例）。此页面包含所有内置装饰器类型及其文档。

## 反转

反转节点的结果——如果节点成功则失败，如果节点失败则成功。

## 强制成功

强制节点成功——即使它失败了。

## 强制失败

强制节点失败——即使它成功了。

## 循环

只要节点没有失败，就多次循环执行节点。返回最后一次迭代的结果。

| 属性               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **循环次数**       | 执行节点的次数。如果使用了 *循环次数选择器*，则此属性不被使用。 |
| **循环次数选择器** | 从行为知识（黑板、目标或传感器）中获取的执行节点的次数。如果设置，将覆盖 *循环次数*。 |

## 时间限制

限制节点执行时间的最长持续时间（以秒为单位）。如果超时，节点将失败。

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **最大持续时间**       | 节点执行的最长时间（以秒为单位）。如果使用了 *最大持续时间选择器*，则此属性不被使用。 |
| **随机偏差**           | 持续时间随机化范围，用于偏离原始值。                         |
| **最大持续时间选择器** | 从行为知识（黑板、目标或传感器）中获取的节点执行最长时间（以秒为单位）。如果设置，将覆盖 MaxDuration，但仍会使用 *随机偏差*。 |

## 冷却

在节点执行之间添加冷却时间。在最后一次运行后的给定持续时间内阻止节点执行。

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **最小持续时间**       | 最小冷却时间（以秒为单位）。如果使用了 *最小持续时间选择器*，则此属性不被使用。 |
| **随机偏差**           | 持续时间随机化范围，用于偏离原始值。                         |
| **最小持续时间选择器** | 从行为知识（黑板、目标或传感器）中获取的最小冷却时间（以秒为单位）。如果设置，将覆盖 MinDuration，但仍会使用 *随机偏差*。 |

## 知识条件

检查特定的知识值，以有条件地进入节点。

| 属性     | 描述                                                   |
| -------- | ------------------------------------------------------ |
| **值 A** | 用于比较的行为知识（黑板、目标或传感器）中的第一个值。 |
| **值 B** | 用于比较的第二个值（常量）。                           |
| **比较** | 值比较模式（等于、不等于、小于、大于等）。             |

## 知识值条件

检查特定的知识值，以有条件地进入节点。

| 属性     | 描述                                                   |
| -------- | ------------------------------------------------------ |
| **值 A** | 用于比较的行为知识（黑板、目标或传感器）中的第一个值。 |
| **值 B** | 用于比较的行为知识（黑板、目标或传感器）中的第二个值。 |
| **比较** | 值比较模式（等于、不等于、小于、大于等）。             |

## 拥有标签

检查某个 Actor（来自知识）是否分配了给定的标签。

| 属性      | 描述                                                         |
| --------- | ------------------------------------------------------------ |
| **Actor** | 行为知识（黑板、目标或传感器）中用于检查标签所有权的 Actor 值。 |
| **标签**  | 要检查的标签。                                               |
| **反转**  | 如果勾选，反转条件——检查 Actor 是否没有标签。                |

## 拥有目标

检查某个目标是否已添加到行为知识中。

| 属性     | 描述               |
| -------- | ------------------ |
| **目标** | 要检查的目标类型。 |
