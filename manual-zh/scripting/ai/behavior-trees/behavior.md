# 行为

**行为** 是一个附加到关卡中 Actor 上的脚本，旨在通过执行 [行为树](index.md) 来控制其逻辑。

行为可以在脚本（及其父 Actor）在关卡加载期间启用时启动，也可以在场景中生成时启动。当 *自动启动* 启用时（默认启用），行为将使用 `OnEnable()` 事件来启动其逻辑。

你可以通过 `StartLogic()`、`StopLogic()`、`ResetLogic()` 方法手动控制逻辑执行。当行为结束时，它会调用 `Finished` 事件，并设置 `Result` 属性（请参阅 `BehaviorUpdateResult`）。

当行为正在运行时，其执行在 `Behavior.System`（`TaskGraphSystem`）中执行，该任务在游戏更新期间（在 `Engine.UpdateGraph` 上）运行，并通过任务系统调度异步执行。

## 属性

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **树**           | 用于逻辑执行的行为树资源。                                   |
| **自动启动**     | 如果勾选，在开始播放时自动启动逻辑。                         |
| **更新速率缩放** | 行为逻辑更新速率缩放（乘以行为树根节点中定义的 *Update FPS*）。可用于通过 LOD 来提高性能，以减少距离玩家较远的行为的更新频率（例如乘以 `0.5`）。 |
