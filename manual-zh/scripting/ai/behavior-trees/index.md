# 行为树

![Flax 引擎中的行为树](media/behavior-tree-1.jpg)

**行为树**（缩写为 **BT**）是一种流行的 AI 技术，用于许多计算机游戏中，用于设计和模拟智能角色、代理或对象。行为树是许多不同 AI 技术的组合：层级状态机、规划、调度和动作执行。行为树的主要优点是它们很容易理解，并且可以通过可视化编辑工具创建，而不仅仅是代码。

在本文档部分，你将学习如何创建和使用行为树。

## 创建行为树

![创建新的行为树](media/new-behavior-tree.jpg)

要创建新的行为树资源，只需在 *内容* 窗口中导航到 Content 目录，然后右键单击并选择选项 **新建 -> AI -> 行为树**。指定其名称并按 *Enter*。

## 行为树编辑器窗口

![行为树编辑器窗口](media/behavior-tree-window-layout.png)

行为树编辑器窗口包含：
1. **工具栏** - 实用按钮，如保存或撤销控制，包含要调试的行为选择器
2. **可视曲面** - 节点图编辑器
3. **选中的节点属性** - 显示选中节点的属性
4. **知识属性** - 显示带有目标的行为知识黑板数据

### 导航控制

行为树编辑器中的控件通常与 Flax 编辑器中其他工具的控件相匹配。

#### 鼠标控制

| 控制                         | 操作                 |
| ---------------------------- | -------------------- |
| **鼠标右键** 在背景上拖动    | 平移节点图           |
| **鼠标右键** 点击背景        | 显示节点创建菜单     |
| **鼠标右键** 点击节点        | 显示节点编辑菜单     |

| **鼠标滚轮**                 | 缩放                 |

### 添加新节点

要添加新节点，请 **右键单击** 曲面背景，然后从弹出菜单中选择节点类型，或输入其名称以查找它。行为树可以使用来自引擎、插件和游戏的节点。此外，当鼠标光标悬停在项目上时，工具提示将显示文档注释，其中包含每个节点的详细信息。

![添加新的行为树节点](media/add-new-node.png)

### 添加新装饰器

每个节点都可以有一个装饰器列表（按特定顺序），这些装饰器是用于检查节点是否可以执行的附加功能，或修改其逻辑流（例如循环节点）。要添加新节点，请 **右键单击** 节点标题，选择子菜单 **添加装饰器**，然后从列表中选择装饰器类型。此外，当鼠标光标悬停在项目上时，工具提示将显示文档注释，其中包含详细信息。

![添加新的行为树节点装饰器](media/add-decorator.png)

装饰器可以像常规节点一样被选择和编辑。你可以通过拖动每个装饰器上关闭按钮旁边的图标来更改它们的顺序。

### 连接节点

有 3 种类型的节点：根节点、复合节点、叶节点。**根节点** 可以包含子节点，但始终是启动树执行的第一个节点。**复合节点** 可以有一个传入连接和一个子节点列表，以根据节点类型（例如序列或选择器）执行它们。**叶节点** 是基于操作的，通常执行单个操作（即时或循环）。

子**节点始终从左到右执行**。这意味着节点的放置位置很重要，并有助于保持树图更可读。

### 调试

行为树包含调试器功能，可以在编辑器中的 **运行模式** 下使用。只需使用工具栏上的对象选择器 **选择目标行为**。

![行为调试器](media/behavior-debug-picker.png)
