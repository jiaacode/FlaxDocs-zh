# 行为树节点

行为树具有很强的可扩展性，这意味着你可以在游戏项目中创建自己的节点类型，或使用引擎和插件中的节点。每个节点都可以定义自定义逻辑、包含属性并存储运行时状态（每个实例）。此页面包含所有内置节点类型及其文档。

## 根节点

行为树的根节点。包含运行时逻辑属性和定义。每个行为树自动创建，无法移除。

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **黑板类型** | 黑板数据的类型（结构或类）。为每个行为实例生成。请参阅[知识文档](knowledge.md)以了解更多信息。 |
| **目标类型** | 行为目标类型的列表（结构或类）。请参阅[知识文档](knowledge.md)以了解更多信息。 |
| **更新 FPS** | 行为逻辑每秒更新的目标次数。                                 |

## 序列

序列节点按顺序更新其所有子节点（从左到右），只要它们返回成功。如果任何子节点失败，序列则失败。

## 选择器

选择器节点更新其所有子节点（从左到右），直到其中一个成功。如果所有子节点都失败，选择器则失败。

## 延迟

延迟节点在执行时等待一段特定的时间。

| 属性               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **等待时间**       | 节点被激活时要等待的时间（以秒为单位）。如果使用了 *等待时间选择器*，则此属性不被使用。 |
| **随机偏差**       | 等待时间随机化范围，用于偏离原始值。                         |
| **等待时间选择器** | 从行为[知识](knowledge.md)（黑板、目标或传感器）中获取的等待时间。如果设置，将覆盖 *等待时间*，但仍会使用 *随机偏差*。 |

## 子树

子树节点在此树内运行一个嵌套的行为树。

| 属性   | 描述                         |
| ------ | ---------------------------- |
| **树** | 在此节点内执行的嵌套行为树。 |

## 强制完成

强制以特定结果结束行为执行（例如强制失败）。

| 属性     | 描述       |
| -------- | ---------- |
| **结果** | 执行结果。 |

## 移动到

将 Actor 移动到特定的目标位置。在导航网格上使用寻路。

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **代理**         | 要移动的代理 Actor。如果未设置，则使用行为的父 Actor。       |
| **移动速度**     | 代理移动速度。默认值为 100 单位/秒。                         |
| **目标**         | 目标移动对象。                                               |
| **目标位置**     | 目标移动位置。                                               |
| **可接受半径**   | 代理与目标目标位置之间的阈值，用于检测是否到达目的地。       |
| **目标更新容差** | 目标 Actor 位置偏移的阈值，触发重新寻路以查找新路径。        |
| **使用寻路**     | 如果勾选，移动将使用导航系统寻路，否则将直接移动到目标位置。 |
| **使用部分路径** | 如果勾选，即使没有直接到达目标的路径（仅部分路径），移动也会开始。 |
| **使用目标更新** | 如果勾选，当目标 Actor 移动时，目标位置将会更新。            |
