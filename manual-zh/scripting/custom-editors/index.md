# 自定义编辑器

**自定义编辑器** 系统是 Flax 编辑器的一项功能，用于在编辑器中呈现对象数据。它是实际对象与用户界面之间的一个层。它处理所有用户操作、对象编辑和撤销操作。通过使用自定义编辑器，任何对象类型都可以在编辑器中进行可视化。这有助于为你的游戏创建和编辑场景及脚本。

Flax 编辑器使用自定义编辑器在 *属性* 窗口中显示选中的 Actor 属性。它还会列出附加的脚本。游戏开发者可以编写自定义编辑器来扩展编辑器的默认 UI 和逻辑。例如，你可以非常轻松地 **为你的脚本创建自定义编辑器**。要了解如何操作，请参阅[此教程](../tutorials/custom-editor.md)。

你也可以在代码中直接使用自定义特性。请参阅[此文档页面](attributes.md)。

自定义编辑器的实现是开源的（作为 *Flax Engine* 的一部分），可以在[此处](https://github.com/FlaxEngine/FlaxEngine/tree/master/Source/Editor/CustomEditors)找到。
