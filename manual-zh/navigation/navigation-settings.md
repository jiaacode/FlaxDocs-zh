# 导航设置

导航设置资源指定了导航网格构建选项和导航系统使用的其他设置。

## 属性

![导航设置](media/navigation-settings.png)

| 属性                       | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **自动添加缺失的导航网格** | 如果勾选，在导航构建期间，为使用它的场景启用自动生成导航网格 Actor。 |
| **自动移除缺失的导航网格** | 如果勾选，在导航构建期间，为不使用它的场景启用自动移除导航网格 Actor。 |
|                            |                                                              |
| **单元高度**               | 在使用高度场的导航网格构建步骤中网格单元的高度。较低的数字意味着垂直轴上的精度更高，但构建时间更长。 |
| **单元大小**               | 在使用高度场的导航网格构建步骤中网格单元的宽度/高度。较低的数字意味着水平轴上的精度更高，但构建时间更长。 |
| **图块大小**               | 导航网格图块使用的图块大小，图块的最终大小为 CellSize*TileSize。 |
| **最小区域面积**           | 允许形成孤立岛屿区域的最小单元数。                           |
| **合并区域面积**           | 任何跨度计数小于此值的区域，如果可能，将与更大的区域合并。   |
| **最大边长**               | 沿网格边界的轮廓边缘的最大允许长度。                         |
| **最大边缘误差**           | 简化轮廓的边界边缘偏离原始原始轮廓的最大距离。               |
| **细节采样距离**           | 定义在生成细节网格时使用的采样距离。                         |
| **最大细节采样误差**       | 细节网格表面偏离高度场数据的最大距离。仅用于高度细节。       |

## 代理

![导航设置导航代理导航网格](media/navigation-settings-agents.png)

导航网格的配置。每个导航网格可以使用不同的代理属性（例如，一个导航网格用于小型 AI 机器人，另一个用于大型 Boss 敌人）。你还可以调整导航网格颜色，甚至通过使用旋转属性在墙壁上生成导航网格。

| 属性           | 描述                                                         |
| -------------- | ------------------------------------------------------------ |
| **名称**       | 导航网格类型名称。标识不同类型的导航网格，用于将导航网格属性与设置资源同步。 |
| **颜色**       | 导航网格类型颜色（用于调试）。                               |
| **旋转**       | 应用于导航表面的导航网格旋转。在构建期间用于旋转场景几何体，并在寻路查询期间将结果转换回来。可用于在墙壁上生成导航网格。 |
| *代理*         | 用于生成可行走导航表面的代理属性。                           |
| **半径**       | 用于导航的代理半径。代理无法通过小于半径两倍的间隙。         |
| **高度**       | 用于导航的代理高度。代理无法进入天花板低于此值的区域。       |
| **步高**       | 用于导航的步高。定义被视为代理仍可通行的最大平台高度。       |
| **最大坡度角** | 被视为可通行的导航最大坡度（以度为单位）。代理无法爬上或爬下高于此值的坡度。 |

## 区域

![导航设置导航区域](media/navigation-settings-areas.png)

导航区域的配置。可用于通过[导航修改器体积](nav-modifier-volume.md)应用它们，以调整关卡区域的导航代价。

| 属性     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| **名称** | 区域类型名称。标识不同类型的区域。                           |
| **颜色** | 区域类型颜色（用于调试）。Alpha 通道用于与导航网格颜色混合（Alpha 为 0 时仅使用导航网格颜色）。 |
| **ID**   | 区域 ID。对于项目来说必须是唯一的。有效范围为 0-63。值 0 保留给 Null 区域（空的、不可导航的区域）。 |
| **代价** | 代理穿越该区域的代价缩放。代价越高，代理选择经过该区域的路径的可能性就越低。例如，像沙地这样较难移动的区域，为了正确的寻路应该具有更高的代价。 |
