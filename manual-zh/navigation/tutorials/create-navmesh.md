# 操作指南：创建导航网格

在本教程中，你将学习如何为你的场景创建导航网格。

## 1. 打开一个新场景

首先，你需要打开场景。如果你没有任何场景，可以使用内容窗口的上下文菜单创建一个。

## 2. 添加碰撞体

使用 *工具箱窗口* 或 *场景树窗口* 中的上下文菜单，为地面模型添加碰撞体，如下所示。

![作为地面的碰撞体](/manual/media/add-collider.jpg)

导航网格生成器使用物理碰撞来定义关卡的环境，而不是使用网格。

## 3. 添加导航网格边界体积

使用 *工具箱窗口* 或 *场景树窗口* 中的上下文菜单，添加导航网格边界 Actor。它用于定义关卡中应生成导航网格的区域。

![导航网格边界体积](/manual/media/add-nav-mesh-bounds-volume.jpg)

## 4. 查看结果

默认情况下，导航网格由编辑器自动生成，因此现在你可以通过启用小部件选项 **视图 -> 显示 -> 导航** 来预览导航网格。要重建已加载场景的导航网格，你可以使用主菜单中的选项，即 **工具 -> 构建导航网格**。

![导航网格](/manual/media/show-nav-mesh.jpg)
