# 音频源

![音频源](media/audio-source-title.jpg)

**音频源** 是一种 Actor 类型，代表用于发出音频的源。音频可以是空间化的（如枪声），也可以是常规的（如音乐）。每个音频源都必须有一个 [音频片段](audio-clip.md) 来播放，并且在空间（3D）音频的情况下还可以有位置。

音频源是否是空间化的由分配的音频片段控制。空间音频源的音量和音高由其位置和 [音频监听器](audio-listener.md) 的位置/方向/速度控制。

## 属性

![音频源属性](media/audio-source-properties.jpg)

| 属性           | 描述                                                         |
| -------------- | ------------------------------------------------------------ |
| **片段**       | 用作声音源的音频片段资源。                                   |
| **音量**       | 从此源播放的音频的音量，范围为 [0, 1]。                      |
| **音高**       | 播放音频的音高。默认值为 1。                                 |
| **循环**       | 确定音频片段播放完成后是否应循环播放。                       |
| **启动时播放** | 确定音频片段是否应在关卡启动时自动播放。                     |
| **最小距离**   | 音频衰减开始的最小距离。当监听器距离源小于此值时，音频以全音量播放。一旦距离更远，音频开始衰减。 |
| **衰减**       | 控制当监听器远离源时音频音量下降速度的衰减。                 |
