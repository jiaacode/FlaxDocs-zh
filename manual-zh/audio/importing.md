# 导入音频

你可以导入音频文件，用作项目中的声音资源。
Flax 引擎支持导入以下列表中的文件类型作为音频片段：
* `.mp3`
* `.wav`
* `.ogg`

## 导入声音

导入一个或多个纹理的最简单方法是将它们从 *资源管理器* 拖放到 *内容* 窗口中。

![导入音频片段](media/import-audio.jpg)

或者，你也可以使用 *内容* 窗口工具栏中的 **导入** 按钮，然后选择要导入的文件。

选择文件后，**导入文件设置** 对话框将显示。它用于为每个资源指定导入选项。在大多数情况下，默认值即可，你只需按下 **导入** 按钮。

![导入音频片段设置](media/import-settings-dialog.jpg)

> [!Note]
> 使用 **导入文件设置** 对话框，你可以一次选择多个资源（或使用 **Ctrl+A** 全选）并同时指定导入选项。

## 导入设置

![音频片段导入设置](media/import-settings.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **格式**         | 指定音频数据导入为音频片段的格式。你可能希望使用优化和压缩的格式，或使用原始 PCM 数据以获得最佳质量。在大多数情况下，为了节省内存使用，你希望使用 Vorbis 压缩格式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**原始**</td><td>这是以脉冲编码调制格式存储的未压缩原始音频数据。</td></tr><tr><td>**Vorbis**</td><td>以 Vorbis 格式存储的压缩音频数据。</td></tr></tbody></table> |
| **压缩质量**     | 音频数据压缩质量。仅在目标格式使用压缩时使用。值 0 表示最小尺寸，值 1 表示最佳质量。 |
| **禁用流式传输** | 如果勾选，则禁用动态音频流式传输。整个片段将被加载到内存中。适用于小型片段（例如枪声）或当音频流式传输在开始播放片段时产生过多延迟时。 |
| **是 3D**        | 如果勾选，片段将作为空间（3D）音频或常规音频播放。3D 音频以单声道格式存储。 |
| **位深度**       | 单个样本的位数（以比特为单位）。导入时片段将转换为该位深度。可能的选项：**8**、**16**、**24**、**32**。默认值为 16。 |
