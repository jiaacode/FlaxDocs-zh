# 音频设置

音频设置资源用于指定音频播放选项。

## 属性

![Flax 音频设置](media/audio-settings.jpg)

| 属性               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **禁用音频**       | 如果勾选，将在构建的游戏中禁用音频播放。如果游戏使用自定义音频播放引擎，可以使用此选项。 |
| **多普勒因子**     | 多普勒效应因子。用于缩放源和监听器的速度。默认值为 1。       |
| **失去焦点时静音** | 如果勾选，当游戏失去用户焦点时，引擎将使所有音频播放静音。   |
