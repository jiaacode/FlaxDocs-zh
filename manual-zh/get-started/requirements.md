# 要求

Flax 引擎在运行游戏或使用引擎进行开发时，有特定的硬件和软件要求。

### 硬件要求

|          | 最低要求                       | 推荐                 |
| -------- | ------------------------------ | -------------------- |
| 操作系统 | Windows 10 64 位               | Windows 11 64 位     |
| 处理器   | 2 GHz                          | 四核，2.5 GHz 或更快 |
| RAM      | 4 GB                           | 8 GB                 |
| 硬盘空间 | 1 GB                           | 5 GB                 |
| GPU      | 512MB，兼容 DirectX 10+ 的 GPU | 2 GB，DirectX 11     |

## Linux

在 Linux 平台上使用 Flax 编辑器的开发人员要求详见[此处](linux.md)。

## Mac

在 Mac 平台上使用 Flax 编辑器的开发人员要求详见[此处](mac.md)。

## 软件要求

Flax 引擎要求在 Windows 上安装 **Visual C++ Redistributable for Visual Studio 2015**（或更新版本）才能启动。
如果缺少该组件，启动器将检查并开始安装，但如果你的游戏目标是 Windows 平台，你应该随游戏附赠该可再发行组件安装程序。你可以[在此处](https://www.microsoft.com/download/details.aspx?id=48145)下载它。

Flax 启动器需要 [Microsoft .NET Framework 4.5.2](https://www.microsoft.com/en-us/download/details.aspx?id=42642) 或更高版本。

Flax 编辑器需要 [.NET SDK 8](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)。

我们建议使用 Visual Studio 2022 编写代码。
你可以[在此处](https://www.visualstudio.com/downloads/)下载免费的社区版。

## GPU 驱动程序

请确保已安装最新的 GPU 驱动程序：
- [NVIDIA 驱动程序](https://www.nvidia.com/Download/index.aspx)
- [AMD 驱动程序](https://www.amd.com/support)
