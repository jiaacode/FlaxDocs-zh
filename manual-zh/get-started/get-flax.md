# 安装 Flax 启动器

![安装 Flax](media/installing-flax.png)

要获取 Flax：请访问[下载页面](https://flaxengine.com/download)下载 Flax 启动器安装程序。

下载完成后，启动安装程序并按照安装向导的步骤操作。为了安装 Flax，你将被要求接受 *EULA*，其中定义了引擎许可条款。你可以在[此处](https://flaxengine.com/licensing)了解更多关于法律规定的信息。

要了解有关软件和硬件要求的更多信息，请访问[此页面](requirements.md)。

# 运行 Flax 启动器

要安装 Flax 引擎，请运行 Flax（默认情况下，Flax 会在桌面上创建一个快捷方式）。
下一步是**登录** Flax 启动器。
> [!Note]
> 此步骤是可选的，可以通过单击 **跳过登录** 来跳过。

![登录 Flax 启动器](media/flax-launcher-login.png)

# 安装 Flax 引擎

登录后，转到 **引擎** 页面。在这里你可以下载和管理引擎安装。你可以在计算机上安装不同版本的 Flax。要下载更新和附加包，请转到 **引擎** 页面。

![打开启动器](media/launcher-engine.png)

要安装 Flax，请使用 **添加版本** 按钮选择引擎版本和安装目标文件夹。在这里你可以选择安装在不同平台上构建和部署游戏所需的包。最后，按下 **安装** 按钮下载 Flax 二进制文件。

使用 *版本* 下拉菜单选择要安装的引擎版本。默认情况下会选择最新版本，但你可以更改它以获取较旧的引擎版本（例如你的团队正在使用的版本）。此外，它还允许从 Github 主分支下载每日构建（名为 `master branch (daily)`）。每天都有新的构建，这允许你尝试新功能和错误修复。

![下载 Flax](media/download-flax.png)

> [!Note]
> 带有蓝色轮廓的引擎版本被标记为打开项目的默认版本。单击任何安装的三个点菜单，将其设置为新的默认版本或修改其属性。

![默认引擎版本](media/default-version.png)
