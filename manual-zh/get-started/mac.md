# Mac 版编辑器

![Mac 上的 Flax 编辑器](media/flax-editor-mac.png)

## 下载

要获取适用于 Mac 的 Flax：请访问[下载页面](https://flaxengine.com/download)。

下载 `FlaxEditor.dmg` 文件后，打开磁盘映像并运行 Flax Editor 应用程序。此外，你可以通过将其拖入应用程序文件夹来将其安装到你的驱动器上。

## 要求

在 Mac 平台上使用 Flax 编辑器的开发人员要求如下：

|              | 推荐                      |
| ------------ | ------------------------- |
| 最低支持版本 | **macOS 11.7 或更高版本** |
| 处理器       | **arm64** (M1/M2/M3)      |
| RAM          | 4 GB 或更多               |
| 硬盘空间     | 至少 1 GB                 |

## 示例项目

为了帮助你开始使用 Flax，请从 [https://github.com/FlaxEngine/FlaxSamples](https://github.com/FlaxEngine/FlaxSamples) 获取最新的 Flax 示例。该集合包含各种示例项目，展示了引擎功能，并可用作你未来 Flax 项目的基础。玩得开心！

## 新项目

要创建新项目，请按如下方式运行 Flax Editor 可执行文件（位于 `Binaries/Editor/Mac/Development` 文件夹内）`./FlaxEditor -new -project <new_project_path>`，以便在指定文件夹内创建新项目。编辑器将生成一个项目模板并打开它。
