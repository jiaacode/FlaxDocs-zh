# Flax 编辑器入门

![Flax 编辑器](../editor/media/title.jpg)

**Flax 编辑器** 是一款独立的、一站式的应用程序，用于使用 Flax 引擎开发游戏。
Flax 文档涵盖了最重要的主题，并描述了如何使用编辑器工具。
请遵循这些说明来推进你的游戏开发！
