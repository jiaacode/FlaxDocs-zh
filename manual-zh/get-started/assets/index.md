# 资源

![资源](/manual/media/title.jpg)

**资源** 是保存资源数据的文件。
例如，纹理、模型或场景文件都是资源。
资源可以从 Flax 外部创建的文件导入，例如 3D 模型、音频文件或纹理。
还有一些资源类型可以在 Flax 编辑器内部创建，例如物理材质或场景。

本节涵盖了在 Flax 中处理资源的基本原则。
