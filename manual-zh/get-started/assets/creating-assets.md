# 创建资源

某些资源类型可以从外部文件导入（模型、纹理等），而某些资源可以直接在编辑器中创建（场景、物理材质等）。在两种情况下，都使用[内容窗口](../../editor/windows/content-window.md)。

## 创建资源

例如，要创建一个新的[物理材质](../../physics/physical-material.md)资源，只需在 *内容* 窗口中导航到 Content 目录，然后右键单击并选择选项 **新建 -> 物理 -> 物理材质**。指定其名称并按 *Enter*。

![创建新的物理材质](../../physics/media/new-physical-material.jpg)

## 导入资源

导入一个或多个纹理/模型等的最简单方法是将它们从 *资源管理器* 拖放到 *内容* 窗口。

![导入纹理](../../graphics/textures/media/import-texture.jpg)

或者，你可以使用 *内容* 窗口工具栏中的 **导入** 按钮，然后选择要导入的任何文件。

选择文件后，**导入文件设置** 对话框将显示。它用于为每个资源指定导入选项。在大多数情况下，默认值即可，你只需按下 **导入** 按钮。
