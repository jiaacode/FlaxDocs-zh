# 世界单位

![World Grid](media/world-grid.png)

Flax 使用 **厘米** 作为长度单位，**千克** 作为重量单位。
这些世界单位被物理引擎和渲染引擎所采用。您应当尽量使用符合现实的值，以便为对象创造稳定的视觉和物理表现。

## 坐标系

Flax 使用 **左手坐标系**。各轴指向如下：
* **X 轴** - *右* 方向
* **Y 轴** - *上* 方向
* **Z 轴** - *前* 方向

## 数学库

Flax 使用 **行主序矩阵** 和行向量。
不过，在表示对象变换时，Flax 尽可能使用 [Transform](https://docs.flaxengine.com/api/FlaxEngine.Transform.html) 结构，因为它在某些情况下更易于使用且具有更好的精度。变换顺序始终为：**缩放** -> **旋转** -> **平移**（TRS 方式）。
欧拉角的存储顺序为：**俯仰 - 偏航 - 滚转**（x, y, z）。
