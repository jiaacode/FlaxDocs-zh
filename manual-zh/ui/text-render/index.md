# 文本渲染

![文本渲染](media/title.jpg)

**文本渲染** 是一种用于渲染 3D 文本的 Actor 类型。它*不是* UI 控件，不需要 UI 画布。文本可以使用自定义字体和材质进行渲染。同时支持投射和接收阴影。

在编辑器中，如果你选择了文本渲染 Actor，它会显示调试边界，这些边界是：
* `橙色` - 文本字形字符位置的轴对齐包围盒（顶点 AABB，参见 **Local Box** 属性）
* `蓝紫色` - 用于换行、对齐和定位文本字符的文本布局矩形（参见 **Bounds** 属性）。

## 属性

![文本渲染属性](media/properties.png)

| 属性           | 描述                                                         |
| -------------- | ------------------------------------------------------------ |
| **文本**       | 要渲染的文本。支持[本地化](../../editor/localization/index.md)。 |
| **颜色**       | 文本的颜色。                                                 |
| **材质**       | 用于渲染的材质。它**必须**包含一个名为 'Font' 的纹理参数，用于采样字体纹理本身。 |
| **字体**       | 用于渲染的字体。                                             |
| **字体大小**   | 字体字符的大小。                                             |
| **阴影模式**   | 此视觉元素的阴影投射模式。                                   |
|                |                                                              |
| **边界**       | 对象局部空间中的布局区域矩形（在 XY 平面上）。               |
| **水平对齐**   | 文本在布局矩形内的水平对齐方式。                             |
| **垂直对齐**   | 文本在布局矩形内的垂直对齐方式。                             |
| **文本换行**   | 文本在布局边界内的换行模式。                                 |
| **行间距缩放** | 行间距的缩放参数。默认值为 1。                               |
