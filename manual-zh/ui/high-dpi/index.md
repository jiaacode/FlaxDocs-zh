# 高 DPI UI

现代屏幕的像素密度越来越高，意味着在相同面积内包含更多像素。这类屏幕被称为高 DPI（每英寸点数）屏幕。这对于以像素大小指定的 UI 带来了问题。例如，一个尺寸为 64x64 像素的图标，在 4k 显示器上最终会显得相当小。为了使 UI 在此类屏幕上具有正确的大小，你需要引入 DPI 调整。

例如，当 DPI 缩放为 200% 时，所有 UI 像素的大小将变为屏幕上像素的两倍。

在大多数情况下，你无需做任何事，Flax 会为你处理一切。不过，需要注意的一件事是在不同的“坐标空间”之间转换向量，例如鼠标位置。

> [!Tip]
> 使用 `-lowdpi` 命令行参数运行编辑器或游戏将禁用高 DPI 感知支持。

## 屏幕空间

屏幕空间中的一个像素恰好是屏幕上的一个像素。屏幕空间也横跨所有显示器。

## 窗口空间

窗口空间从窗口的左上角开始，不包括标题栏。对于 FlaxEngine 的 UI，这始终是经过 DPI 调整的。Flax 会在将 UI 渲染到物理屏幕之前负责对其进行放大。

## 局部空间

局部空间从控件的左上角开始。它也经过了 DPI 调整。

## 游戏窗口空间

游戏窗口空间从窗口的左上角开始，不包括标题栏。此空间明确不进行 DPI 调整。
