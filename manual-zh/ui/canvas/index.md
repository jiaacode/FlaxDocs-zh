# UI 画布

![UI 画布](media/title.jpg)

**UI 画布** 是一种用于渲染 UI 的 Actor 类型。它是 UI 结构的根节点，负责执行 GUI 绘制并处理输入事件。画布可以放置在 3D 空间中（作为世界空间或摄像机空间对象），也可以直接渲染在屏幕上（作为屏幕空间模式）。

> [!Note]
> 在编辑器中创建 UI 画布后，它默认会旋转。这是因为 GUI 坐标系使用容器的左上角作为其变换的原点。

## 属性

![UI 画布属性](media/properties.png)

| 属性             | 描述                                                         |

| **渲染模式**     | 画布渲染模式。可能的选项包括：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**屏幕空间**</td><td>屏幕空间渲染模式，将 UI 元素放置在屏幕上，渲染在场景之上。如果屏幕被调整大小或分辨率更改，画布将自动更改大小以匹配。</td></tr><tr><td>**摄像机空间**</td><td>摄像机空间渲染模式，将画布放置在指定摄像机前方给定距离处。UI 元素由此摄像机渲染，这意味着摄像机设置会影响 UI 的外观。如果摄像机设置为“透视”，则 UI 元素将以透视方式渲染，透视畸变程度可由摄像机视场角控制。如果屏幕被调整大小、分辨率更改或摄像机视锥更改，画布也将自动更改大小以匹配。</td></tr><tr><td>**世界空间**</td><td>世界空间渲染模式将画布像场景中的任何其他对象一样放置。画布的大小可以使用其变换手动设置，UI 元素将根据 3D 位置在场景中的其他对象前面或后面渲染。这对于希望成为世界一部分的 UI 非常有用。这也称为“叙事界面”。</td></tr><tr><td>**世界空间面向摄像机**</td><td>世界空间渲染模式将画布像场景中的任何其他对象一样放置，并使其面向摄像机。画布的大小可以使用其变换手动设置，UI 元素将根据 3D 位置在场景中的其他对象前面或后面渲染。这对于希望成为世界一部分的 UI 非常有用。这也称为“叙事界面”。</td></tr></tbody></table> |

## 将画布渲染到 GPU 纹理

画布可以直接渲染到 GPU 纹理，以便在材质或 VFX 中使用。只需将 `RenderMode` 更改为 `GPUTexture`，并提供 `OutputTexture`，它将用作画布元素的输出图像。请参见示例脚本：

```cs
using FlaxEngine;

namespace Game;

public class RenderCanvasToTexture : Script
{
    public GPUTexture MyTexture;

    public override void OnEnable()
    {
        // 分配一个新的 GPU 纹理并调整其大小
        MyTexture = new GPUTexture();
        var desc = GPUTextureDescription.New2D(300, 200, PixelFormat.R8G8B8A8_UNorm);
        MyTexture.Init(ref desc);

        // 将纹理链接到画布
        Actor.As<UICanvas>().OutputTexture = MyTexture;
    }

    public override void OnDisable()
    {
        // 释放引用并释放纹理内存
        Actor.As<UICanvas>().OutputTexture = null;
        Destroy(ref MyTexture);
    }
}
```
