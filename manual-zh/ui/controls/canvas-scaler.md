# 画布缩放器

**CanvasScaler** 控件是一个用于用户界面的缩放组件，用于适配多种不同的游戏分辨率（例如手机屏幕）。它可以用于将 UI 约束到最小/最大分辨率，或根据显示 DPI 或分辨率进行缩放。使用 **缩放** 属性来定义缩放器的逻辑，使用 **缩放因子** 属性来手动控制 UI 缩放。

| 模式             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **恒定像素大小** | 以像素为单位对整个 UI 应用恒定缩放。                         |
| **恒定物理大小** | 以物理单位（取决于屏幕 DPI）对整个 UI 应用恒定缩放。确保 UI 无论屏幕分辨率如何都具有特定的现实世界大小。 |
| **随分辨率缩放** | 根据屏幕分辨率对 UI 应用最小/最大缩放。确保 UI 大小不会低于最小分辨率或超过最大分辨率，以保持其可读性。 |
| **随 DPI 缩放**  | 根据屏幕 DPI 对 UI 应用缩放曲线。                            |
