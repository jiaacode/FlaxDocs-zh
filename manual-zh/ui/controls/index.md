* # 控件

  使用 Flax 构建 UI 的游戏通过**控件**来实现。每个控件都是一个独立的对象，仅实现最基本的变换、背景色和可见性等概念。更具体的逻辑，如点击事件、文本绘制、子控件布局等，可以通过使用特定的控件类型来实现。Flax 提供了一套完善的即用型控件，可用于游戏的 GUI。要创建你自己的控件类型，请参阅相关教程[此处](../tutorials/create-custom-control.md)。
