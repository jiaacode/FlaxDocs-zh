# 铰链关节

![铰链关节](media/hinge-joint.gif)

**铰链关节** 从其两个连接的刚体上移除除了单个旋转自由度之外的所有自由度（例如门铰链）。

## 属性

![属性](media/hinge-joint-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **目标**         | 关节的目标 Actor。必须是 **刚体** 或 **角色控制器**。        |
| **断开力**       | 确定关节在断开前可以承受的最大力。断开的关节不再参与物理模拟。 |
| **断开扭矩**     | 确定关节在断开前可以承受的最大扭矩。断开的关节不再参与物理模拟。 |
| **启用碰撞**     | 确定是否启用由关节管理的两个刚体之间的碰撞。                 |
| **启用自动锚点** | 确定是否根据关节的世界空间框架（在创建关节时计算）使用自动目标锚点位置和旋转。 |
| **目标锚点**     | 这是相对于目标 Actor 定位关节框架的相对姿态位置。            |
| **目标锚点旋转** | 这是相对于目标 Actor 定位关节框架的相对姿态旋转。            |
| **标志**         | 控制关节行为。                                               |
| **限制**         | 确定关节的限制。限制将运动约束到指定的角度范围。你必须启用关节上的限制标志才能使此功能生效。请参阅 [LimitAngularRange](https://docs.flaxengine.com/api/FlaxEngine.LimitAngularRange.html) 以了解更多信息。 |
| **驱动**         | 确定关节的驱动属性。它将关节的角速度驱动到特定值。你必须启用关节上的驱动标志才能使驱动处于活动状态。请参阅 [HingeJointDrive](https://docs.flaxengine.com/api/FlaxEngine.HingeJointDrive.html) 以了解更多信息。 |
