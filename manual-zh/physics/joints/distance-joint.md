# 距离关节

![距离关节](/manual/media/distance-joint.gif)

**距离关节** 将约束 Actor 的原点保持在一定的距离范围内。该范围可以同时具有上限和下限。

## 属性

![属性](/manual/media/distance-joint-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **目标**         | 关节的目标 Actor。必须是 **刚体** 或 **角色控制器**。        |
| **断开力**       | 确定关节在断开前可以承受的最大力。断开的关节不再参与物理模拟。 |
| **断开扭矩**     | 确定关节在断开前可以承受的最大扭矩。断开的关节不再参与物理模拟。 |
| **启用碰撞**     | 确定是否启用由关节管理的两个刚体之间的碰撞。                 |
| **启用自动锚点** | 确定是否根据关节的世界空间框架（在创建关节时计算）使用自动目标锚点位置和旋转。 |
| **目标锚点**     | 这是相对于目标 Actor 定位关节框架的相对姿态位置。            |
| **目标锚点旋转** | 这是相对于目标 Actor 定位关节框架的相对姿态旋转。            |
| **标志**         | 控制关节行为。                                               |
| **最小距离**     | 最小距离必须不大于最大距离。仅在设置了 MinDistance 标志时使用。 |
| **最大距离**     | 最大距离必须不小于最小距离。仅在设置了 MaxDistance 标志时使用。 |
| **容差**         | 关节的误差容差。在关节激活之前，距离超出关节 [min, max] 范围的距离。默认值：25，范围：[0.1, float.MaxValue]。 |
| **弹簧参数**     | 弹簧参数。仅在设置了 Spring 标志时使用。请参阅 [SpringParameters](https://docs.flaxengine.com/api/FlaxEngine.SpringParameters.html) 以了解更多信息。 |
