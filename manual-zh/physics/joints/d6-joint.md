# D6 关节

![D6 关节](/manual/media/d6-joint.png)

**D6 关节** 是最可定制的关节类型。此关节类型可用于创建所有其他内置关节类型，并设计你自己的自定义关节，但使用起来不太直观。它允许指定线性约束（例如用于滑动器）、扭转约束（绕 X 轴旋转）和摆动约束（绕 Y 轴和 Z 轴旋转）。它还允许你将约束限制为仅特定轴，或完全锁定特定轴。

D6 关节默认由布娃娃生成器使用，因为它们可用于模拟各种类型的人体关节行为。在调试视图中，当选中关节时，会以线框球体显示位置和目标位置点。扭转限制以黄色弧线或黄色圆盘显示。摆动锥体以绿色显示，箭头指向其中心。

## 关节轴

D6 关节使用（顾名思义）6 个不同的可能运动轴：
* **X** - X 轴上的线性运动。
* **Y** - Y 轴上的线性运动。
* **Z** - Z 轴上的线性运动。
* **扭转** - 绕 X 轴旋转。
* **摆动Y** - 绕 Y 轴旋转。
* **摆动Z** - 绕 Z 轴旋转。

每个轴可以使用 3 种运动类型之一：
* **锁定** - 轴不可移动。
* **受限** - 轴将受到指定限制的约束（例如，参见线性/扭转/摆动限制）。
* **自由** - 轴不受约束。

每个轴都可以独立调整。

## 属性

![属性](/manual/media/d6-joint-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **目标**         | 关节的目标 Actor。必须是 **刚体** 或 **角色控制器**。        |
| **断开力**       | 确定关节在断开前可以承受的最大力。断开的关节不再参与物理模拟。 |
| **断开扭矩**     | 确定关节在断开前可以承受的最大扭矩。断开的关节不再参与物理模拟。 |
| **启用碰撞**     | 确定是否启用由关节管理的两个刚体之间的碰撞。                 |
| **启用自动锚点** | 确定是否根据关节的世界空间框架（在创建关节时计算）使用自动目标锚点位置和旋转。 |
| **目标锚点**     | 这是相对于目标 Actor 定位关节框架的相对姿态位置。            |
| **目标锚点旋转** | 这是相对于目标 Actor 定位关节框架的相对姿态旋转。            |
| **线性限制**     | 确定用于约束平移自由度的线性限制。请参阅 [LimitLinear](https://docs.flaxengine.com/api/FlaxEngine.LimitLinear.html) 以了解更多信息。 |
| **扭转限制**     | 确定用于约束扭转（绕 X 轴旋转）自由度的角度限制。请参阅 [LimitAngularRange](https://docs.flaxengine.com/api/FlaxEngine.LimitAngularRange.html) 以了解更多信息。 |
| **摆动限制**     | 确定用于约束摆动（绕 Y 轴和 Z 轴旋转）自由度的锥体限制。请参阅 [LimitConeRange](https://docs.flaxengine.com/api/FlaxEngine.LimitConeRange.html) 以了解更多信息。 |
