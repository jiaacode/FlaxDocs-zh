# 球形关节

**球形关节** 约束两个 Actor 的原点重合。
它移除所有平移自由度，但允许所有旋转自由度。本质上，这确保了两个刚体的锚点始终重合。刚体被允许绕锚点旋转，并且它们的旋转可以被椭圆锥体限制。

## 属性

![属性](media/spherical-joint-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **目标**         | 关节的目标 Actor。必须是 **刚体** 或 **角色控制器**。        |
| **断开力**       | 确定关节在断开前可以承受的最大力。断开的关节不再参与物理模拟。 |
| **断开扭矩**     | 确定关节在断开前可以承受的最大扭矩。断开的关节不再参与物理模拟。 |
| **启用碰撞**     | 确定是否启用由关节管理的两个刚体之间的碰撞。                 |
| **启用自动锚点** | 确定是否根据关节的世界空间框架（在创建关节时计算）使用自动目标锚点位置和旋转。 |
| **目标锚点**     | 这是相对于目标 Actor 定位关节框架的相对姿态位置。            |
| **目标锚点旋转** | 这是相对于目标 Actor 定位关节框架的相对姿态旋转。            |
| **标志**         | 控制关节行为。                                               |
| **限制**         | 确定将关节运动约束到特定最小和最大距离的限制。你必须启用关节上的限制标志才能使其生效。请参阅 [LimitConeRange](https://docs.flaxengine.com/api/FlaxEngine.LimitConeRange.html) 以了解更多信息。 |
