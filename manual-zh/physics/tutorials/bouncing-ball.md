# 操作指南：创建弹跳球

![弹跳球](/manual/media/ball.gif)

在本教程中，你将学习如何创建并使用带有碰撞体和物理材质的刚体来制作一个弹跳球。

请参阅[刚体](../rigid-bodies.md)页面以了解有关刚体的更多信息。

## 1. 创建刚体

首先，我们需要生成一个刚体并将其放置在关卡中的某个位置。使用 *工具箱* 窗口（*物理* 部分）或 *场景* 窗口的上下文菜单。

![生成刚体](/manual/media/spawn-rigidbody.jpg)

## 2. 添加碰撞体和模型

向刚体添加 **球体碰撞体** Actor 和 **球体模型**（作为子级），使其具有物理形状和视觉表现。

为此，使用 *工具箱* 窗口并将其拖放到 *场景* 窗口中的刚体 Actor 上：

* 从 **物理** 部分拖放一个 **球体碰撞体**
![生成球体碰撞体](/manual/media/spawn-sphere-collider.jpg)

* 从 **基本模型** 部分拖放一个 **球体**
![生成球体模型](/manual/media/spawn-sphere-model.jpg)

## 3. 创建物理材质

使用 *内容* 窗口创建一个新的物理材质资源。右键单击并选择选项 **新建 -> 物理 -> 物理材质**。指定其名称并按 *Enter* 确认。

![新建物理材质](/manual/media/new-physical-material-1.jpg)

打开创建的资源（双击它），并将 **恢复系数** 设置为 `1`，这样球会弹跳得更高。记得使用 *磁盘* 图标保存资源。

![编辑物理材质](/manual/media/edit-physical-material-1.jpg)

## 4. 将材质分配给碰撞体

将创建的物理材质拖放到球体碰撞体的 **材质** 属性中。

![设置物理材质](/manual/media/set-physical-material.jpg)

## 5. 测试！

点击 **播放** 按钮并测试弹跳球。你也可以在地面上使用相同的物理材质来模拟更多的弹跳。

![弹跳球](/manual/media/ball.gif)
