# 盒体碰撞体

![盒体碰撞体](media/box.png)

一种盒形的基本碰撞体。

## 属性

![属性](media/box-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **是触发器** | 如果勾选，碰撞体将作为触发器。请参阅[触发器](../triggers.md)文档以了解更多信息。 |
| **接触偏移** | 距离小于其 ContactOffset 值之和的碰撞体将生成接触。接触偏移必须为正。接触偏移允许碰撞检测系统即使在对象略微分离时也能主动强制执行接触约束。 |
| **材质**     | 用于定义碰撞体物理属性的物理材质。                           |
| **中心**     | 碰撞体的中心，在对象的局部空间中测量。                       |
| **大小**     | 盒体的大小，在对象的局部空间中测量。它将按 Actor 的世界缩放进行缩放。 |
