# 网格碰撞体

![网格碰撞体](/manual/media/mesh.png)

一种由任意网格表示的碰撞体。请参阅[碰撞数据](collision-data.md)资源文档，了解有关创建凸包网格和三角形网格的更多信息。

## 属性

![属性](/manual/media/mesh-properties.jpg)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **是触发器** | 如果勾选，碰撞体将作为触发器。请参阅[触发器](../triggers.md)文档以了解更多信息。 |
| **接触偏移** | 距离小于其 ContactOffset 值之和的碰撞体将生成接触。接触偏移必须为正。接触偏移允许碰撞检测系统即使在对象略微分离时也能主动强制执行接触约束。 |
| **材质**     | 用于定义碰撞体物理属性的物理材质。                           |
| **中心**     | 碰撞体的中心，在对象的局部空间中测量。                       |
| **碰撞数据** | 链接的碰撞数据资源，包含用于表示网格碰撞体形状的凸包网格或三角形网格。 |
