# 碰撞体

![碰撞体](/manual/media/colliders.png)

**碰撞体** 用于定义对象的物理形状。碰撞体是不可见的，不需要与对象的网格形状完全相同，实际上，粗略的近似通常更高效，并且在游戏玩法中难以察觉差异。

Flax 提供了各种 *基本* 碰撞体类型，例如盒体、球体或胶囊体。使用简单的碰撞体形状有助于优化游戏性能。但是，如果你需要为对象提供更精细和精确的碰撞，请使用网格碰撞体。

## 静态碰撞体

如果碰撞体没有父级[刚体](../rigid-bodies.md)，则它将是静态碰撞体。
静态碰撞体用于始终停留在同一位置且永不移动的关卡几何体。进入的刚体对象将与静态碰撞体碰撞，但不会移动它。

## 刚体碰撞体

如果碰撞体有[刚体](../rigid-bodies.md)父级，则它将用于定义其形状。
刚体碰撞体由物理引擎完全模拟，可以对碰撞和从脚本施加的力做出反应。它们可以与其他对象（包括静态碰撞体）碰撞，是在使用物理的游戏中最常用的碰撞体配置。

## 调试视图

![物理碰撞体调试视图](/manual/media/physics-colliders-debug-view.png)

在编辑器视口中，使用小部件选项 **视图 -> 调试视图 -> 物理碰撞体** 来启用绘制碰撞形状的几何体。它可以用于分析物理场景。静态碰撞体为蓝色，动态碰撞体为粉色，地形为绿色，角色为黄色。

或者，你可以使用小部件选项 **视图 -> 视图标志 -> 物理调试** 来分析物理形状和物理模拟。
