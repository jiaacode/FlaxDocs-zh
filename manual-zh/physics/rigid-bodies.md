# 刚体

![刚体](media/rigidbodies.gif)

**刚体** 是可以碰撞并提供物理行为的动态对象。它们的运动基于物理力，例如重力。通常，刚体是盒子、家具和障碍物等可移动或可推动物体的不错选择。刚体使用附加的[碰撞体](colliders/index.md)来定义其物理 *形状*。

## 创建刚体

你可以使用 *工具箱* 窗口或 *场景* 窗口中的上下文菜单在编辑器内轻松生成刚体 Actor。

![添加刚体](tutorials/media/spawn-rigidbody.jpg)

你也可以在运行时从 C# 代码生成刚体。以下是一个生成并发射子弹的示例：

```cs
var ball = new RigidBody();
var ballCollider = new SphereCollider();
var ballModel = new StaticModel();
ballModel.Model = SphereModel;
ballModel.Parent = ball;
ballCollider.Parent = ball;
ball.UseCCD = true;
ball.Transform = Transform;
ball.LinearVelocity = Actor.Direction * 600.0f;
Destroy(ball, 5.0f);
```

## 属性

![刚体属性](media/rigidbody-properties.jpg)

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **是运动学的**         | 如果勾选，为刚体启用运动学模式。请参阅下面的 [运动学刚体](rigid-bodies.md#kinematic-rigidbodies) 部分。 |
| **启用模拟**           | 如果勾选，将为刚体启用模拟和碰撞检测。                       |
| **使用 CCD**           | 如果勾选，将为此对象使用连续碰撞检测（CCD）。                |
| **启用重力**           | 如果勾选，对象应施加重力。                                   |
| **启动时唤醒**         | 如果勾选，对象应在启动时唤醒。否则它将初始处于休眠状态。     |
| **线性阻尼**           | 用于减慢对象速度。阻尼越高，对象减速越快。                   |
| **角阻尼**             | 用于减慢对象的旋转。阻尼越高，旋转减速越快。                 |
| **最大角速度**         | 用于钳制刚体的角速度，以避免快速旋转体的数值不稳定性。由于这可能会阻止车轮等物体的预期快速旋转，你可以为每个刚体覆盖此值。 |
| **质量**               | 对象质量值根据密度和附加的碰撞体计算（考虑其他参数，如 *MassScale*）。你可以启用 *OverrideMass* 并提供自定义值来覆盖它。 |
| **质量缩放**           | 每个实例的质量缩放。仅用于自动计算的质量，不用于覆盖的值。   |
| **缩放变化时更新质量** | 如果勾选，当 Actor 缩放变化时，质量将更新。仅当质量未被覆盖时使用。 |
| **质心偏移**           | 此对象质心的自定义偏移，从计算位置偏移。在 Actor 局部空间中。 |
| **约束**               | 对象运动约束标志，定义模拟对象允许的自由度。                 |

## 刚体约束

动态刚体的运动和旋转可以使用约束进行锁定。它们可用于提供一种机制来锁定沿/绕特定轴或一组轴的运动，以约束对象运动。这通常用于创建“铰链”或“旋转”效果。

| 约束           | 描述                       |
| -------------- | -------------------------- |
| **无**         | 无约束。                   |
| **锁定位置 X** | 冻结沿 X 轴的运动。        |
| **锁定位置 Y** | 冻结沿 Y 轴的运动。        |
| **锁定位置 Z** | 冻结沿 Z 轴的运动。        |
| **锁定旋转 X** | 冻结绕 X 轴的旋转。        |
| **锁定旋转 Y** | 冻结绕 Y 轴的旋转。        |
| **锁定旋转 Z** | 冻结绕 Z 轴的旋转。        |
| **锁定位置**   | 冻结沿所有轴的运动。       |
| **锁定旋转**   | 冻结绕所有轴的旋转。       |
| **锁定全部**   | 冻结绕所有轴的旋转和运动。 |

## 运动学刚体

运动学刚体是特殊的动态 Actor，不受力（例如重力）影响，也没有动量。它们被视为具有无限质量，可以将常规动态 Actor 推开。运动学对象不会与静态或其他运动学对象碰撞。

运动学刚体非常适合移动平台、门或角色，在这些场景中需要直接的运动控制。

> [!NOTE]
> 运动学刚体与 CCD 不兼容。
