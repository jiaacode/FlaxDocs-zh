# 布料

![布料](/manual/media/cloth.gif)

**布料** Actor 使用网格的顶点作为布料粒子，并模拟具有物理属性、力、约束和碰撞的效果。通过将其添加到静态模型或动画模型 Actor（作为子级），你可以选择子网格将其转化为布料。

### 设置

1. 添加布料 Actor

![新建布料 Actor](/manual/media/new-cloth.png)

在模型上使用 **新建 -> 物理 -> 布料**，或从[工具箱](../editor/windows/toolbox.md)中拖放布料。这将把布料添加到模型 Actor（静态模型或动画模型）下。每个模型 Actor 可以有多个布料——例如，每个模型的网格或 LOD 对应一个。此外，布料可以在预制体窗口中使用以实现可重用性（例如，在游戏角色服装部件上）。

使用 *网格* 属性选择父级模型的网格（来自特定 LOD），以用布料模拟覆盖。网格引用选择器将显示模型中的所有网格。

2. 绘制布料

![布料绘制](/manual/media/cloth-paint.gif)

现在你可以使用鼠标左键在布料顶点上绘制，并标记不可移动的顶点（用红色标记）。属性面板将显示布料设置和笔刷设置（例如笔刷半径或绘制值）。点击以绘制顶点，点击时按住 `Ctrl` 键可反向绘制（例如绘制可移动顶点）。你可以调整笔刷属性以使用更精确的绘制，或调整半移动顶点的绘制值。

布料绘制值在 `0-1` 范围内（含），其中 `0` 表示无移动（锁定），`1` 表示移动距离可达 *最大粒子距离*（从原始布料位置算起）。

3. 试试看！

在编辑器中运行游戏以查看模拟结果。如果你移动布料的父级模型，它将表现为逼真的织物。你可以控制施加在布料上的风力。

### 碰撞

当启用 *场景碰撞* 选项时，布料系统将收集布料 Actor 附近的碰撞体（匹配布料的[物理层遮罩](physics-settings.md)，每几帧异步更新一次）。然后布料模拟将支持与环境的运行时碰撞（包括静态和动态）。

如果布料与几何体过度相交，请使用 *碰撞厚度* 属性来增加布料粒子与碰撞体之间的边距。此外，在创建较厚的织物（例如地毯或窗帘）时，自碰撞设置可能非常有用。

每个布料的总碰撞体限制为 32 个球体和 32 个平面——与凸体碰撞需要使用少于 32 个平面作为限制才能正确表现。每个胶囊碰撞体使用该限制中的 2 个球体。由于计算开销大和数据量大，不支持三角形网格和高度场（地形）碰撞。

### 角色

![布料角色](/manual/media/cloth-character.gif)

布料可以用于[蒙皮模型](../animation/skinned-model/index.md)（甚至可以与 *Blend Shapes* 同时使用）。你可以在蒙皮模型的子网格上使用布料（例如角色头发、服装部件如肩带）或整个网格（如上方 GIF 所示）。在这两种情况下，确保精确绘制应继续接收动画的不可移动粒子。你可以使用 *填充* 按钮为所有粒子分配特定的绘制值，然后手动标记可移动粒子。

使用[调试视图](../graphics/debugging-tools/debug-view.md)（例如 *物理碰撞体*）来分析布料表面及其与角色/环境的碰撞。布料可以使用自定义物理层遮罩来定义其应与哪些对象碰撞（例如，排除与角色控制器主体的碰撞，但仅与手动指定的模型骨骼碰撞体碰撞——如上方 GIF 所示）。

### 技术细节

布料使用 [NvCloth](https://github.com/NVIDIAGameWorks/NvCloth) 库来运行模拟（仅在 CPU 上）。它支持所有平台，**Flax 通过[作业系统](../scripting/advanced/multithreading.md)在 Fixed Update 之后异步运行模拟**（此时物理世界已更新，速率可能与游戏渲染速率不同）。由于布料模拟对网格数据（可能很大）执行操作，它广泛使用作业系统和高效的数据管理来处理游戏中大量布料的模拟。此外，你可以调整 *剔除距离* 并禁用 *屏幕外更新* 选项来控制对性能的影响。如果你的游戏使用自定义着色或布料是未照明网格，则可以取消勾选 *计算法线* 选项以获得更高性能。

### 属性

![布料属性](/manual/media/cloth-properties.png)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **网格**         | 用于布料模拟的网格（来自特定 LOD 的单个网格）。              |
| 力               |                                                              |
| **重力缩放**     | 应用于布料粒子重力的缩放乘数（缩放全局重力）。               |
| **阻尼**         | 布料粒子速度的阻尼。0：速度不受影响。1：速度归零。           |
| **线性阻力**     | 应用于布料粒子的速度比例。0：布料粒子不受影响。1：全局布料粒子速度被阻尼。 |
| **角阻力**       | 应用于旋转布料粒子的角速度比例。0：布料粒子不受影响。1：全局布料粒子角速度被阻尼。 |
| **线性惯性**     | 应用于布料粒子的线性加速度比例。0：布料粒子不受影响。1：物理正确的线性加速度。 |
| **角惯性**       | 应用于旋转布料粒子的角加速度比例。0：布料粒子不受影响。1：物理正确的角加速度。 |
| **离心惯性**     | 应用于旋转布料粒子的角速度比例。0：布料粒子不受影响。1：物理正确的角速度。 |
| **空气阻力系数** | 定义空气对布料粒子施加的阻力大小。设置为 0 以禁用风。        |
| **空气升力系数** | 定义空气对布料粒子施加的升力大小。设置为 0 以禁用风。        |
| **空气密度**     | 定义用于阻力和升力计算的空气流体密度。                       |
| 碰撞             |                                                              |
| **摩擦力**       | 控制布料粒子与碰撞体之间的摩擦力大小。0：禁用摩擦力。        |
| **质量缩放**     | 控制碰撞期间布料粒子质量增加的速度。0：禁用质量缩放。        |
| **场景碰撞**     | 启用与场景几何体（动态和静态）的碰撞。禁用此功能以提高不需要碰撞的布料的性能。 |
| **连续碰撞检测** | 启用连续碰撞检测（CCD），通过计算布料粒子与碰撞体之间的撞击时间来改善碰撞。质量的提高可能会影响性能。 |
| **碰撞厚度**     | 模拟布料的附加厚度，以防止与附近碰撞体相交。                 |
| **自碰撞距离**   | 碰撞的布料粒子之间必须保持的最小距离（以米为单位）。0：禁用自碰撞。 |
| **自碰撞刚度**   | 自碰撞约束的刚度。0：禁用自碰撞。                            |
| 模拟             |                                                              |
| **求解器频率**   | 目标布料求解器每秒迭代次数。每秒执行的迭代次数可能因多种性能因素而异。但是，无论设置的值如何，每帧至少解决一次迭代。 |
| **剔除距离**     | 运行布料模拟的摄像机最大距离。用于提高性能并跳过更新太远的布料。物理系统可能会降低足够远的布料的更新率（例如该距离的一半）。0 表示禁用任何剔除。 |
| **屏幕外更新**   | 如果为 true，即使 Actor 在任何摄像机视野之外，布料也会更新。否则，当 Actor 在屏幕外时，布料模拟将停止运行。 |
| **最大粒子距离** | 布料粒子可以从原始位置（在 Actor 的局部空间内）移动的最大距离。按绘制的逐粒子值（0-1）缩放，以限制特定粒子的移动。 |
| **计算法线**     | 启用布料网格的自动法线向量计算，否则将使用原始网格法线。     |
| **风速**         | 世界坐标中的风速向量（方向和大小）。较大的幅度施加更强的风力。确保空气阻力和空气升力系数非零以施加风力。 |
| 织物             |                                                              |
| **垂直**         | 垂直方向（沿重力方向）的拉伸或压缩约束。                     |
| **水平**         | 水平方向（垂直于重力）的拉伸或压缩约束。                     |
| **弯曲**         | 基于角度公式的面外弯曲约束。                                 |
| **剪切**         | 沿（通常）对角线的平面剪切约束。                             |
| 织物轴           |                                                              |
| **刚度**         | 拉伸和压缩约束的刚度值。0：禁用它。                          |
| **刚度乘数**     | 拉伸和压缩约束的缩放值。0：不应用拉伸和压缩约束。1：完全应用拉伸和压缩约束。 |
| **压缩限制**     | 约束的压缩限制。                                             |
| **拉伸限制**     | 约束的拉伸限制。                                             |
