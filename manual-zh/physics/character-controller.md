# 角色控制器

![角色控制器](/manual/media/physics4.gif)

**角色控制器** 是一种用于玩家对象的 Actor 类型，提供基于碰撞的物理效果，同时也允许对游戏角色（玩家或 NPC）进行更多自定义设置。它是第一人称和第三人称游戏的常见选择。

## 角色体积

角色使用 **胶囊体** 定义，由中心位置、垂直高度和半径组成。高度是胶囊体两端球体中心之间的距离。例如，胶囊体在攀爬楼梯时具有更好的行为。

![角色体积](/manual/media/cc-capsule.png)

要实现角色蹲伏或动态尺寸更改，请使用 `Resize(float height, float radius)`。它会更新角色高度和中心位置，以确保其脚部位置保持不变。它通过相应地调整碰撞体中心以适应高度差异，来保持相同的 Actor 位置，使其保持在胶囊体中间。

## 自动踏步

如果没有自动踏步，角色很容易卡在地面网格的轻微高度变化处。这感觉不自然，因为在现实世界中，人只会越过这些小的障碍物。

你可以使用 [CharacterController.SlopeLimit](https://docs.flaxengine.com/api/FlaxEngine.CharacterController.html#FlaxEngine_CharacterController_SlopeLimit) 和 [CharacterController.StepOffset](https://docs.flaxengine.com/api/FlaxEngine.CharacterController.html#FlaxEngine_CharacterController_StepOffset) 属性来调整自动踏步行为。

## 属性

![属性](/manual/media/cc-properties.jpg)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **是触发器**     | *未使用。继承自 Collider 基类。*                             |
| **接触偏移**     | 距离小于其 ContactOffset 值之和的碰撞体将生成接触。接触偏移必须为正。接触偏移允许碰撞检测系统即使在对象略微分离时也能主动强制执行接触约束。 |
| **材质**         | 用于定义碰撞体物理属性的物理材质。                           |
| **中心**         | 碰撞体的中心，在对象的局部空间中测量。                       |
| **半径**         | 球体的半径，在对象的局部空间中测量。它将按 Actor 的世界缩放进行缩放。 |
| **高度**         | 胶囊体的高度，在对象的局部空间中测量。它将按 Actor 的世界缩放进行缩放。 |
| **坡度限制**     | 限制碰撞体仅攀爬坡度（以度为单位）小于指示值的斜坡。         |
| **不可行走模式** | 指定角色控制器的不可行走模式。可能的选项：<br><table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**阻止攀爬**</td><td>阻止角色攀爬不可行走的斜坡，但不会以其他方式移动它。</td></tr><tr><td>**阻止攀爬并强制滑动**</td><td>阻止角色攀爬不可行走的斜坡，并强制其沿这些斜坡滑下。</td></tr></tbody></table> |
| **原点模式**     | 指定角色控制器胶囊体的放置方式。可能的选项：<br><table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**胶囊体中心**</td><td>角色原点从胶囊体中心开始（包括正确的 Center 偏移）。</td></tr><tr><td>**底部**</td><td>角色原点从胶囊体底部位置开始，即角色脚部位置。</td></tr></tbody></table> |
| **步高**         | 只有当台阶离地面比指示值更近时，角色才会踏上一个台阶。这不应大于角色控制器的高度，否则会产生错误。 |
| **向上方向**     | 角色向上向量。                                               |
| **最小移动距离** | 要考虑的最小移动距离。如果移动距离较小，角色则不会移动。这用于在剩余移动距离较小时停止递归运动算法。 |
| **自动重力**     | 自动重力施加模式。如果游戏逻辑控制角色运动速度（包括重力），可以关闭；如果应该将重力与动画运动中的根运动一起施加，则可以打开。 |
