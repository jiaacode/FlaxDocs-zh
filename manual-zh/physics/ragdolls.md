# 布娃娃系统

![布娃娃模拟](/manual/media/knight-ragdolls.gif)

**布娃娃** 是一种 Actor，可以用物理模拟的骨骼覆盖动画模型的骨骼。带有物理碰撞形状并通过关节连接的骨骼节点层级结构可用于模拟逼真的身体行为。此功能可用于在游戏中生成角色的程序化死亡动画，或模拟骨骼中应表现得更程序化的部分（例如尾巴）。

## 创建

![创建新的布娃娃](/manual/media/new-ragdoll.png)

创建布娃娃最快的方法是使用编辑器中的 **内置生成器工具**，在场景树中 *右键单击* **动画模型**，然后选择选项 **创建布娃娃**。它将生成一个布娃娃作为其子级，并包含完整的物理骨骼层级。

现在，你可以直接按播放并测试它。它将自动用模拟的骨骼覆盖骨骼姿态（无论是否使用动画图）。你可以将 `BonesWeight` 默认设置为 `0`，并在需要时从代码切换为 `1` 以启用角色的物理模拟。布娃娃可以在动画状态和模拟状态之间混合，或仅对指定的骨骼集使用部分模拟。此外，如果某个骨骼仅使用动画，它将相应地动画，因此你可以使用布娃娃碰撞形状通过射线投射进行命中测试。

可以使用预制体来制作布娃娃，使其可重用，甚至可以为同一模型添加多个布娃娃设置（只需确保一次只启用一个）。Flax 布娃娃系统不假设角色是人形，而是通用的，适用于所有骨骼网格，这意味着它可以用于动物或怪物。

## 编辑器

![布娃娃编辑器和属性](/manual/media/ragdoll-editor.png)

选中时，布娃娃在编辑器属性面板中有一组工具可使用：
* **重建** - 打开一个带有布娃娃重建设置的弹出窗口。如果你的角色非常小或非常大，请调整 *最小骨骼大小* 以获得更好的结果。你还可以使用 *碰撞边距* 属性缩放创建的碰撞形状。
* **重建/添加骨骼** - 打开一个带有骨骼名称的选择器以重建或添加。它将忽略任何最小骨骼大小限制，并创建它以反映实际使用该骨骼的网格部分。已存在的节点以白色文本显示，缺失的节点以灰色显示以区分。
* **移除骨骼** - 打开一个带有骨骼名称的选择器以快速移除。它还将修复与此骨骼相关的任何关节，以确保移除骨骼后布娃娃能正常表现。
* **选择所有关节** - 选择布娃娃骨骼使用的所有关节。
* **选择所有碰撞体** - 选择布娃娃骨骼使用的所有碰撞体形状。
* **选择所有刚体** - 选择布娃娃骨骼使用的所有刚体。

通过使用这些工具，你可以生成或移除骨骼骨骼，并快速同时调整多个对象。此外，如果选中，布娃娃将显示所有关节和碰撞体的调试形状。要进行更精确的调整，你可以选择特定的碰撞体和关节。每个骨骼体默认使用胶囊体，但这可以修改或替换为其他形状（例如盒体），甚至每个骨骼使用多个形状。要了解有关调整 **D6 关节** 的更多信息，请参阅[此页面](joints/d6-joint.md)。

> [!NOTE]
> 要快速更改关节类型，请在场景树中使用 *右键单击* 并选择选项 **转换** 以选择不同类型的关节。编辑器将自动保持关节目标锚点框架。

在底层，布娃娃 Actor 会查找名称与骨骼节点匹配的 *Rigidbody* 子级，并使用它们进行模拟或使用动画骨骼姿态更新。根据场景和布娃娃复杂度，物理引擎甚至可以同时动态模拟数百个布娃娃，同时仍保持稳定的性能。请注意，默认情况下，如果摄像机远离动画模型，它会使用 LOD 来调整模型和姿态更新的频率，这在某些情况下可能很明显。这种技术可以在大型世界中节省性能——远处的模型每 2、3、4 帧或更少更新一次。

## 属性

| 属性                   | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **骨骼权重**           | 默认骨骼权重，其中 `0` 表示完全动画骨骼，`1` 表示完全模拟骨骼。可用于控制所有骨骼模拟模式，但会被每个骨骼的 *BonesWeights* 覆盖。 |
| **骨骼权重**           | 布娃娃模拟的每个骨骼权重。键是 *骨骼名称*，值是 *混合权重*，其中 `0` 表示完全动画骨骼，`1` 表示完全模拟骨骼。可用于控制每个骨骼的模拟。 |
| **位置求解器迭代次数** | 物理求解器应为此布娃娃中的刚体执行的最小位置迭代次数。较高的值可提高稳定性，但会影响性能。 |
| **速度求解器迭代次数** | 物理求解器应为此布娃娃中的刚体执行的最小速度迭代次数。较高的值可提高稳定性，但会影响性能。 |
| **最大脱离速度**       | 布娃娃的刚体移出穿透状态时的最大脱离速度。使用此属性可以平滑对象移出碰撞状态并防止不稳定运动。 |
