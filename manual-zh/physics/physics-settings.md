# 物理设置

**物理设置资源** 用于指定初始物理模拟配置。实际上，其某些选项只能在物理引擎启动时设置，因此可能必须使用该资源。但是，大多数物理模拟选项可以在运行时使用 [Physics](https://docs.flaxengine.com/api/FlaxEngine.Physics.html) 类进行调整。

## 创建物理设置

1. 在 *内容* 窗口中导航到 Content 目录

2. 右键单击并选择选项 **新建 -> 设置**，指定资源名称（例如 *物理设置*）并按 *Enter*
   <br>![教程](/manual/media/new-settings.png)

3. 选择选项 **物理设置** 并按下 **创建** 按钮
   <br>![教程](/manual/media/physics-settings-new.png)

4. 双击资源以打开并编辑它
   <br>![教程](/manual/media/empty-physics-settings.png)

## 使用物理设置

你可以创建任意数量的物理设置资源（甚至每个平台的专用版本），但在游戏构建时只能使用一个。使用 **游戏设置** 资源（始终位于 `Content/GameSettings.json`）来链接物理选项。如果你的游戏使用更高级的配置，你可以从代码中的构建脚本编辑游戏设置（使用 C# API 中的 [GameSettings.Load](https://docs.flaxengine.com/api/FlaxEditor.Content.Settings.GameSettings.html#FlaxEditor_Content_Settings_GameSettings_Load) 和 [GameSettings.Save](https://docs.flaxengine.com/api/FlaxEditor.Content.Settings.GameSettings.html#FlaxEditor_Content_Settings_GameSettings_Save__1___0_)）。

## 模拟选项

![模拟](/manual/media/physics-simulation-options.png)

| 属性                 | 描述                                                         |
| -------------------- | ------------------------------------------------------------ |
| **默认重力**         | 默认重力值（以 cm/(s^2) 为单位）。                           |
| **弹跳阈值速度**     | 物体弹跳所需的最小相对速度。模拟稳定性的典型值约为 0.2 * 重力。 |
| **摩擦力组合模式**   | 默认摩擦力组合模式，控制多个材质的摩擦力计算方式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**平均值**</td><td>使用接触材质的平均值：(a+b)/2。</td></tr><tr><td>**最小值**</td><td>使用接触材质的较小值：min(a,b)。</td></tr><tr><td>**相乘**</td><td>将接触材质的值相乘：a*b。</td></tr><tr><td>**最大值**</td><td>使用接触材质的较大值：max(a,b)。</td></tr></tbody></table> |
| **恢复系数组合模式** | 默认恢复系数组合模式，控制多个材质的恢复系数计算方式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**平均值**</td><td>使用接触材质的平均值：(a+b)/2。</td></tr><tr><td>**最小值**</td><td>使用接触材质的较小值：min(a,b)。</td></tr><tr><td>**相乘**</td><td>将接触材质的值相乘：a*b。</td></tr><tr><td>**最大值**</td><td>使用接触材质的较大值：max(a,b)。</td></tr></tbody></table> |
| **禁用 CCD**         | 如果勾选，CCD 将被忽略。当从不使用 CCD 时，这是一种优化，可以避免物理引擎内部检查它。 |
| **宽阶段类型**       | 模拟中使用的宽阶段算法。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**扫描和剪枝**</td><td>三轴扫描和剪枝。当许多对象处于休眠状态时，这是一个通用性好的选择，性能出色。</td></tr><tr><td>**多盒剪枝**</td><td>替代宽阶段算法，当所有对象都在移动或插入大量对象时，不会出现与 SAP 相同的性能问题。</td></tr><tr><td>**自动盒剪枝**</td><td>MBP 的重新实现，自动管理宽阶段区域。</td></tr><tr><td>**并行自动盒剪枝**</td><td>ABP 的并行实现。它通常可能是最快的（CPU）宽阶段，但可能比 ABP 使用更多内存。</td></tr></tbody></table> |
| **启用增强确定性**   | 在模拟中启用增强确定性。这会对性能产生影响。                 |
| **求解器类型**       | 模拟中使用的求解器类型。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**投影高斯-赛德尔迭代求解器**</td><td>迭代顺序脉冲求解器</td></tr><tr><td>**时间高斯-赛德尔求解器**</td><td>非线性迭代求解器。这种求解器可以改善收敛性，并更好地处理大质量比、长链和关节系统。它比默认求解器稍贵，并可能引入更多能量来纠正关节和接触误差。</td></tr></tbody></table> |

> [!TIP]
> 当启用连续碰撞检测（**CCD**）时，受影响的刚体不会在高速下穿过其他对象（也称为 *隧道效应*）。

## 帧率选项

![模拟](/manual/media/physics-framerate-options.png)

| 属性             | 描述                                           |
| ---------------- | ---------------------------------------------- |
| **最大增量时间** | 物理模拟步骤允许的最大增量时间（以秒为单位）。 |
| **启用子步**     | 是否对物理模拟进行子步。                       |
| **子步增量时间** | 单个模拟子步的增量时间（以秒为单位）。         |
| **最大子步数**   | 物理模拟的最大子步数。                         |

## 层矩阵选项

![模拟](/manual/media/physics-layers-options.png)

Flax 物理模拟支持基于层的碰撞检测。你可以为每个层指定碰撞遮罩，用于描述该层的对象是否可以与其他层的对象碰撞。

这使用全局层设置，并将其显示为层矩阵。使用复选框来定义层的碰撞遮罩。

## 其他

![其他](/manual/media/physics-other-options.png)

| 属性                       | 描述                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **支持运行时烘焙**         | 启用对在运行时烘焙物理碰撞形状几何体的支持。使用它来启用生成运行时地形碰撞或凸包网格碰撞体。 |
| **三角形网格最小面积阈值** | 面积小于或等于此值的三角形网格（CSG）中的三角形将从物理碰撞数据中移除。设置为小于或等于 0 以禁用。 |
| **查询命中触发器**         | 如果勾选，任何与标记为触发器的碰撞体相交的[射线投射](raycasting.md)或其他场景查询将返回命中结果。单个射线投射可以覆盖此行为。 |
