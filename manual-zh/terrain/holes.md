# 地形孔洞

![地形孔洞](/manual/media/terrain_pic_07.gif)

Flax 支持在地形中创建**逐顶点孔洞**。孔洞遮罩作为 *无效法线* 存储在地形图块高度图纹理中。这种打包方法允许保持地形高度有效而不会损失质量，除了地形孔洞周围的法线向量，它们使用固定值 `(0, 0, 1)` 指向上方（在世界空间中）。

地形碰撞烘焙会采样高度图，并在碰撞体形状中生成孔洞，以保持视觉和物理外观一致。因此，对象可以穿过地形孔洞掉落。

可以使用编辑器工具在 **工具箱 -> 地形 -> 雕刻 -> 工具模式 -> 孔洞** 中绘制孔洞。选择 **孔洞模式** 后，你可以使用鼠标在地形上添加孔洞。如果你按住 **Control** 键，则可以还原孔洞并清除遮罩。

为了在地形中看到孔洞，其材质需要支持使用孔洞层来遮罩区域。要实现这一点，请使用材质的 **遮罩** 属性和 **地形孔洞遮罩** 节点，如下所示：

![孔洞材质](/manual/media/terrain-holes-material.png)

要了解有关创建和使用地形孔洞的更多信息，请参阅相关教程[此处](tutorials/terrain-holes.md)。
