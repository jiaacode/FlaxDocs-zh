# 地形笔刷

Flax 支持使用各种笔刷编辑和绘制地形，以便直接在编辑器中轻松达到预期效果。请使用本文档页面了解 Flax 支持的笔刷类型。

> [!Note]
> 按住 **Shift** 键并使用 `鼠标滚轮` 控制笔刷大小。

## 圆形笔刷

**圆形笔刷** 是默认的地形笔刷，具有圆形形状并使用径向衰减。它支持多种衰减模式，以使用它创建有趣的效果。

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **大小**     | 笔刷大小（以世界单位为单位）。在此区域内，笔刷将至少产生一些效果。 |
| **衰减**     | 笔刷衰减，定义了从笔刷范围开始衰减的百分比。本质上，这描述了笔刷边缘的硬度。衰减为 0 表示笔刷将在整个范围内具有完全效果，边缘清晰。衰减为 1 表示笔刷仅在其中心具有完全效果，并且效果将在其整个区域到边缘减弱。 |
| **衰减类型** | 笔刷衰减类型。定义圆形笔刷衰减模式。请参见下面带有衰减类型的示例图像。 |

### 平滑衰减

![地形笔刷平滑](media/brush-smooth.png)

一种线性衰减，经过平滑处理以消除衰减开始和结束处的尖锐边缘。

### 线性衰减

![地形笔刷线性](media/brush-linear.png)

一种尖锐的线性衰减，没有圆角边缘。

### 球形衰减

![地形笔刷球形](media/brush-spherical.png)

一种半椭球形状的衰减，平滑开始并尖锐结束。

### 尖端衰减

![地形笔刷尖端](media/brush-tip.png)

一种突然开始并平滑椭球结束的衰减。与球形衰减相反。
