# 操作指南：导入地形

在本教程中，你将学习如何从高度图纹理生成地形。

## 1. 导入高度图

首先，你需要将高度图纹理导入到你的项目中。你可以按照[这些说明](../../graphics/textures/index.md)学习如何操作。

当导入 `.RAW` 或 `.EXR` 文件时，导入器会提示使用 *HdrRGBA* 格式且不压缩，这为地形提供了更好的质量（此外，RAW 文件需要是正方形尺寸）。如果你导入灰度高度图，请确保也使用 HDR 格式并禁用压缩，以减少生成地形中的伪影。你导入后的高度图将不会被引擎使用，因此不要将自己限制在特定的分辨率上。

Flax 支持**任何高度图尺寸**作为高度图。

![导入高度图选项](/manual/media/import-heightmap-options.png)

如果你没有任何高度图，可以下载此图像：

![示例高度图](/manual/media/heightmap4.png)

## 2. 打开场景

创建或打开现有关卡以向其添加新的地形。Flax 支持每个场景包含多个地形，因此没有限制。

## 3. 打开地形创建器对话框

使用主菜单按钮 **场景 -> 创建地形**。

![创建地形](/manual/media/create-terrain.png)

## 4. 调整选项

使用此对话框调整初始地形属性。选择**块大小**和要创建的**图块**数量。以下大多数属性可以在之后调整。此窗口支持创建没有导入高度图的地形，如[此教程](create-terrain.md)所示。

要了解有关地形图块、块和技术细节的更多信息，请参阅相关文档[此处](../index.md)。

![创建地形对话框](/manual/media/import-terrain-dialog.png)

## 5. 生成地形

按下 **创建** 按钮，查看添加到场景中的新地形。现在你可以[编辑](../editing.md)和[绘制](../painting.md)它了！

![导入地形](/manual/media/imported-terrain.jpg)
