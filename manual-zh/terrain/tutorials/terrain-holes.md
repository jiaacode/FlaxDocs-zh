# 操作指南：在地形中创建孔洞

在本教程中，你将学习如何创建和使用自定义地形材质，以在地形中生成孔洞。

## 1. 准备材质

使用你的地形材质或创建一个新的。你可以按照[这些说明](terrain-material.md)来操作。

## 2. 添加遮罩

创建 **Terrain Holes Mask** 节点，并将其与材质的 **Mask** 输入连接。它将用于丢弃被遮罩为 *不可见* 的地形表面像素。

![地形孔洞遮罩](../media/terrain-holes-material.png)

## 3. 绘制孔洞遮罩

选择 **工具箱 -> 雕刻 -> 孔洞** 模式。

![地形孔洞工具模式](media/holes-mode-tool.png)

现在，你可以在地形上绘制以添加孔洞。如果你想还原，可以使用 **撤销** 或按 **Control** 键从地形中移除孔洞。

![地形孔洞绘制](../media/terrain_pic_07.gif)

> [!Note]
> 使用 **Mask** 输入的材质性能较低，因此最好仅对需要它的块使用带有孔洞的材质。
