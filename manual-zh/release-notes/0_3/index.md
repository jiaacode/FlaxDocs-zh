# Flax 0.3 发布说明

## 亮点

### 地形

![地形](media/terrain.png)

我们为 Flax 添加了 **地形**！这不仅包括地形导入和渲染，还包括完整的碰撞支持、地形孔洞支持、从高度图和泼溅贴图进行高级地形生成、地形实时修改以及在编辑器中进行绘制（支持完整的撤销功能）。我们添加了专门用于地形的新材质领域类型，并增加了在运行时生成地形的支持。

地形使用带有流式传输的 **连续 LOD** 系统，能够创建非常大的景观，并在高视距下渲染而不会降低性能。在底层，地形 Actor 使用了一个图块集合，每个图块包含一个 4×4 块的四边形。块的大小可针对每个地形进行调整，默认情况下，我们使用值 127。这使得 Flax 能够有效地剔除和仅绘制可见的块，并实现平滑的 LOD 过渡（在不同 LOD 边缘没有裂缝或视觉伪影）。

![地形编辑](media/terrain_pic_05.gif)

地形可以从外部工具作为高度图以及一组泼溅贴图导入，也可以直接在编辑器中使用地形雕刻工具创建。Flax 编辑器支持使用简单的雕刻笔刷、平滑笔刷、噪点笔刷和压平笔刷。完整的撤销/重做支持和直观的编辑工具使得直接在编辑器内修改地形非常方便。Flax 还支持在地形中为洞穴和隧道创建孔洞（包括适当的碰撞处理）。

![地形绘制](media/terrain_pic_08.gif)

要了解有关地形的更多信息，请参阅相关文档[此处](../../terrain/index.md)。

### 动画图状态机

![状态机](media/anim-graph-state-machine.png)

我们持续改进 **动画图**，以使开发者能够创建更加逼真和独特的动画模型。在此更新中，我们为动画图带来了许多令人兴奋的功能，包括 **状态机** 支持。使用状态机是一种非常常见的创建角色动画混合图的技术，现在也可以在 Flax 中使用。除了此功能之外，我们还向动画图添加了一系列新节点，以帮助使用此功能，例如值比较节点、布尔数学节点、按位整数数学节点等。

要了解如何创建状态机，请参阅[此教程](../../animation/tutorials/setup-state-machine.md)。

### 编辑器改进

Flax 编辑器是一个优秀的工具集，但我们不能停止改进它。在此更新中，我们专注于通过添加以下功能来提高整体生产力：
* 修改属性的高亮显示和恢复默认值
* 支持只读脚本属性
* 导入时调整纹理大小
* 源代码编辑器选项和用于其他 IDE 集成的 C# API
* 材质实例编辑器窗口的撤销/重做支持
* 高亮显示修改过的材质实例参数（与基础材质相比）
* 等等...

### 模型 LOD 改进

![模型 LOD 抖动过渡](media/lod_transition.gif)

现在，Flax 支持 **抖动 LOD 过渡** 和高级模型 LOD 配置。我们为模型（甚至地形本身）添加了 `LOD Bias` 和 `Forced LOD` 属性。这使开发者能够调整模型视觉质量以匹配所需效果。你还可以通过专用的 C# API 按场景视图控制 LOD。

模型资源窗口包含一个预览选定 LOD 的选项。

### 动画图中的多重混合节点

我们向动画图添加了更多混合节点，可用于实现更高级的模型动画混合设置。

##### 多重混合 2D

在 2D 空间中混合多达 14 种不同的动画。此节点对于实现玩家移动动画混合或创建角色瞄准混合非常有用。

![多重混合 2D](media/multi-blend-2d.png)

##### 多重混合 1D

多重混合 1D 节点的工作方式类似于多重混合 2D，不同之处在于它使用简化的单轴进行混合。它更加优化，可用于玩家蹲伏前进或左右动画混合。

![多重混合 1D](media/multi-blend-1d.png)

##### 姿势混合

在某些情况下，按姿势索引（随机或由参数提供）播放角色动画可能很有用。例如，你可以通过从一组各种可能的死亡类型动画中选择一个来播放玩家死亡动画。此节点还提供了在选定姿势变化时在两个动画之间混合的功能，因此过渡可以平滑进行。

![姿势混合](media/blend-poses.png)

### 开放世界优化

![地形世界](media/terrain_pic_09.gif)

仅创建地形系统不足以让开发者创建巨大的世界。虽然 Flax 渲染管线已经针对大型场景进行了相当好的优化，但我们还对 CPU 渲染代码和场景更新代码应用了更多优化，使其运行得更快。这带来了 **出色的性能** 和 **更少的内存使用**。场景对象剔除已得到改进（使用 *基数* 排序和更好的数据局部性）。绘制调用排序不仅更快，而且 Flax 在场景渲染期间不会分配任何内存。

### 脚本改进

除了编辑器改进之外，我们还在不断为 C# 脚本 API 添加更多功能。现在你可以在代码中使用 `Int2`、`Int3` 和 `Int4` 类型作为整数类型向量。Flax 也会在编辑器中以适当的方式显示它们。我们改进了脚本更新逻辑，因此如果你的游戏不使用大量脚本但拥有大型场景，你将看到显著的性能提升。

现在，你还可以为你的属性使用 **默认值**。专用的特性已集成到编辑器中，有助于脚本属性的编辑。请参见以下示例代码：

```cs
[DefaultValue(3.14f)]
public float MyValue;

[DefaultValue(typeof(Vector2), "1,2")]
public Vector2 StartPosition;
```

你还可以使用 **只读** 值特性，仅用于值预览目的：

```cs
[ReadOnly]
public Int2 MyValue2;
```

最后，我们将更多编辑器 C# API 公开给公众，以便插件可以更深入地集成并在未来扩展。

### `ModelActor` 重命名为 `StaticModel`

最后一个需要提及的非常重要的更改是 **ModelActor** 名称重构。现在它的类型名称是 **StaticModel**。我们决定尽早重命名它以匹配命名约定（作为 *AnimatedModel* 类型），并使其更符合其实际行为：它是非动画的静态几何模型。为了匹配此更改，你将需要更新游戏脚本和代码以匹配新类型。你的所有场景和资源不应受此更改影响（除了在 Json 资源中使用的少数情况需要手动修复）。我们还更新了 *FlaxSamples*，因此你可以获取更新的项目来尝试。

我们只想提醒大家，在 **Alpha** 发布期间，我们可能仍然会对命名或数据引入破坏性更改，因此请记住，引擎的许多部分可能仍然会发生变化。然而，这种情况不太可能发生，因为我们希望在 **Beta** 发布之前稳定引擎。
