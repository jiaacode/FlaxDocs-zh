# Flax 0.2 发布说明

## 亮点

### 嵌套预制体

![嵌套预制体](../../get-started/prefabs/media/nested_prefabs.gif)

我们添加了一种新的资源类型：**预制体**。它用于构建 Actor 和脚本的原型，以便在游戏中重用。预制体就像一个模板或原型，你可以在场景中生成它。对预制体资源所做的任何编辑都会立即反映到从它生成的所有实例中，但你也可以单独为每个实例覆盖组件和设置。这有助于创建高级游戏内容。此外，**Flax 开箱即用地支持在预制体内部嵌套预制体！**

要了解有关预制体的更多信息，请参阅相关文档[此处](../../get-started/prefabs/index.md)。

### 运动模糊

![运动模糊](/manual/media/motion_blur.gif)

Flax 包含了内置的 **运动模糊** 效果，模拟了现实摄像机光圈的效果。现在，动态对象被渲染到运动向量缓冲区中，该缓冲区用于绘制逐对象（或蒙皮模型逐骨骼）的模糊。此外，任何摄像机移动都会提供逼真的模糊效果，有助于创建令人惊叹的视觉效果和过场动画。

### 插件

![插件](../../scripting/plugins/media/plugins-window.png)

现在，Flax 支持 **游戏插件** 和 **编辑器插件**。开发者还可以轻松地包含 .Net 库以在游戏脚本中使用。Flax 插件系统允许添加自定义功能并扩展引擎功能。请参阅专门的页面[此处](../../scripting/plugins/index.md)以了解有关创建和使用插件的更多信息。

### 次表面材质

![次表面散射](/manual/media/subsurface_materials.gif)

材质现在将使用 **着色模型** 属性来定义要使用的着色类型。支持的类型包括 **Unlit**、**Lit** 和 **Subsurface**。现在创建皮肤、蜡或植被材质变得更加容易，并提供了更多可能性。

### 细分和位移

![细分和位移](/manual/media/tessellation_support.png)

最新的 Flax 版本支持细分材质和位移贴图。使用此功能有助于实现逼真的地形或水面表面。

### 材质中的纹理数组和体积纹理

新的材质参数类型和改进的渲染目标 C# API 使开发者能够创建和使用 3D 纹理和纹理数组。此外，`GPUContext` 已更新，支持将后期处理材质渲染到单个纹理切片。新的 C# API 允许为你的游戏创建高级视觉效果，例如 GPU 上的体积云或水流模拟。

### 纹理 Mip 映射预览

![纹理 Mip 映射预览](/manual/media/texture-mipmap-preview.png)

纹理窗口和立方体贴图纹理窗口现在包含专用小部件，用于预览单个纹理 Mip 映射，以及选择采样器（点采样或线性采样）的选项。这有助于高级游戏开发和处理纹理内容。

此外，许多编辑器窗口都包含一个指向相关文档的专用按钮（在浏览器中打开 Flax 文档）。

### 场景序列化更改

从此版本开始，场景和 Actor 集合将把脚本序列化到 Actor 数据列表中，而不是在父 Actor 内部。这与在预制体系统实现期间引入的场景对象序列化更改有关。新的引擎版本仍将加载旧格式的场景，但序列化的场景将匹配新设计。
