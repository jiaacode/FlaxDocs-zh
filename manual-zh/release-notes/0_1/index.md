# Flax 0.1 发布说明

## 亮点

### 贴花

![贴花](/manual/media/decals.png)

我们添加了新的材质类型：**贴花** 和新的 **贴花 Actor**，可用于在场景几何体表面之上绘制贴花材质。这是一种非常常见且简单的方式，用于添加特殊效果，如血迹、脚印等。绘制调用渲染经过高度优化，适合大多数游戏的需求。要了解有关贴花的更多信息，请参阅相关文档[此处](../../graphics/decals/index.md)。

### C# 7.2 支持

现在你可以使用最新的 **C# 7.2** 功能，包括：
* 局部函数
* 二进制字面量
* 数字分隔符
* 模式匹配
* `out` 变量
* 表达式体成员
* `ref readonly`
* `private protected`
* 等等...

当前 Flax 版本包含 [Roslyn](https://github.com/dotnet/roslyn) 编译器，并支持在脚本中使用最新的 C# 语言版本。

### 游戏 UI

新的 **UICanvas** 和 **UIControl** Actor 类型使游戏开发者能够轻松为游戏菜单、玩家 HUD 和其他关卡界面（如控制面板）创建 UI。用户界面可以从代码创建，也可以直接在编辑器内创建，并支持完整的序列化和撤销功能。

### 编辑器选项

现在你可以修改编辑器选项，并将其全局应用于所有已安装的引擎实例。你可以调整脚本重新编译逻辑、更改界面、修改选择轮廓颜色等。
