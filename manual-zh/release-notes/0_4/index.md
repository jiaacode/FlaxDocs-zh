# Flax 0.4 发布说明

## 亮点

### 植被

![植被](/manual/media/foliage-rendering.gif)

全新的 **植被** 系统必将改善开放世界游戏的开发，并完善最近添加的地形系统。植被系统最重要的目的是它可以轻松扩展并实现非常稳定的性能。如果你的游戏需要充满树木、草地和岩石的巨大开放世界，那么你绝对需要使用植被系统。它支持在关卡中放置和渲染数十万个植被实例，且不会降低性能。

每个植被 Actor 包含一个预定义的植被类型列表和一个植被实例集合。每个植被类型定义了用于渲染的模型资源、放置属性和绘制属性。每个植被实例包含有关它使用的类型以及在世界中实际放置变换的信息。实例和类型集合都封装在植被 Actor 内部以提高性能。

Flax 编辑器包含了用于创建和编辑植被的即用型工具，然而整个系统也可以直接从代码中使用，以在游戏运行时生成程序化植被。

![植被绘制](/manual/media/foliage-painting.gif)

要了解有关植被的更多信息，请参阅相关文档[此处](../../foliage/index.md)。

### 导航网格和导航

![导航寻路](/manual/media/navmesh-agent.gif)

我们为各种类型的游戏添加了 **导航** 支持和寻路工具。你可以使用导航系统来控制 AI 角色和其他对象如何在游戏环境中导航，而不会撞墙和避开障碍物。

![导航网格](/manual/media/navmesh-dynamic-rebuild.gif)

导航系统使用 **导航网格**（缩写为 navmesh），它是多边形表面，用于定义场景的“可行走”区域。它们用于查询路径，以便对象在游戏关卡中导航。
Flax 支持运行时生成的导航网格和在编辑器中预构建的导航网格。导航网格构建过程是异步的，不会阻塞游戏逻辑线程。也支持进度报告。

要了解如何在游戏中使用它，请参阅[本节](../../navigation/index.md)。

### 自定义动画图节点支持

![自定义动画图节点](/manual/media/custom-node-results.gif)

**动画图** 已成为一个功能齐全的环境，用于创建各种类型的动画对象。虽然我们不断添加新节点并改进现有节点的性能，但总是需要扩展默认行为。现在，我们很高兴地介绍动画图的 **自定义节点** 支持！使用此功能，你可以轻松定义和实现自己的动画图节点，以实现动画处理的任何功能。

此功能可用于从外部动画源（如实时绑定）获取数据，或实现自定义 IK 求解器。此外，插件可以包含自定义节点，以便在不同项目之间重用。

我们准备了一个关于自定义节点使用的示例教程[此处](../../animation/anim-graph/custom-nodes.md)。

### 空渲染器

**空渲染器** 是一项允许你在没有渲染后端的情况下运行引擎的功能。如果你使用命令行在云端进行游戏构建，可以传递标志 `-null` 来禁用 GPU 渲染。这可以在不需要图形渲染时提高性能（也适用于服务器构建）。

### 锁定刚体位置/旋转轴

![锁定刚体位置和旋转](/manual/media/rigidbody-constraints.jpg)

现在，Flax 支持 **刚体约束**。此功能可用于锁定对象在特定轴集合上的旋转或位置。如果你希望允许玩家仅沿单个轴滑动盒子并防止其旋转，只需使用此功能将刚体运动冻结到一定的自由度。

### 渲染质量和性能改进

我们一直在致力于改进 Flax 渲染器。这一次我们：
* 添加了 **亚像素形态抗锯齿（SMAA）**
* 添加了 **时间抗锯齿（TAA）** - 预览
* 改进了 **屏幕空间反射（SSR）** - 更稳定且支持 HDR
* 改进了 **屏幕空间环境光遮蔽（SSAO）** - 远距离质量更好
* 改进了渲染流程
