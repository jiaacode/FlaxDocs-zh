# Flax 1.9 发布说明

## 亮点

### 视频播放

![Flax 引擎中的视频播放](/manual/media/video.gif)

此版本包含一个视频播放器，用于加载 `.mp4` 文件并播放其中的视频和音频。新的 `VideoPlayer` Actor 可以添加到场景中、添加到预制体中、附加到 UI，或从代码中动态生成。它可以播放本地文件或通过 HTTP URL 流式传输视频。

我们准备了关于如何使用[视频](../../graphics/video/index.md)的文档和教程。

### 渲染性能提升

![通过异步绘制的渲染性能](/manual/media/job-system.png)

每次 Flax 更新都会为渲染带来 **新的性能改进**。这次我们增强了：
* 绘制调用排序（通过优化绘制键内存，并使用归并排序而非快速排序），
* 异步绘制（通过在作业系统上运行绘制调用排序、阴影设置和 DDGI 设置），
* 对象批处理（通过合并使用此材质的所有网格的材质常量设置），
* GPU 对象数据（通过异步将整个场景的所有绘制调用实例一次性上传），
* 阴影贴图绘制减少（通过对不透明非遮罩几何体使用材质共享）。

### DDGI 改进

![Flax 引擎中的 Bistro DDGI 渲染](/manual/media/bistro-lighting.png)

[动态漫反射全局光照](../../graphics/lighting/gi/realtime.md)（**DDGI**）使用我们自定义的软件光线追踪解决方案来绘制动态光照。Flax 1.9 为此视觉效果增加了实质性的质量和性能升级。我们添加了 **每个探针的可变光线数量**，意味着视锥之外的或远离几何体或远离摄像机原点的 GI 探针每帧使用的光线更少。探针 **重定位算法应用平滑的探针移动**，以更好地适应动态变化的场景。此外，探针采样支持从其他网格单元回退，这减少了背景伪影。总的来说，**DDGI 已可用于生产**，并可用于在 **大规模游戏中实现逼真的光照**。

### 阴影贴图图集

![静态阴影贴图图集渲染](/manual/media/static-shadow-map.png)

阴影贴图是用于实时绘制光源阴影的深度纹理。Flax 过去使用固定大小的渲染目标来根据全局阴影质量设置绘制阴影。我们 **重新实现了阴影映射，使用共享图集纹理**，这带来了许多好处：
* 可变阴影分辨率（例如，基于到光源的距离），
* 可变更新率（例如，远距离光源的阴影贴图绘制频率更低），
* 静态几何体的独立静态图集（复制到动态图集），
* 透明度中的阴影光源（单个图集可以轻松绑定到着色器），
* 阴影光源批处理（例如，渲染体积雾时），
* 更好的性能（深度绘制到单个纹理）。

### 基于 GPU 的网格 SDF 生成

![基于 GPU 的网格 SDF 生成](/manual/media/mesh-sdf-generated-on-gpu.png)

网格 **SDF 现在默认在 GPU 上生成**。它减少了计算时间（包括项目中启用 SDF 时的模型导入时间）。例如，一个具有 *3,700,000* 个顶点的模型在 *约 160ms* 内生成。对于某些网格（例如像植被这样的薄物体），新的 GPU 生成会导致伪影（使用的算法不同），因此如有必要，仍然可以使用旧的基于 CPU 的算法。

### 缺失引用调试改进

![缺失引用调试日志](/manual/media/missing-ref.png)

在处理较大的 Flax 项目时，资源或对象引用经常会丢失。例如，如果有人删除了正在使用的纹理或材质，可能会导致游戏或视觉伪影。现在，任何缺失的资源或对象都会被记录，并带有关于源引用的上下文信息（例如，特定资源路径、类型和 ID 或特定 Actor/脚本信息）。这大大提高了开发者快速解决损坏引用的能力，从而提高成功率。我们计划继续改进此功能，使其更容易找到缺失的引用或数据问题。

### 编辑器层级引导线

![编辑器层级引导线](/manual/media/guidelines.png)

我们添加了在编辑器树层级中显示引导线。此更改大大提高了 Actor 层级或文件夹结构的可读性。此功能可以在编辑器界面选项中关闭。

### 无限网格

![无限网格](/manual/media/new-grid.png)

在此更新中，我们增强了编辑器中的网格，使其看起来更美观。它不再使用调试线，而是使用一个大型四边形上的着色器，该四边形跟随摄像机移动并与环境正确混合。颜色和距离都可以在编辑器选项中配置。

### 列表重新排序

![列表重新排序](/manual/media/reordering-lists.png)

Flax 1.9 为编辑器添加了一个高度请求的功能，用于数组和列表编辑。现在，你可以使用左侧的小图标向上或向下拖动项目以重新排序列表。此功能在整个编辑器中有效，包括材质和可视化脚本参数列表。

### Visject 改进

Visject 是用于基于曲面的内容创建系统的名称，例如：材质、可视化脚本、粒子发射器、动画图等。在过去几个月中，我们为 Visject 添加了多项重要更新，以赋能创作者：

#### 工具提示和描述面板

![工具提示和描述面板](/manual/media/visject-description.gif)

向上下文菜单添加了节点文档部分，允许用户快速区分上下文菜单列表中的节点。这对于可视化脚本尤其有用，因为它显示了函数的可视参数和返回值类型。

#### 搜索和过滤改进

![搜索和过滤改进](/manual/media/visject-filtering.gif)

通过添加 2 个新功能，进一步改进了在上下文菜单中搜索节点的用户体验：`按组过滤` 和 `类型排序优先级`。

#### 直线

![直线](/manual/media/visject-lines.jpg)

编辑器选项包含一个用于线条曲率的设置，可以使它们看起来是直的。

### 径向菜单控件

![径向菜单控件](/manual/media/radial-menu.png)

新的 `RadialMenu` 控件可用于构建交互式用户界面，在允许用户从库存中选择物品或将游戏移植到主机以进行游戏手柄控制时特别有用。

### 常规改进

Flax 编辑器正在持续开发中，旨在成为最佳游戏编辑器，这次我们主要致力于：

* 新的内容创建选项（新建预制体或 Widget 根 Actor 设置），
* UI 控件工具箱（带有用于拖放生成的 UI 控件的工具箱部分），
* 新的材质渐变节点（锥形、循环、线性、径向和环形渐变），
* 场景动画时间线 Gizmo（用于编辑摄像机轨道曲线的视口 Gizmo），
* 动画事件 UI。

## 迁移指南

* 对象绘制已重构，为不同网格使用材质批处理（除了现有的硬件实例化），所有对象的变换和数据都存储在整个帧共享的单个大型 GPU 缓冲区中。新的每绘制常量缓冲区在槽位 `2` 使用——更新你的自定义材质着色器，如果它们使用了额外的常量缓冲区，则应改用槽位 `3`。直接从槽位 `0` 的 `Data` 常量缓冲区使用 `WorldMatrix`、`LODDitherFactor`、`PerInstanceRandom` 的材质和着色器需要使用 `LoadObject` 函数以在 GPU 上正确读取数据。
* 由于性能原因，Sort Order 已从 `int16` 减少到 `int8`（渲染中更优化的排序键打包），这为透明度排序重排序留下了 `-[127; 127]` 的范围。
* `DEPRECATED` 已更改为一个接受自定义弃用消息的函数。
