# 物理

动画图可以在特定骨骼上运行简单的物理模拟，以丰富角色或动画对象的视觉效果。物理可以由动画部分控制，例如弹簧骨骼链的根节点由动画驱动，以在艺术家制作的动画和运行时生成的动画之间提供真实的衔接。

> [!Tip]
> 物理模拟在世界空间中运行，这意味着动画骨骼姿态会自动从局部节点空间转换并转换回来。

## 弹簧骨骼物理

| 关闭                                         | 开启                                        |
| -------------------------------------------- | ------------------------------------------- |
| ![无弹簧骨骼物理](media/spring-bone-off.gif) | ![有弹簧骨骼物理](media/spring-bone-on.gif) |

**弹簧骨骼物理**节点为一连串的骨骼节点模拟柔软的、基于物理的拖尾运动——例如触角、尾巴或布条。设置 `结束节点` 和 `节点数量` 以定义角色或对象中的骨骼链。根骨骼保持固定在你的常规动画上，而每个后续骨骼都会跟随动态的二次运动（摇摆、飘动、抖动），自然地反应重力、风和运动。你可以控制骨骼的硬度、重量或灵活性，限制它们可以移动的幅度，并与任何标准动画系统结合（这保留了你角色的主要动画，只影响模拟的骨骼）。

典型用例：动画尾巴、摆动的头发、兔耳朵、绳索、触手、拖尾电线和天线。

![弹簧骨骼物理节点](media/spring-bone-node.png)

| 属性         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **结束节点** | 要模拟的弹簧骨骼链的最后一个（尖端）节点。                   |
| **节点数量** | 链中要模拟的节点数量，从结束节点开始向上层级计算。不包括链所连接的根节点。 |
| **权重**     | Alpha 参数，可以在动画姿态和模拟姿态之间混合。`0` - 完全动画，`1` - 完全模拟。 |
| **硬度**     | 定义骨骼之间关节的刚度。`0` - 柔软，`1` - 刚性。             |
| **阻力**     | 应用于骨骼的速度缩放。值越大，运动被抑制得越厉害。较低的值会增加运动自由度。 |
| **拉伸限制** | 最大骨骼拉伸缩放。`0` - 无拉伸，`1` - 最多可拉伸到两倍长度。 |
| **重力缩放** | 世界重力缩放。可用于调整重力大小或禁用它。                   |
| **力**       | 作用于绳索的额外外部力（世界空间）。例如可以是风力。         |
