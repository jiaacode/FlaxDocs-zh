# 状态机

![状态机](../tutorials/media/example-state-machine-2.png)

动画图可以包含嵌套的**状态机**节点，这些节点可用于定义动画角色的状态并在它们之间执行平滑过渡。状态机提供了一种可视化方式，将动画逻辑划分为一系列状态。每个状态可以定义其表示的自定义动画姿态逻辑（常见状态包括 **Idle**、**Run**、**Falling** 等）。这些状态然后由过渡来控制，这些过渡控制如何从一个状态混合到另一个状态。

使用状态机可以极大地简化创建动画模型的设计和实现过程。使用具有可视化动画状态及其之间连接关系的图，即使在处理复杂角色时也能改善工具工作流程。请参阅本文档部分以了解如何在你的项目中使用它们。

## 状态过渡

![状态过渡属性](../tutorials/media/transition-properties-panel.png)

每个过渡都有一组你可以定义的各种属性。禁用的过渡在编辑器中会变灰，以帮助你引导。你还可以调整过渡时间和混合模式。**使用默认规则**选项可用于在状态动画即将结束时触发自动过渡。这在创建单次状态而无需手动创建规则时非常有用。

### 过渡属性

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **启用**         | 如果勾选，则可以触发过渡，否则将被忽略。                     |
| **独立**         | 如果勾选，动画图将忽略来自源状态的其他过渡，仅使用此过渡。   |
| **使用默认规则** | 如果勾选，动画图将基于状态动画姿态（单次动画播放）执行自动过渡。 |
| **顺序**         | 过渡顺序。具有较高顺序的过渡在具有较低顺序的过渡之前处理。   |
| **混合持续时间** | 过渡混合持续时间（以秒为单位）。                             |
| **混合模式**     | 用于混合 Alpha 的过渡混合模式。                              |
| **中断**         | 过渡中断选项（标志）。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**无**</td><td>无。</td></tr><tr><td>**规则重新检查**</td><td>在活动过渡期间将重新检查过渡规则，并提供中断过渡的选项。</td></tr><tr><td>**即时**</td><td>中断的过渡立即停止，不进行淡出混合。</td></tr></tbody></table> |

## 过渡规则

![状态过渡规则 1](../tutorials/media/state-transition-definition-1.png)

要编辑状态过渡规则触发逻辑，请使用 **编辑规则** 按钮或 **双击** 它（在连接线上）。
然后过渡图将显示。同样，它的工作方式类似于状态机图。此子图包含一个单输出节点，该节点采样决定何时触发过渡的布尔值。

另外，请记住使用特殊的 **过渡源状态动画** 节点，该节点可以添加到过渡图中，以访问源状态动画播放信息。它可用于在特定时刻触发动画，例如当源状态动画即将结束时。

## 入口状态

![状态机中的入口状态](/manual/media/entry-state.png)

**入口** 状态是一个特殊节点（始终创建），它可以有一个过渡（即时）到状态机内的初始状态。它指向当状态机变为活动时应选择的状态。

## 任意状态

![状态机中的任意状态](/manual/media/any-state.png)

**任意** 状态是一个特殊节点，可以定义到状态的过渡，这些过渡将在状态机更新期间始终被检查。它可用于在创建更复杂的角色动画时改善工作流程。
