# 蒙皮模型窗口界面

蒙皮模型编辑器窗口的 UI 由工具栏、视口和属性面板组成。

1. 工具栏
2. 属性面板
3. 视口

## 视口

![视口](../anim-graph/media/anim-graph-viewport.png)

视口面板显示资源的预览。

你可以通过使用**鼠标右键**在视口中导航，或按住鼠标右键并使用**鼠标滚轮**进行缩放。

与编辑器中的所有视口一样，此视口也带有一个 *视图* 小部件菜单。按下该按钮，你可以调试材质通道、预览不同的视图模式，甚至更改摄像机的视野角度。要了解有关使用编辑器视口和相关工具的更多信息，请阅读[调试工具](../../graphics/debugging-tools/index.md)页面。

## 属性面板

![属性](media/skinned-model-properties.gif)

此面板显示模型资源属性，并组织为单独的选项卡。

- **网格** - 每个模型细节层次（*LOD*）的属性。这包括 LOD 三角形/顶点统计、边界、网格的材质槽绑定，以及隔离或高亮显示网格的选项。
- **骨骼** - 骨骼节点和骨骼层级结构。Blend Shapes 预览。
- **材质** - 此模型使用的材质槽列表。
- **UV** - 模型纹理坐标通道调试可视化工具，包括光照贴图 UV。
- **导入** - 模型导入选项（从上次导入恢复）。你可以修改它们，然后按 **重新导入** 按钮从源图像文件更新资源。

你可以使用它来修改资源、查看模型信息（三角形、顶点、骨骼数量），或从源资源重新导入。由于此面板包含大量内容，因此被分成多个组，因此点击给定组标题栏（例如 *骨骼*）将弹出其内容。
