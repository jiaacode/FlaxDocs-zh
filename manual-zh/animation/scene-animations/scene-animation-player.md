# 场景动画播放器

![场景动画播放器](media/scene-animation-player.png)

**场景动画播放器** 是一种 Actor 类型，可以播放 [场景动画](scene-animation.md) 序列。它可以在启动时播放，也可以在从脚本调用播放后播放。播放速度和循环选项可以调整。

## 结束时恢复状态

场景动画播放器支持在播放开始时缓存动画对象的状态，并在结束时恢复。这在某些游戏场景中可能很有用。要启用它，只需勾选 *停止时恢复状态* 选项。如果使用，播放开始会花费更长时间，因为必须缓存状态（额外的内存分配和数据处理）。

## 对象和轨道映射

在某些情况下，例如预制体对象动画或实例化动画，你可能希望将动画对象更改为其他对象。为此，你可以使用播放器中的 `MapObject(Guid from, Guid to)` 或 `MapTrack(string from, Guid to)` 函数。两者都可用于将资源中的动画对象重定向到另一个对象。

## 属性

![场景动画播放器属性](media/scene-animation-player-properties.png)

| 属性               | 描述                                                         |
| ------------------ | ------------------------------------------------------------ |
| **动画**           | 要播放的场景动画。                                           |
| **速度**           | 动画播放速度因子。缩放时间线更新的增量时间。可用于加快或减慢序列播放。 |
| **起始时间**       | 动画起始时间。可用于在开始时跳过序列的一部分。               |
| **使用时间缩放**   | 确定场景动画是否应考虑全局游戏时间缩放来进行模拟更新。       |
| **循环**           | 确定场景动画播放完成后是否应循环播放。                       |
| **启动时播放**     | 确定场景动画是否应在游戏启动时自动播放。                     |
| **随机起始时间**   | 确定场景动画是否应在播放开始时随机化起始时间。               |
| **停止时恢复状态** | 确定场景动画在停止播放时是否应恢复初始状态。状态在动画停止（而非暂停）时缓存。 |
| **更新模式**       | 描述场景动画更新频率的动画更新模式。可能的选项：<table><tbody><tr><th>选项</th><th>描述</th></tr><tr><td>**每帧更新**</td><td>动画将在每次游戏逻辑更新时更新。</td></tr><tr><td>**手动**</td><td>动画可以由用户脚本手动更新。</td></tr></tbody></table> |
