# 动画

![动画](/manual/media/knight_dance.gif)

每个游戏中最基本的组成部分之一就是**动画**。Flax 引擎拥有高质量且高性能的动画系统，可帮助开发者实现栩栩如生的角色和动画。
本文档部分描述了如何使用 Flax 动画管线。请遵循指南和教程来创建你自己的动画角色。

>[!Note]
>作为起点，我们建议查看以下教程：[如何设置动画模型](tutorials/setup-animated-model.md)。
