# 根运动

**根运动**是 Flax 动画系统的一项特殊功能，可用于从动画模型根节点提取运动并将其应用到 Actor 上。这对于创建动画驱动的角色等场景非常有用。Flax 支持从自定义节点提取根运动以及运动混合，因此可以实现逼真的效果。

| 无根运动                                 | 启用根运动                              |
| ---------------------------------------- | --------------------------------------- |
| ![根运动关闭](media/root-motion-off.gif) | ![根运动开启](media/root-motion-on.gif) |

## 使用方法

要使用根运动，你需要：

1. 在导入动画时启用根运动（可以从特定节点提取，也可以从整个骨骼姿态运动生成）

	![根运动设置](media/root-motion-setup-1.jpg)

2. 在动画图中启用根运动提取和应用

	![根运动设置](media/root-motion-setup-2.jpg)

## 根运动模式

| 选项         | 描述                                         |
| ------------ | -------------------------------------------- |
| **无**       | 禁用根运动功能。                             |
| **提取节点** | 从根节点（或按名称指定的节点）提取运动。     |
| **提取质心** | 从质心运动（基于骨骼姿态动画估算）提取运动。 |

## 根运动标志

使用**根运动标志**来指定应从动画中提取到目标上的运动分量。

| 标志          | 描述                                                         |
| ------------- | ------------------------------------------------------------ |
| **无**        | 无根运动。                                                   |
| **根位置 XZ** | 根节点在 XZ 平面上的位置。应用水平运动。适用于固定位置的动画（例如待机）。 |
| **根位置 Y**  | 根节点在 Y 轴（向上）上的位置。应用垂直运动。适用于所有“地面”动画，除非跳跃由代码处理。 |
| **根旋转**    | 根节点的旋转。应用朝向变化。适用于内嵌了根旋转的动画（例如转身动画）。 |
| **根位置**    | 根节点的位置。                                               |
| **根变换**    | 根节点的位置和旋转。                                         |

## 提示

你可以在导入动画时手动指定用于运动提取的根节点。使用**根节点名称**字段（更多信息见[此处](../../graphics/models/import.md)）。

如果你的角色使用了[角色控制器](../../physics/character-controller.md)或运动学[刚体](../../physics/rigid-bodies.md)，你可能希望将根运动应用到它上面，而不是应用到动画模型上。要执行此操作，只需将目标对象赋值给 [AnimatedModel.RootMotionTarget](https://docs.flaxengine.com/api/FlaxEngine.AnimatedModel.html#FlaxEngine_AnimatedModel_RootMotionTarget)。
