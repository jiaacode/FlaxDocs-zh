# 操作指南：设置状态机

在本教程中，你将学习如何在动画图内创建和使用状态机，以根据输入参数在不同动画之间切换。

## 1. 准备动画图和资源

![准备动画图](/manual/media/empty-anim-graph.png)

首先，你需要准备好动画和蒙皮模型。然后创建一个用于设置状态机的动画图。你可以按照[此教程](create-anim-graph.md)学习如何操作。

## 2. 添加 **状态机** 节点

![添加动画图状态机](/manual/media/new-state-machine.png)

在曲面上 **右键单击**，输入 **State Machine** 并按回车，或从层级中选择该节点以生成它。然后你可以指定其名称。默认的 *Locomotion* 名称应适合大多数用例，因此只需按 *回车*。然后将其与 *Anim Graph* 输出节点连接，如下图所示。

![链接状态机](/manual/media/link-state-machine.png)

>[!Note]
>你可以通过 *双击* 节点标题来重命名状态机节点。

## 3. 打开状态机图

![打开状态机](/manual/media/open-state-machine.png)

下一步是打开状态机图以进行修改。只需按下节点标题下方的 **编辑** 按钮。
每个状态机都包含一个状态和过渡的嵌套图。你可以在窗口工具栏上看到导航栏，它允许你通过按下 *Anim Graph/* 按钮返回到曲面。在编辑状态和过渡时，这在图形之间移动时会很方便。

打开图后，它包含一个默认的 **入口** 节点，该节点用于指向状态机的默认状态。即在状态机初始化后分配的状态（例如 Idle）。

## 4. 添加状态

![添加状态](/manual/media/add-state.png)

现在，使用 *右键单击* 菜单向状态机添加新状态。每个状态都可以有自己的名称。添加状态后，你可以通过按下并拖动标题来移动它们。十字按钮用于删除状态，工具按钮允许在创建后重命名状态。

![示例状态机状态](/manual/media/example-state-machine-1.png)

## 5. 创建过渡

![示例状态机状态已连接](/manual/media/example-state-machine-2.png)

通过按住鼠标左键在状态或入口节点的边缘上并拖动鼠标，你可以创建过渡。这与连接曲面框的工作方式相同。连接你的状态并添加从入口节点的输出以准备好状态机。我们将调整过渡以为此状态机流程实现正确的行为。

>[!Note]
>你可以按下 **鼠标中键** 来 **删除过渡**，或 *右键单击* 以使用上下文菜单。只需单击过渡线（它会高亮显示）。

## 6. 设置状态动画

![动画图状态输出](/manual/media/anim-graph-state-edit.png)

每个状态都可以定义自定义动画姿态采样。这包括单个动画播放或更高级的用例，如使用特殊节点的多重混合。要编辑状态，只需 **双击** 它。它将打开允许定义动画输出的子图。它的工作方式类似于动画图的主输出节点，区别在于它仅在状态处于活动状态时使用。

在此示例中，我们简单地采样了 **Idle** 和 **Punch** 动画。

![采样 Idle](/manual/media/sample-idle-state.png)

<p>
</p>

![采样 Punch](/manual/media/sample-punch-state.png)

## 7. 添加参数

要控制状态机逻辑流程，你需要定义过渡规则。每个过渡都可以在你定义的特定条件下触发。例如，当玩家正在下落时，你可以在脚本中检测到这一事实，并将变量传递给动画图参数，该参数将触发到 Falling 状态的过渡，并播放玩家下落的适当动画。要了解如何创建动画图参数，请参阅[此教程](change-anim-graph-param.md)。

在此示例中，我们使用 **Is Punching** 参数在 *Idle* 和 *Punch* 状态之间切换。

![动画图参数](/manual/media/anim-param-for-states.png)

## 8. 设置过渡规则

最后一步是使用输入参数来定义状态过渡规则。要编辑过渡，你可以 **左键单击** 它。然后属性面板将弹出。

![状态过渡属性](/manual/media/transition-properties-panel.png)

每个过渡都有一组你可以定义的各种属性。禁用的过渡在编辑器中会变灰，以帮助你引导。你还可以调整过渡时间和混合模式。**使用默认规则** 选项可用于在状态动画即将结束时触发自动过渡。这在创建单次状态而无需手动创建规则时非常有用。

要编辑状态过渡规则触发逻辑，请使用 **编辑规则** 按钮或 **双击** 它（在连接线上）。
然后过渡图将显示。同样，它的工作方式类似于状态机图。此子图包含一个单输出节点，该节点采样决定何时触发过渡的布尔值。

![状态过渡规则 1](/manual/media/state-transition-definition-1.png)

<p>
</p>

![状态过渡规则 2](/manual/media/state-transition-definition-2.png)

在此示例中，我们定义了两个过渡：一个从 Idle 到 Punch，另一个从 Punch 到 Idle。两者都使用 *Is Punching* 变量，但方式相反（作为切换）。你可以使用各种比较节点和数学节点来定义各种类型的过渡规则。

另外，请记住使用特殊的 **过渡源状态动画** 节点，该节点可以添加到过渡图中，以访问源状态动画播放信息。它可用于在特定时刻触发动画，例如当源状态动画即将结束时。

![过渡源状态动画](/manual/media/transition-source-state-anim.png)
