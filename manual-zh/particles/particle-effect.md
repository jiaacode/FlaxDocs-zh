# 粒子特效

![粒子特效](/manual/media/particle-effect.jpg)

**粒子特效** 是一种 Actor 类型，用于在场景中播放粒子模拟。用它来为你的游戏添加粒子效果。

## 模拟模式

粒子模拟支持 2 种不同的更新模式：
* **实时** - 在每次游戏逻辑更新时更新粒子。
* **固定时间步长** - 使用固定的时间步长增量时间，以自定义频率更新粒子模拟。

在大多数情况下，使用实时更新是最常见的选择，但如果你的粒子模拟涉及物理碰撞，你可能需要以固定时间戳运行的更稳定的更新。

## 属性

![粒子特效属性](/manual/media/particle-effect-properties.png)

| 属性             | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| **粒子系统**     | 要播放的粒子系统。                                           |
| **更新模式**     | 粒子模拟的更新模式。定义如何更新粒子发射器。                 |
| **固定时间步长** | 模拟更新的固定时间步长。仅在 `UpdateMode` 设置为 `FixedTimestep` 时使用。 |
| **模拟速度**     | 粒子模拟速度因子。缩放粒子系统更新的增量时间。可用于加快或减慢粒子速度。 |
| **使用时间缩放** | 确定粒子特效是否应考虑全局游戏时间缩放来进行模拟更新。       |
| **循环**         | 确定粒子特效播放完成后是否应循环播放。                       |
| **屏幕外更新**   | 如果勾选，即使 Actor 在任何摄像机视野之外，粒子模拟也会更新。否则，当 Actor 在屏幕外时，模拟将停止运行。 |
