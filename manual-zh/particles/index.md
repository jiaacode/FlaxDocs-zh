# 粒子

![粒子](media/title.jpg)

Flax 支持大规模粒子模拟以及精灵、网格和带状粒子的高性能渲染。编辑器中的高级工具集有助于创建复杂的视觉效果。粒子系统允许轻松扩展并生成所需的粒子效果。请使用本文档部分学习如何创建粒子效果，以创造出色的视觉体验。

## 基础

![粒子](media/particles.gif)

**粒子** 是大量使用时可创建视觉效果的对象。你可以使用粒子来创建火焰、爆炸、液体、烟雾、闪电、魔法效果、热畸变等效果。

粒子系统的设计目标是使开发者能够快速创建视觉效果，并具备内容可扩展性。向游戏添加粒子需要创建[粒子发射器](particle-emitter.md)资源，设置[粒子系统](particle-system.md)资源，并通过放置在场景中的[粒子特效](particle-effect.md) Actor 播放粒子以模拟视觉效果。这种面向内容的管线允许轻松创建和重用不同类型的发射器，以制作各种类型的效果。此外，粒子发射器通过可视化图定义，以改善美术师的创作过程。

## 技术细节

Flax 同时支持 **CPU 和 GPU 粒子模拟**。粒子发射器图可以直接在 CPU 上执行以模拟粒子，也可用于生成计算着色器源代码，以实现大规模 GPU 粒子模拟。

为了更好地理解，请阅读以下对比：

| CPU 模拟                     | GPU 模拟                  |
| ---------------------------- | ------------------------- |
| 低延迟                       | 高吞吐量                  |
| 最多 20 万个粒子             | 最多 500 万个粒子         |
| 针对小型系统优化             | 针对大规模模拟优化        |
| 需要每帧将绘制数据发送到 GPU | 所有模拟数据存储在 GPU 上 |
| 无法采样场景纹理             | 可以采样场景纹理          |
| 无特殊要求                   | 需要计算着色器和间接绘制  |

此外，如果发射器使用带状或光源，则不支持 GPU 粒子。然而，GPU 粒子可以高效地采样纹理，并对大量粒子执行深度缓冲区碰撞。

>[!Note]
>始终尝试将粒子发射器容量设置为实际所需的值，以提高模拟性能并减少内存使用。
