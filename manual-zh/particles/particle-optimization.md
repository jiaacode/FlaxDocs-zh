# 粒子优化

大型粒子系统可能会影响游戏性能并降低帧率。有几种方法可以优化高质量的视觉效果。请参阅本文档页面学习它们。

## 基本检查清单

以下是进行性能分析和优化粒子时需要遵循的辅助检查清单。

* 将粒子发射器的 *容量* 调整到效果实际使用的真实值。使用过高的值会增加内存使用。
* 在常用发射器或短生命周期发射器上启用 *自动池化*。
* 在小型 CPU 粒子发射器上，或如果粒子系统的边界是可预测的或几乎恒定的，则禁用 *自动边界*。这将改善粒子更新（引擎不会在粒子更新后计算边界）。
* 使用 *材质复杂度* 和 *四边形过度绘制* 模式 [调试视图](../graphics/debugging-tools/debug-view.md) 来分析粒子的渲染性能影响。
* 使用 [Tracy](../editor/profiling/tracy.md) 或[内置性能分析器](../editor/profiling/profiler.md) 来分析 CPU 粒子性能。你可以看到更新特定发射器需要多长时间，因此最好首先优化最慢的发射器。可选地，如果你使用的是自定义引擎分支，可以通过在 `ParticleEmitterGraph.CPU.ParticleModules.cpp` 文件中将 `PARTICLE_EMITTER_MODULES_PROFILE` 设置为 `1` 来启用 CPU 粒子更详细的性能分析事件。
